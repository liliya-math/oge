# Telegram: обновления домашнего задания

Код готовится в `kabinet-apps-script.txt` (версия 7.5). Без настройки бота уведомления выключены, кабинет продолжает работать как прежде. Это дополнение к прежнему Google Apps Script, не отдельный сервер.

## Подключить один раз

1. В Telegram открой [@BotFather](https://t.me/BotFather), отправь `/newbot` и создай отдельного бота для lili.math. Сохрани токен. **Не вставляй токен в GitHub, код сайта или переписку.**
2. Открой Google-таблицу кабинета → **Расширения → Apps Script**. Замени прежний код всем содержимым `kabinet-apps-script.txt`, сохрани.
3. Выполни `setup`, разреши необходимые доступы. Вернись в таблицу и обнови её. Выбери **Кабинет → Подключить Telegram-бота**, вставь токен в окно. Если меню пока не появилось, функцию `configureTelegram` можно запустить из редактора.
4. В Apps Script: **Развернуть → Управление развёртываниями → карандаш → Новая версия → Развернуть**. Используй прежний адрес `/exec`, уже указанный в `kabinet.html`. Токен хранится в Script Properties проекта. Развёртывание должно исполняться от владельца таблицы, как и прежде.
5. Ученик открывает свою личную ссылку на кабинет → **Подключить Telegram → Открыть бота и нажать «Старт»**. На обработку команды может уйти около минуты. После обновления кабинета статус станет «подключён».

Ссылка привязки одноразовая, действует 10 минут. Обычный `/start` без неё не привязывает ученика. Для смены Telegram-аккаунта учитель сначала нажимает «Отключить Telegram»; старую активную привязку нельзя перехватить другой ссылкой.

## Как работает обновление файлов

- Существующие триггеры проекта сохраняются. Добавляются два: команды Telegram примерно раз в минуту; проверка файлов примерно раз в пять минут.
- Проверяются **только назначенные, ещё не выполненные задания активных учеников**, которые подключили бота. Источник назначений: листы «Домашка» и «Файлы».
- Для автоматической проверки подходят HTML/PDF на `https://lilimath.ru/`, в том числе относительные ссылки вроде `domashnee-zadanie-trapeciya.html`. Внешние сайты и ссылки Google Drive автоматически не скачиваются. О прикреплённом файле с Диска можно сообщить кнопкой «Уведомить» у задания.
- Читается именно опубликованный сайт: сообщения не отправляются при неудавшемся или ещё не опубликованном коммите. При первом успешном чтении создаётся эталон **без рассылки старых домашних заданий**. Поэтому после подключения ученика дождись первого прохода, прежде чем проверять обновление.
- Следующее изменение содержимого даст сообщение с темой задания и кнопкой открытия. Одинаковые версии повторно не отправляются. Несколько файлов одного ученика, изменившихся за один проход, объединяются в сообщение.
- 404, перенаправления, сетевые ошибки и пустые ответы не считаются обновлением. Прежний эталон сохраняется. Файлы больше 8 МБ не проверяются автоматически. За один проход читаются максимум 40 разных ссылок, затем курсор переходит дальше; для большого числа файлов задержка может быть больше пяти минут.
- Любое изменение байтов, включая оформление, считается изменением. Для исправления оформления без сообщения поставь Telegram ученика на паузу **до публикации**, затем включи после проверки сайта. При включении исходная версия снимется заново, без сообщения.

## Управление в кабинете учителя

- **Задать без уведомления**: сохранить новое назначение, не отправляя отдельного сообщения. Это не отключает уведомления о будущих изменениях файла.
- **Задать и уведомить**: сохранить назначение и отправить ученику сообщение.
- **Сохранить без уведомления / Сохранить и уведомить** в редакторе выданной домашки: сохранить правки с выбранным способом отправки.
- **Уведомить** рядом с назначением: отправить сообщение после ручного обновления/добавления файла. Это явная ручная отправка; повторное нажатие после завершения предыдущего запроса отправляет ещё одно сообщение.
- **Пауза для тихого обновления / Включить уведомления**: управлять автоматической и ручной отправкой для выбранного ученика.
- **Отключить Telegram**: удалить действующую привязку. Ученик также может отправить `/stop` самому боту.

Если Telegram недоступен, новое задание всё равно сохраняется; интерфейс сообщает отдельно, что сообщение не ушло. Не нажимай «Задать» повторно: используй «Уведомить».

## Данные и проверка

Служебные листы `Telegram`, `Telegram-ссылки`, `Telegram-файлы` создаются автоматически. Они содержат приватные привязки, хеши одноразовых ссылок и версии файлов. **Не публикуй эти листы/таблицу в открытый доступ.** Публичный API кабинета не возвращает Chat ID, токен бота и служебные листы. Не меняй коды учеников или служебные строки вручную во время отправки.

Настройку выполняет один владелец таблицы, чтобы не создавать параллельные триггеры разных аккаунтов. При смене бота прежние подписки отключаются; ученики подключают нового бота через кабинет. Бот с уже установленным webhook не перенастраивается автоматически: используй отдельного бота.

Автоматические тесты не отправляют настоящие сообщения:

```sh
node --test tools/test_telegram.cjs
python3 tools/check_links.py
```

После настройки: подключи тестовый кабинет, дождись исходной версии, измени только назначенную ему страницу, дождись сообщения. Повтори проверку без изменения файла (нового сообщения быть не должно), затем проверь паузу и `/stop`.
