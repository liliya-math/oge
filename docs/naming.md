# Как называются материалы

Название в каталоге (`catalog.json`, поле `title`) всегда такое:

    ID темы · Вид · Тема

Примеры:
- `5A.5.3 · ДЗ · Уровень 1 · Десятичные дроби`
- `8A.3 · Теория · Квадратные уравнения`
- `9A.3.2 · План урока · Смеси и сплавы`
- `6A.4 · Ответы к ДЗ (PDF) · Проценты`

ID темы был из карты навыков 5–9 (например `7A.4.2`); карта навыков с сайта убрана 07.11.2026. В названии указывается первая тема. Названия сортируются по ID, поэтому всё по одной теме идёт подряд.

## Виды (словарь, других не придумываем)
Теория, План урока, Разбор в диалоге, Разбор 5 задач, Памятка, Пятиминутки, Тест, Зачётный лист, Тренажёр, Тренажёр (новые числа), ДЗ, ДЗ №N, ДЗ · Уровень N, Ответы к ДЗ, Задание, Диагностика, Комплект, Закрепление, Работа. Печатная версия добавляет «(PDF)», текстовая «(текст)».

## Для учителя
План урока, Ответы и Разбор в диалоге помечены в каталоге полем `audience: "teacher"`. Ученику и родителю их показывать не надо.

## Файлы не переименовываем
Имена файлов остаются как есть: на них ссылаются кабинет и домашки у учеников. Единое название живёт только в `title`. Для новых файлов имя `тип-класс-тема` из STATE.md сохраняется.

## Как поддерживать
Новый материал: добавить запись в `catalog.json`, название писать вручную по образцу выше. Привязки материалов к узлам навыков (поле `node`) с сайта убраны 07.11.2026.
