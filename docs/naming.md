# Как называются материалы

Название в каталоге (`catalog.json`, поле `title`) всегда такое:

    ID темы · Вид · Тема

Примеры:
- `5A.5.3 · ДЗ · Уровень 1 · Десятичные дроби`
- `8A.3 · Теория · Квадратные уравнения`
- `9A.3.2 · План урока · Смеси и сплавы`
- `6A.4 · Ответы к ДЗ (PDF) · Проценты`

ID темы берётся из карты навыков 5–9 (`skills-by-grade.json`, например `7A.4.2`). Если материал привязан к нескольким темам, в названии первая, остальные лежат в поле `node`. Названия сортируются по ID, поэтому всё по одной теме идёт подряд.

## Виды (словарь, других не придумываем)
Теория, План урока, Разбор в диалоге, Разбор 5 задач, Памятка, Пятиминутки, Тест, Зачётный лист, Тренажёр, Тренажёр (новые числа), ДЗ, ДЗ №N, ДЗ · Уровень N, Ответы к ДЗ, Задание, Диагностика, Комплект. Печатная версия добавляет «(PDF)», текстовая «(текст)».

## Для учителя
План урока, Ответы и Разбор в диалоге помечены в каталоге полем `audience: "teacher"`. Ученику и родителю их показывать не надо.

## Файлы не переименовываем
Имена файлов остаются как есть: на них ссылаются кабинет, домашки у учеников и `skills-links.json`. Единое название живёт только в `title`. Для новых файлов имя `тип-класс-тема` из STATE.md сохраняется.

## Как поддерживать
Новый материал: добавить запись в `catalog.json` с `node`, затем `python3 tools/normalize_titles.py` (показать) и `--apply` (записать). Скрипт сам собирает название по имени файла и теме.
