## Активация проверки ДЗ (Apps Script 7.6)

GitHub Pages публикует HTML, но не обновляет привязанный к Google Таблице Apps Script. Пока сервер старый, кабинет показывает обычную галочку выполнения, архив и ссылку на Telegram. Новые статусы и загрузка решений появятся только после ответа сервера `workflow: 1`.

1. Открыть Google Таблицу кабинетов → Расширения → Apps Script.
2. Заменить код актуальным содержимым `kabinet-apps-script.txt` из этого репозитория и сохранить.
3. Выполнить `setup`. Если Google запросит доступ к Диску, разрешить для сохранения решений.
4. Развернуть → Управление развёртываниями → Изменить (карандаш) → Новая версия → Развернуть. Обновить существующее развёртывание, сохранив URL.
5. Обновить кабинет. В домашке появится вкладка «На проверке».

Старые данные сохраняются. К листу «Домашка» добавлены столбцы K–P: статус, сообщение ученика, комментарий учителя, файл решения, дата изменения, версия записи. Старые галочки отображаются как «Выполнено», без приписывания проверки учителем.

## Сценарий после активации

1. Ученик открывает назначенное задание → «Решаю».
2. «Отправить на проверку»: фото/PDF до 5 МБ либо текст решения → «На проверке».
3. «Нужна помощь»: причина, пояснение и необязательное фото → вопрос в кабинете учителя.
4. Учитель нажимает «Проверить / написать комментарий»: «Проверено» или «Нужно исправить». При возврате комментарий обязателен.
5. Ученик читает комментарий и отправляет исправление. Проверенные работы доступны в архиве.

Сообщения workflow сохраняются в кабинете, автоматически не рассылаются. Фотографии сохраняются в папку Диска «Кабинет 25-25 · решения учеников» с просмотром по ссылке, как текущие вложения ДЗ. При смене статуса запись сверяет код ученика, текст задания и версию, чтобы не затереть другую правку. Ученику недоступны статусы учительской проверки.

## Проверка

- `node tools/test_cabinet_workflow.cjs`: проверки владения заданием, устаревшей версии, допустимых статусов, комментария, формата/размера файла и сохранения фото (моки Sheets/Drive).
- Синтаксис JavaScript и Apps Script проверен Node.
- В браузере проверены демо, переходы вкладок, поиск, отправка текстового решения, режим родителя и совместимость со старым сервером.
- Реальное развёртывание Apps Script, отправка файлов на Google Диск и проверка на реальном ученике требуют активации владельцем. Они не проверены этой сессией.

## Первая очередь улучшений · 24 октября 2026

- Карточка ДЗ: название, раздел/темы, срок, одна основная кнопка и дополнительные файлы. Оценка времени показывается только при наличии `minutes`/`estimateMinutes`, без выдуманных значений.
- «На проверке», «Проверено», «Нужно исправить» и старая отметка выполнения считаются отдельно.
- Поддержка продолжения: 46 страниц на общем движке, шесть фиксированных пошаговых тренажёров и тренажёр смысла процентов. Общий мост `tools/study-resume.js` подключается только при открытии из кабинета через `lili_student`/`lili_hw`; внешние ссылки и PDF не меняются.
- Сохраняются позиция, введённый ответ, выбранные варианты и текст рассуждения. Пошаговые тренажёры восстанавливают состояние без повторного начисления баллов. Данные разделены по ученику и назначению. Обычные прямые ссылки продолжают использовать прежние сохранения.
- Кнопка «Продолжить с места остановки» появляется при наличии сохранённой позиции для этой работы и этого пути. На экране «Сегодня» приоритет: исправления → последняя незаконченная работа → ближайший срок.
- «Моя тетрадь ошибок» находится под списком ДЗ. Можно добавить личную запись, правило, исправление и аналогичное задание. При получении `revise` импортируется комментарий учителя; исходное замечание сохраняется, когда учитель меняет его при проверке. Статус «Исправление проверено» появляется только по серверному `checked`.
- Тетрадь и позиции сохраняются в браузере, между устройствами не синхронизируются. Для отправки исправлений через кабинет нужна уже существующая серверная возможность `workflow: 1` (активация 7.6 описана выше). В этой сессии Google Apps Script не развёртывался. На прежнем сервере доступны личная тетрадь, карточки и продолжение; автоимпорт замечаний и отправка зависят от сервера.
- Неподключённые движки/генераторы используют своё прежнее поведение; им не приписывается сохранённая позиция.

Проверки: `test_cabinet_homework.cjs`, `test_study_resume.cjs`, прежний `test_cabinet_workflow.cjs`, синтаксис всех изменённых HTML и проверка ссылок. В браузере проверены карточки, запись и восстановление тетради, продолжение пошагового тренажёра и домашки по трапеции (включая черновик рассуждения). Реальные работы учеников не изменялись.
