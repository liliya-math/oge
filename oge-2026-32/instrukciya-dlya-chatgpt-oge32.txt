ИНСТРУКЦИЯ: перевод вариантов ОГЭ из сканов в текст (папка oge-2026-32)

ЦЕЛЬ
В index.html 32 варианта ОГЭ. Условия заданий показаны картинками-сканами (img/vNN/zMM-K.webp).
Нужно по одному варианту заменять сканы набранным текстом с формулами, а рисунки оставлять
аккуратными вырезками. Образец готовой работы: вариант 10. Образец скрипта: primer-variant-10.py.
Делай так же, меняя только номер варианта, тексты и координаты вырезок.

КАК УСТРОЕНЫ ДАННЫЕ
В index.html есть <script type="application/json" id="data"> со списком из 32 вариантов.
У варианта: context (скан общего условия к №1-5), tasks (25 заданий), у задания: scan и key.
Страница сама покажет текст вместо скана, если добавить поля:
  вариант["ctxHtml"]        - HTML общего условия к №1-5
  задание["html"]           - HTML условия задания
Поля scan, context и key НЕ удалять и НЕ менять. Код страницы и CSS менять только так, как сказано
в разделе "ЧТО УЖЕ СДЕЛАНО НА СТРАНИЦЕ (16.11, трогать не нужно)
Общий код страницы переделан под режим "как на экзамене". Твоя работа - только перевод вариантов в текст.
- Подсказок и показа ответов нет. Ответ сохраняется без проверки и меняется до завершения варианта.
- Вторая часть: где в key есть ответ - поле ответа (с кнопками символов √ − ∞ ∪ ;), где key пустой (№24) -
  текст решения и до 4 фото.
- Общее условие к №1-5 раскрыто в каждом из этих заданий. Листание: кнопки, ряд номеров, стрелки клавиатуры.
- Таймер (только когда вкладка видна), кнопка "Завершить вариант" с подтверждением, потом ученику
  виден только балл первой части и время.
- Результат уходит на сервер кабинета (версия 8.2, oge32Submit_) с кодом ученика из адреса ?lili_student=КОД.
  При сбое сети отправка повторяется при следующем открытии.
Если при переводе варианта нужно что-то на странице изменить, СНАЧАЛА написать Лилии, сам код не править.

ВАЖНО ДЛЯ ПЕРЕВОДА: условие задания показывается из поля html. Пока поля нет, показывается скан.
Задание №24 (без ключа) переводить так же, как остальные. Поле key не трогать.

- Не делать больше одного варианта за один заход.
- Не менять ключи, оформление страницы, другие варианты.
- Не добавлять ссылки на источник сборника.
