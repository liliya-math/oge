ИНСТРУКЦИЯ: перевод вариантов ОГЭ из сканов в текст (папка oge-2026-32)

ЦЕЛЬ
В index.html 32 варианта ОГЭ. Условия заданий показаны картинками-сканами (img/vNN/zMM-K.webp).
Нужно по одному варианту заменять сканы набранным текстом с формулами, а рисунки оставлять
аккуратными вырезками. Образец готовой работы: вариант 10. Образец скрипта: primer-variant-10.py.
Делай так же, меняя только номер варианта, тексты и координаты вырезок.

КАК УСТРОЕНЫ ДАННЫЕ
В index.html есть <script type="application/json" id="data"> со списком из 32 вариантов.
У варианта: context (скан общего условия к №1-5), tasks (25 заданий), у задания: scan и key.
Страница сама покажет текст вместо скана, если добавить поля:
  вариант["ctxHtml"]        - HTML общего условия к №1-5
  задание["html"]           - HTML условия задания
Поля scan, context и key НЕ удалять и НЕ менять. Код страницы и CSS НЕ трогать.
После записи JSON обязательно заменить "</" на "<\/" (как в образце скрипта).

ПОРЯДОК РАБОТЫ НАД ОДНИМ ВАРИАНТОМ (экономно)
1. Склей сканы варианта в 3-4 длинных листа (context; №1-10; №11-18; №19-25) и посмотри их
   по одному разу. Не открывай 25 картинок по отдельности.
2. Набери текст каждого задания дословно, как в скане. Слово "Ответ:" и пустые клетки не переносить.
   У №19 второй скан (заголовок "Часть №2") не переносить.
3. Рисунки вырежи функцией crop из образца: задаёшь прямоугольник с запасом, она сама обрезает поля.
   В вырезку не должен попадать текст условия. Файлы: img/vNN/f07.webp, f-ctx.webp и т.п.
4. Склей все вырезки в один лист и посмотри его один раз: нет ли обрезанных букв и чужого текста.
5. Реши каждое задание №1-23 и №25 и сравни с key. Если не совпало, ключ не исправляй,
   а выпиши номер задания в отчёт для Лилии.
6. Запусти скрипт, проверь: node --check для кода страницы, все файлы рисунков существуют.
7. Один коммит на один вариант: "ОГЭ-32: вариант NN в текст".

ПРАВИЛА ОФОРМЛЕНИЯ (обязательные)
- Каждая новая мысль условия - отдельный абзац <p> (красная строка ставится сама).
  Вопрос задания ("Найдите...", "Ответ дайте в...") - отдельным абзацем.
- Главная формула или выражение - на отдельной строке: <p class="big">...</p>.
- Формулы внутри текста оборачивать в <span class="f">...</span>, чтобы не рвались переносом.
- Дроби только с горизонтальной чертой: <math><mfrac><mn>3</mn><mn>11</mn></mfrac></math>.
  Никаких 3/11 в условии.
- Корень только настоящим знаком: <math><msqrt><mn>5</mn></msqrt></math>. Не писать "√" отдельным символом.
- Любая система уравнений или неравенств - с фигурной скобкой слева, строки одна под другой
  (функция sysm в образце).
- Степени <sup>, индексы <sub>, переменные курсивом <i>x</i>. Минус - знак "−", не дефис.
- Варианты ответа 1) 2) 3) 4): <p class="opts"> и каждый вариант в <span class="f">.
- Утверждения в №19: каждое отдельным <p class="st">.
- Таблицы настоящими <table>, не картинкой.
- Рисунок ставить перед текстом (чертёж) или там, где он стоит в условии (числовая прямая, графики).
- Текст не пересказывать и не упрощать. Обращение "Найдите", "Решите" оставлять как в оригинале.
- Длинных тире не добавлять от себя.

ЧТО УЖЕ СДЕЛАНО НА СТРАНИЦЕ (16.11, трогать не нужно)
Общий код страницы переделан под режим "как на экзамене". Твоя работа - только перевод вариантов в текст.
- Подсказок и показа ответов нет. Ответ сохраняется без проверки и меняется до завершения варианта.
- Вторая часть: где в key есть ответ - поле ответа (с кнопками символов), где key пустой (№24) -
  текст решения и до 4 фото.
- Общее условие к №1-5 раскрыто в каждом из этих заданий. Листание: кнопки, ряд номеров, стрелки клавиатуры.
- Таймер (только когда вкладка видна), кнопка "Завершить вариант" с подтверждением, потом ученику
  виден только балл первой части и время.
- Результат уходит на сервер кабинета (версия 8.2, oge32Submit_) с кодом ученика из адреса ?lili_student=КОД.
  При сбое сети отправка повторяется при следующем открытии.
Если при переводе варианта нужно что-то на странице изменить, СНАЧАЛА написать Лилии, сам код не править.

Условие задания страница показывает из поля html. Пока поля нет, показывается скан.
Задание №24 (без ключа) переводить так же, как остальные. Поле key не трогать.
