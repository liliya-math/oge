УРОВЕНЬ 1. РАЗМИНКА (задания 1–10)
======================================================================

ЗАДАНИЕ 1. Вычисли: √49 + √81 − √16.

Ученик: Нужно в столбик извлекать?
Учитель: Не нужно — это «табличные» корни, их стоит знать наизусть.
√49 = 7 (потому что 7² = 49), √81 = 9, √16 = 4.
Теперь обычная арифметика: 7 + 9 − 4 = 12.
Ответ: 12.

ЗАДАНИЕ 2. Разложи на множители: x² − 9.

Учитель: Узнаёшь формулу? Это разность квадратов: a² − b² = (a − b)(a + b).
Здесь 9 = 3², значит:
x² − 9 = (x − 3)(x + 3).
Проверка обратным умножением: (x − 3)(x + 3) = x² + 3x − 3x − 9 = x² − 9.
Ответ: (x − 3)(x + 3).

ЗАДАНИЕ 3. Вычисли: (√5)² + (√3)².

Ученик: А как возводить корень в квадрат?
Учитель: Очень просто: (√a)² = a — корень и квадрат взаимно
уничтожаются, ведь это обратные действия. Значит:
(√5)² = 5, (√3)² = 3, а 5 + 3 = 8.
Ответ: 8.

ЗАДАНИЕ 4. Вычисли: √144.

Учитель: Какое число в квадрате даёт 144? Перебираем: 11² = 121,
12² = 144. Значит √144 = 12.
Ответ: 12.

ЗАДАНИЕ 5. Упрости: √16 · √9.

Ученик: Можно сразу перемножить под корнем?
Учитель: Можно и так: √16 · √9 = √(16 · 9) = √144 = 12. А можно
по отдельности: 4 · 3 = 12. Результат одинаковый — используй тот
путь, который удобнее.
Ответ: 12.

ЗАДАНИЕ 6. Найди значение: 3⁻².

Ученик: Отрицательная степень — это минус в ответе?
Учитель: Нет, это самая частая ошибка! Отрицательный показатель
означает ДРОБЬ: a⁻ⁿ = 1/aⁿ. Значит:
3⁻² = 1/3² = 1/9.
Минус в показателе «убирает» степень в знаменатель.
Ответ: 1/9.

ЗАДАНИЕ 7. Раскрой скобки: (x − 4)².

Учитель: Квадрат разности: (a − b)² = a² − 2ab + b². Здесь a = x, b = 4:
x² − 2 · x · 4 + 4² = x² − 8x + 16.
Три частые ошибки: забыть удвоенное произведение (получится x² + 16),
написать плюс вместо минуса, забыть квадрат 4². Проверяй все три
члена.
Ответ: x² − 8x + 16.

ЗАДАНИЕ 8. Разложи на множители: a² + 10a + 25.

Ученик: Как понять, что это полный квадрат?
Учитель: Проверь крайние члены: 25 = 5² — квадрат есть. Теперь
удвоенное произведение: 2 · a · 5 = 10a — совпадает с средним членом!
Значит это квадрат суммы:
a² + 10a + 25 = (a + 5)².
Ответ: (a + 5)².

ЗАДАНИЕ 9. Реши уравнение: x² = 64.

Учитель: Какие числа в квадрате дают 64? 8² = 64 и (−8)² = 64.
У такого уравнения ВСЕГДА два корня (кроме x² = 0):
x = 8 и x = −8.
Забыть минусовый корень — классическая ошибка, за неё снимают баллы
на ОГЭ.
Ответ: x = 8 и x = −8.

ЗАДАНИЕ 10. Вычисли: 2⁻³ · 2⁵.

Ученик: Опять отрицательная степень?
Учитель: Не обязательно раскрывать её. При умножении степеней
показатели складываются — это работает и для отрицательных:
2⁻³ · 2⁵ = 2⁻³⁺⁵ = 2² = 4.
Ответ: 4.


======================================================================
УРОВЕНЬ 2. ИСПЫТАНИЕ (задания 11–20)
======================================================================

ЗАДАНИЕ 11. Реши квадратное уравнение: x² − 7x + 12 = 0.

Учитель: Прежде чем считать дискриминант, попробуй подобрать корни
по теореме Виета: нужны два числа, которые в сумме дают 7, а в
произведении — 12. Это 3 и 4: 3 + 4 = 7, 3 · 4 = 12.
Если подбор не идёт — всегда работает дискриминант:
D = 49 − 48 = 1, x = (7 ± 1)/2, то есть 4 и 3.
Ответ: x = 3 и x = 4.

ЗАДАНИЕ 12. Упрости: √50 − √18 + √8.

Ученик: Корни разные, как вычитать?
Учитель: Сначала сделай их «одинаковыми» — вынеси множители
из-под корней так, чтобы везде остался √2:
√50 = √(25 · 2) = 5√2
√18 = √(9 · 2) = 3√2
√8 = √(4 · 2) = 2√2
Теперь это подобные: 5√2 − 3√2 + 2√2 = 4√2.
Идея как с буквами: 5a − 3a + 2a = 4a, только вместо a — √2.
Ответ: 4√2.

ЗАДАНИЕ 13. Сократи дробь: (x² − 4) / (x + 2).

Учитель: Числитель — разность квадратов:
(x² − 4) / (x + 2) = (x − 2)(x + 2) / (x + 2) = x − 2.
Важно: сокращать можно только МНОЖИТЕЛИ. Если бы в числителе было
x − 4, а не x² − 4, сократить нельзя было бы.
Ответ: x − 2.

ЗАДАНИЕ 14. Найди дискриминант уравнения: 2x² − 5x + 3 = 0.

Ученик: Формула с минусом b — всегда путаюсь.
Учитель: Запомни шаблон: D = b² − 4ac. Сначала выпиши коэффициенты
аккуратно: a = 2, b = −5, c = 3. Тогда:
D = (−5)² − 4 · 2 · 3 = 25 − 24 = 1.
Минус при b исчезает, потому что он в квадрате.
Ответ: D = 1.

ЗАДАНИЕ 15. Реши уравнение: x² − 6x + 9 = 0.

Учитель: Смотри внимательно на левую часть: x² − 6x + 9 — это
полный квадрат (x − 3)², ведь 2 · x · 3 = 6x и 3² = 9.
(x − 3)² = 0
Квадрат равен нулю только когда само выражение равно нулю:
x − 3 = 0, значит x = 3. Один корень (говорят «корень кратный 2»).
Проверка через дискриминант: D = 36 − 36 = 0 — согласуется.
Ответ: x = 3.

ЗАДАНИЕ 16. Упрости: (√7 − √3)(√7 + √3).

Ученик: Тут длинное умножение?
Учитель: Не нужно — это разность квадратов (a − b)(a + b) = a² − b²
с a = √7 и b = √3:
(√7)² − (√3)² = 7 − 3 = 4.
Вся хитрость задания — увидеть формулу и не раскрывать скобки в лоб.
Ответ: 4.

ЗАДАНИЕ 17. Освободись от иррациональности в знаменателе: 6 / √3.

Ученик: Что значит «освободиться»?
Учитель: Сделать так, чтобы в знаменателе не было корня. Умножаем
числитель и знаменатель на √3 — значение дроби не изменится:
6/√3 = (6 · √3)/(√3 · √3) = 6√3/3 = 2√3.
Ответ: 2√3.

ЗАДАНИЕ 18. Разложи на множители: x² − 5x + 6.

Учитель: Ищем два числа с суммой −5 и произведением 6. Это −2 и −3:
(−2) + (−3) = −5, (−2) · (−3) = 6. Значит:
x² − 5x + 6 = (x − 2)(x − 3).
Если подбор не идёт — дискриминант: D = 25 − 24 = 1, корни 2 и 3,
а по корням x₁ и x₂ разложение — (x − x₁)(x − x₂).
Ответ: (x − 2)(x − 3).

ЗАДАНИЕ 19. Найди значение: (√2 + 1)².

Ученик: (√2)² = 2, плюс 1² = 1, итого 3?
Учитель: Стоп! Так работает только если бы между членами был минус
в квадрате... нет, и при минусе не так. Квадрат суммы — это ТРИ члена:
(a + b)² = a² + 2ab + b².
(√2)² + 2 · √2 · 1 + 1² = 2 + 2√2 + 1 = 3 + 2√2.
Удвоенное произведение 2√2 — и есть то, что ты потерял.
Ответ: 3 + 2√2.

ЗАДАНИЕ 20. Реши уравнение: x² + 4x = 0.

Учитель: Сюда дискриминант можно, но лень — и правильно! Вынеси x
за скобку:
x(x + 4) = 0.
Произведение равно нулю, когда хотя бы один множитель равен нулю:
x = 0 или x + 4 = 0.
Ответ: x = 0 и x = −4.

УРОВЕНЬ 3. ВЫЗОВ (задания 21–25)

ЗАДАНИЕ 21. Одна сторона прямоугольника на 5 см больше другой,
площадь равна 84 см². Найди периметр.

Ученик: Периметр, а даны площадь...
Учитель: Сначала найдём стороны, периметр — в конце. Пусть меньшая
сторона — x, тогда большая — x + 5. Площадь:
x(x + 5) = 84
x² + 5x − 84 = 0
D = 25 + 336 = 361 = 19² — красивый дискриминант, значит всё верно.
x = (−5 + 19)/2 = 7 (отрицательный корень отбрасываем — длина
положительна). Стороны: 7 и 12.
Периметр: P = 2 · (7 + 12) = 38 см.
Ответ: P = 38 см.

ЗАДАНИЕ 22. Реши уравнение: 3x² − 5x + 2 = 0.

Учитель: Здесь a ≠ 1, поэтому теорема Виета в простом виде не
сработает — идём через дискриминант.
a = 3, b = −5, c = 2.
D = (−5)² − 4 · 3 · 2 = 25 − 24 = 1.
x = (5 ± 1)/6.
Два корня: x = 6/6 = 1 и x = 4/6 = 2/3.
Проверка по Виета для приведенного уравнения не нужна, но подставим
x = 1: 3 − 5 + 2 = 0 — верно.
Ответ: x = 1 и x = 2/3.

ЗАДАНИЕ 23. Докажи, что значение выражения (n + 3)² − (n − 3)²
делится на 12 для любого натурального n.

Ученик: Можно n = 1, 2, 3 проверить?
Учитель: Примеры — это не доказательство. Упрощаем выражение
для произвольного n:
(n + 3)² − (n − 3)² =
= (n² + 6n + 9) − (n² − 6n + 9) =
= n² + 6n + 9 − n² + 6n − 9 =
= 12n.
12n при любом натуральном n делится на 12, ведь это 12, умноженное
на целое число n. Что и требовалось доказать.
Ответ: выражение равно 12n, делится на 12.

ЗАДАНИЕ 24. Упрости: (√5 − 2)(√5 + 2) + (√3)².

Ученик: Сначала раскрою обе скобки?
Учитель: Можно умнее. Первое произведение — разность квадратов:
(√5 − 2)(√5 + 2) = (√5)² − 2² = 5 − 4 = 1.
А (√3)² = 3. Итого: 1 + 3 = 4.
Ответ: 4.

ЗАДАНИЕ 25. Моторная лодка прошла 30 км по течению и 30 км против
течения за 5 часов. Скорость течения 2 км/ч. Найди собственную
скорость лодки.

Ученик: Как из этого уравнение сделать?
Учитель: Разберём по шагам. Пусть собственная скорость лодки — v км/ч.
Тогда по течению она идёт со скоростью v + 2, а против течения — v − 2.
Время = путь / скорость:
по течению: 30/(v + 2), против течения: 30/(v − 2).
Всего 5 часов:
30/(v + 2) + 30/(v − 2) = 5.
Приводим к общему знаменателю (v + 2)(v − 2) = v² − 4 и умножаем
обе части на него:
30(v − 2) + 30(v + 2) = 5(v² − 4)
60v = 5v² − 20
5v² − 60v − 20 = 0
v² − 12v − 4 = 0
D = 144 + 16 = 160, √160 = 4√10.
v = (12 + 4√10)/2 = 6 + 2√10 ≈ 12,3 км/ч.
(Корень с минусом отбрасываем: скорость положительна.)
Поговори со мной об этом задании на занятии — такие задачи на ОГЭ
встречаются постоянно, и там числа обычно «круглее»: здесь важен
сам метод составления уравнения.
Ответ: v = 6 + 2√10 ≈ 12,3 км/ч.
