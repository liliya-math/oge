Средняя линия трапеции
m = (a + b) / 2
Соединяет середины боковых сторон. Параллельна обоим основаниям. Отрезок средней линии, заключённый между диагоналями, равен |a - b| / 2.
Площадь через основания и высоту
S = ((a + b) / 2) · h = m · h
Площадь равна произведению полусуммы оснований (средней линии) на высоту, опущенную на основание.
Площадь через диагонали
S = (1/2) · d₁ · d₂ · sin(φ)
Где φ — острый угол между пересекающимися диагоналями. Если диагонали взаимно перпендикулярны (φ = 90°), то S = (d₁ · d₂) / 2.
Равнобедренная трапеция: проекции
AH = (a - b) / 2,   HD = (a + b) / 2
Высота из вершины тупого угла делит большее основание на полуразность и полусумму оснований. Высота также равна средней линии, если диагонали перпендикулярны!
Треугольники при диагоналях
S₁ · S₂ = S₃²,   √S = √S₁ + √S₂
При пересечении диагоналей треугольники при основаниях подобны (коэффициент k = a / b), а боковые треугольники всегда равновелики (S₃ = S₄).
Вписанная и описанная окружности
Вписанная: a + b = c + d
Окружность можно вписать тогда и только тогда, когда суммы противоположных сторон равны. Описать окружность можно только около равнобедренной трапеции.
