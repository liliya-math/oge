Задача A. Приведение к одному основанию, степень степени, отрицательные показатели

Найдите значение выражения 8−3 · 16232−1 · 4−2

Что видим. Дробь, в числителе и знаменателе произведения степеней. Основания 8, 16, 32, 4 разные, но все они — степени числа 2. Показатели отрицательные.

Правило. При возведении степени в степень показатели перемножают: (am)n = amn. При умножении степеней с одинаковыми основаниями показатели складывают, при делении вычитают.

Алгоритм. все основания к числу 2 → числитель → знаменатель → показатель частного → значение степени.

Решение по шагам.

  1. 8 = 23, 16 = 24, 32 = 25, 4 = 22.
  2. Числитель: 8−3 · 162 = (23)−3 · (24)2 = 2−9 · 28 = 2−1.
  3. Знаменатель: 32−1 · 4−2 = (25)−1 · (22)−2 = 2−5 · 2−4 = 2−9.
  4. Частное: 2−1 : 2−9 = 2−1−(−9) = 28 = 256.

Ответ: 256.

Проверка. Числитель: 8−3 = 1512, 162 = 256, произведение 256512 = 12. Знаменатель: 132 · 116 = 1512. Частное: 12 : 1512 = 256.

Ловушка. Вычитание отрицательного показателя: −1 − (−9) = 8, а не −10. Ещё одна частая ошибка — перемножить показатели при умножении степеней.

Задача B. Разные основания: разложение на простые множители

Найдите значение выражения 124 · 6−323 · 3

Что видим. Основания 12 и 6 нельзя свести к одному числу, но оба разлагаются на простые множители 2 и 3. В знаменателе тоже 2 и 3.

Правило. Степень произведения равна произведению степеней: (ab)n = anbn. Показатели складывают только у степеней с одинаковым основанием.

Алгоритм. разложить основания на простые множители → собрать показатели двойки и тройки отдельно → разделить → вычислить.

Решение по шагам.

  1. 12 = 22 · 3, значит 124 = (22 · 3)4 = 28 · 34. 6 = 2 · 3, значит 6−3 = 2−3 · 3−3.
  2. Числитель: 28 · 34 · 2−3 · 3−3 = 28−3 · 34−3 = 25 · 3.
  3. Знаменатель: 23 · 3.
  4. Частное: (25 · 3) : (23 · 3) = 25−3 · 31−1 = 22 · 30 = 4 · 1 = 4.

Ответ: 4.

Проверка. Числитель: 124 = 20736, 6−3 = 1216, значение 20736216 = 96. Знаменатель 8 · 3 = 24. Частное 96 : 24 = 4.

Ловушка. Нельзя складывать показатели у разных оснований: 124 · 6−3 не равно ни 121, ни 61 (значение равно 96). Сначала разложение на простые множители, потом показатели каждого множителя отдельно.

Задача C. Отрицательные основания, отрицательный показатель, порядок действий

Найдите значение выражения (−2)−3 · (−4)3 − (−3)2 : 32

Что видим. Отрицательные основания в скобках, один отрицательный показатель, умножение, деление и вычитание. Главная трудность — знаки.

Правило. Степень отрицательного числа с чётным показателем положительна, с нечётным — отрицательна. a−n = 1an. Сначала возведение в степень, затем умножение и деление слева направо, затем вычитание.

Алгоритм. каждая степень отдельно (со знаком) → умножение и деление → вычитание.

Решение по шагам.

  1. (−2)−3 = 1(−2)3 = 1−8 = −0,125.
  2. (−4)3 = −64. Произведение: −0,125 · (−64) = 8 (знаки одинаковые, результат положительный).
  3. (−3)2 = 9; 9 : 32 = 9 : 9 = 1.
  4. 8 − 1 = 7.

Ответ: 7.

Проверка. Через степени двойки: (−4)3 = −26, (−2)−3 = −2−3, их произведение 23 = 8. Дальше 8 − 1 = 7.

Ловушка. (−3)2 = 9, а не −9: скобки значат, что в квадрат возводят число с минусом. Отрицательный показатель не меняет знак основания: (−2)−3 = −0,125, а не 0,125.

Задача D. Корень из степени и степень произведения

Найдите значение выражения √26 · 34(2−1 · 3)2

Что видим. Корень из произведения степеней в числителе и степень произведения в знаменателе.

Правило. Для неотрицательных чисел √ab = √a · √b и √a2 = a. Степень произведения равна произведению степеней: (ab)n = anbn.

Алгоритм. числитель: корень из каждого множителя → знаменатель: степень каждого множителя → деление.

Решение по шагам.

  1. √26 · 34 = √26 · √34 = 23 · 32 = 8 · 9 = 72.
  2. (2−1 · 3)2 = 2−2 · 32 = 94 = 2,25.
  3. 72 : 94 = 72 · 49 = 32.

Ответ: 32.

Проверка. Числитель: √64 · 81 = √5184 = 72, так как 722 = 5184. Знаменатель: (32)2 = 2,25. Частное 72 : 2,25 = 32.

Ловушка. Корень делит показатель пополам: √26 = 23, а не 212 и не 26. В степень возводят каждый множитель: (2−1 · 3)2 = 2−2 · 32, а не 2−1 · 32.

Задача E. Стандартный вид числа и степени десяти

Найдите значение выражения 3,6 · 105 · 5 · 10−31,2 · 102

Что видим. Числа в стандартном виде: десятичные множители и степени десяти с разными показателями.

Правило. При умножении степеней с одинаковым основанием показатели складывают, при делении вычитают. Десятичные множители и степени десяти считают отдельно.

Алгоритм. числитель: множители отдельно, степени десяти отдельно → знаменатель → сократить степени десяти → разделить множители.

Решение по шагам.

  1. Числитель: 3,6 · 5 = 18; 105 · 10−3 = 102. Значит числитель равен 18 · 102.
  2. Знаменатель: 1,2 · 102.
  3. 18 · 1021,2 · 102 = 181,2 = 18012 = 15 (степени десяти сократились).

Ответ: 15.

Проверка. Без степеней: 3,6 · 105 = 360000, 5 · 10−3 = 0,005, произведение 1800. Знаменатель 1,2 · 102 = 120. 1800 : 120 = 15.

Ловушка. 105 · 10−3 = 102 (показатели складывают), а не 10−15 и не 108. При делении 18 : 1,2 переносите запятую в обоих числах: 180 : 12.
