5 задач повышенной сложности (№20): подробный разбор

Те же пять задач, что в интерактивном тренажёре z20-kvadratnye-trenazhor.html: сначала решите там по шагам, потом сверьтесь здесь.

Задача 1. Замена переменной

Решите уравнение (x² − 3x)² − 2(x² − 3x) − 8 = 0.

  1. Выражение x² − 3x встречается дважды. Обозначим t = x² − 3x.
  2. Получаем t² − 2t − 8 = 0. D = 4 + 32 = 36; t = (2 ± 6)/2; t₁ = 4, t₂ = −2.
  3. Возвращаемся к x. Первое: x² − 3x = 4, то есть x² − 3x − 4 = 0; D = 9 + 16 = 25; x = (3 ± 5)/2; x = 4 или x = −1.
  4. Второе: x² − 3x = −2, то есть x² − 3x + 2 = 0; D = 9 − 8 = 1; x = (3 ± 1)/2; x = 2 или x = 1.
  5. Проверка x = 1: (1 − 3)² − 2(1 − 3) − 8 = 4 + 4 − 8 = 0.

Ответ: −1; 1; 2; 4.

Ловушка: Найти t и остановиться (записать 4 и −2). Ответ — значения x. Для каждого t решают своё уравнение.

Задача 2. Дробно-рациональное уравнение

Решите уравнение (x + 1)/(x − 1) + (x − 1)/(x + 1) = 10/3.

  1. ОДЗ: x ≠ 1 и x ≠ −1 (знаменатели не равны нулю).
  2. Общий знаменатель (x − 1)(x + 1) = x² − 1. Числитель: (x + 1)² + (x − 1)² = x² + 2x + 1 + x² − 2x + 1 = 2x² + 2.
  3. Уравнение: (2x² + 2)/(x² − 1) = 10/3. По основному свойству пропорции 3(2x² + 2) = 10(x² − 1).
  4. 6x² + 6 = 10x² − 10; 4x² = 16; x² = 4; x = 2 или x = −2.
  5. Оба числа входят в ОДЗ. Проверка x = 2: 3/1 + 1/3 = 10/3.

Ответ: −2; 2.

Ловушка: Забыть записать ОДЗ: здесь корни подошли, но в задаче 4 один корень придётся отбросить.

Задача 3. Кубическое уравнение, группировка

Решите уравнение x³ + 3x² − 4x − 12 = 0.

  1. Сгруппируем слагаемые: (x³ + 3x²) − (4x + 12) = 0.
  2. Вынесем общие множители: x²(x + 3) − 4(x + 3) = 0; (x + 3)(x² − 4) = 0.
  3. Разложим x² − 4 = (x − 2)(x + 2): (x + 3)(x − 2)(x + 2) = 0.
  4. Произведение равно нулю, когда один из множителей равен нулю: x = −3, x = 2, x = −2.
  5. Проверка x = −3: −27 + 27 + 12 − 12 = 0.

Ответ: −3; −2; 2.

Ловушка: Поделить обе части на (x + 3): корень −3 потеряется. Общий множитель выносят за скобку и приравнивают к нулю.

Задача 4. Посторонний корень

Решите уравнение x/(x − 2) − 8/(x² − 4) = 1/(x + 2).

  1. Разложим x² − 4 = (x − 2)(x + 2). ОДЗ: x ≠ 2 и x ≠ −2.
  2. Умножим обе части на (x − 2)(x + 2): x(x + 2) − 8 = x − 2.
  3. x² + 2x − 8 = x − 2; x² + x − 6 = 0.
  4. D = 1 + 24 = 25; x = (−1 ± 5)/2; x = 2 или x = −3.
  5. Число 2 не входит в ОДЗ (знаменатель x − 2 обращается в нуль), это посторонний корень.
  6. Проверка x = −3: −3/(−5) − 8/5 = 0,6 − 1,6 = −1; 1/(−3 + 2) = −1.

Ответ: −3.

Ловушка: Записать «−3; 2». Посторонний корень в ответе стоит балла.

Задача 5. Система с квадратным уравнением

Решите систему уравнений: x² + y² = 29, x − y = 3.

  1. Из линейного уравнения x = y + 3.
  2. Подставим: (y + 3)² + y² = 29; y² + 6y + 9 + y² = 29; 2y² + 6y − 20 = 0; y² + 3y − 10 = 0.
  3. D = 9 + 40 = 49; y = (−3 ± 7)/2; y = 2 или y = −5.
  4. Находим x = y + 3: при y = 2 получаем x = 5; при y = −5 получаем x = −2.
  5. Проверка: (5; 2): 25 + 4 = 29 и 5 − 2 = 3; (−2; −5): 4 + 25 = 29 и −2 + 5 = 3.

Ответ: (5; 2), (−2; −5).

Ловушка: Записать только значения y или x. Ответ — пары. Ошибка при раскрытии: (y + 3)² ≠ y² + 9.
