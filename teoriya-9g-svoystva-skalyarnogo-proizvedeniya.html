Свойства скалярного произведения векторов

Свойства

Для любых векторов a⃗\vec{a}a, b⃗\vec{b}b, c⃗\vec{c}c и любого числа kkk:

a⃗⋅b⃗=b⃗⋅a⃗\vec{a}\cdot\vec{b}=\vec{b}\cdot\vec{a}a⋅b=b⋅a (переместительное)
(ka⃗)⋅b⃗=k (a⃗⋅b⃗)(k\vec{a})\cdot\vec{b}=k\,(\vec{a}\cdot\vec{b})(ka)⋅b=k(a⋅b) (сочетательное по числу)
(a⃗+b⃗)⋅c⃗=a⃗⋅c⃗+b⃗⋅c⃗(\vec{a}+\vec{b})\cdot\vec{c}=\vec{a}\cdot\vec{c}+\vec{b}\cdot\vec{c}(a+b)⋅c=a⋅c+b⋅c (распределительное)

Чем отличается от умножения чисел

Результат - число, но сомножители - векторы: нельзя «разделить вектор на вектор».

И нет сочетательного закона для трёх векторов: (a⃗⋅b⃗)⋅c⃗(\vec{a}\cdot\vec{b})\cdot\vec{c}(a⋅b)⋅c - это число, умноженное на вектор, смысл другой.

Скалярный квадрат

a⃗2=∣a⃗∣2≥0\vec{a}^2=|\vec{a}|^2\ge 0a2=∣a∣2≥0, причём a⃗2=0\vec{a}^2=0a2=0 только для нулевого вектора.

Это свойство позволяет находить длину суммы: ∣a⃗+b⃗∣2=a⃗2+2a⃗⋅b⃗+b⃗2|\vec{a}+\vec{b}|^2=\vec{a}^2+2\vec{a}\cdot\vec{b}+\vec{b}^2∣a+b∣2=a2+2a⋅b+b2.

Применение: доказательство теорем

Скалярное произведение доказывает перпендикулярность без углов: например, диагонали ромба перпендикулярны, потому что (a⃗+b⃗)⋅(a⃗−b⃗)=∣a⃗∣2−∣b⃗∣2=0(\vec{a}+\vec{b})\cdot(\vec{a}-\vec{b})=|\vec{a}|^2-|\vec{b}|^2=0(a+b)⋅(a−b)=∣a∣2−∣b∣2=0 (в ромбе все стороны равны).

Применение: косинус угла

Угол между векторами находим из определения: cos⁡φ=a⃗⋅b⃗∣a⃗∣∣b⃗∣\cos\varphi=\frac{\vec{a}\cdot\vec{b}}{|\vec{a}||\vec{b}|}cosφ=∣a∣∣b∣a⋅b​. Свойства позволяют вычислить числитель, раскрыв скобки.
