Ловушка №1: Вынесение знака из-под корня
ОШИБКА: √(x²) = x ВЕРНО: √(x²) = |x|

Арифметический квадратный корень по определению неотрицателен (√A ≥ 0). Если x = -7, то √((-7)²) = √49 = 7, но отнюдь не -7. Запись без модуля верна только при гарантированном x ≥ 0.

Ловушка №2: Порядок операций: (√a)² vs √(a²)
(√a)² определено при любых a ОДЗ (√a)²: только a ≥ 0

Выражение (√a)² = a, но оно существует исключительно при a ≥ 0. В то же время √(a²) = |a| определено для любых вещественных чисел (-∞; +∞).

Ловушка №3: Корень из разности квадратов и сумм
√(a² + b²) = a + b √(a² + b²) ≠ a + b

Радикал не обладает линейностью по сложению. Пример: √(9 + 16) = √25 = 5, в то время как √9 + √16 = 3 + 4 = 7. Корень «распадается» только для произведений и частных: √(ab) = √a · √b (при a, b ≥ 0).

Ловушка №4: Внесение отрицательного множителя
При b < 0: b√3 = √(3b²) При b < 0: b√3 = -√(3b²)

Если множитель отрицателен, его знак «минус» обязан остаться снаружи радикала, иначе положительное подкоренное число исказит знак всего выражения.
