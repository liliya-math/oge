Разбор 5 задач повышенной сложности · системы уравнений (№20)

Каждая задача: условие, что видим, правило, алгоритм, решение, проверка, ответ и типичная ловушка. Ответ записывается парами.

Задача 1. Дробное уравнение и замена t = x/y

Условие. Решите систему уравнений: xy + yx = 52x² − y² = 3

Что видим. Система с дробью. Знаменатели x и y, поэтому нужно ОДЗ. В первом уравнении дроби x/y и y/x взаимно обратны: удобна замена t = x/y.

Правило. Дробь определена, когда знаменатель не равен нулю. Для взаимно обратных величин t и 1/t: t + 1/t = a сводится к квадратному уравнению (умножаем на t при t ≠ 0).

Алгоритм.

  1. Записать ОДЗ.
  2. Ввести t = x/y и решить уравнение для t.
  3. Для каждого t выразить x через y и подставить во второе уравнение.
  4. Найти x и y, проверить по ОДЗ.
  5. Записать пары.

Решение.

  1. ОДЗ: x ≠ 0, y ≠ 0.
  2. Пусть t = x/y, тогда y/x = 1/t: t + 1/t = 5/2. Умножим на 2t (t ≠ 0): 2t² + 2 = 5t, 2t² − 5t + 2 = 0, D = 25 − 16 = 9, t = (5 ± 3)/4, t = 2 или t = 1/2.
  3. Если t = 2, то x = 2y. Подставим: 4y² − y² = 3, y² = 1, y = 1 или y = −1. Тогда x = 2 или x = −2: пары (2; 1) и (−2; −1).
  4. Если t = 1/2, то x = y/2. Подставим: y²/4 − y² = 3, −3y²/4 = 3, y² = −4. Решений нет.
  5. Найденные числа не равны нулю, ОДЗ выполнено.

Проверка. (2; 1): 2/1 + 1/2 = 5/2, 4 − 1 = 3. (−2; −1): (−2)/(−1) + (−1)/(−2) = 2 + 1/2 = 5/2, 4 − 1 = 3. Оба верно.

Ответ: (2; 1), (−2; −1)

Ловушка. Не записать ОДЗ. Найти только x и забыть y. Искать решения во второй ветке «насильно»: там y² = −4, вывод «решений нет» тоже надо записать.

Задача 2. Сложение: только x² и y²

Условие. Решите систему уравнений: 2x² + 3y² = 303x² − y² = 23

Что видим. В обоих уравнениях только x² и y² (нет x, y, xy). Подходит сложение с умножением на число.

Правило. Способ сложения: умножаем уравнения на числа так, чтобы коэффициенты при одной переменной стали противоположными, затем складываем.

Алгоритм.

  1. Выбрать переменную, которую исключаем (здесь y²).
  2. Умножить уравнение и сложить.
  3. Найти x², затем y².
  4. Извлечь корни: каждый квадрат даёт два значения.
  5. Составить все пары.

Решение.

  1. Умножим второе уравнение на 3: 9x² − 3y² = 69.
  2. Сложим с первым: 2x² + 9x² + 3y² − 3y² = 30 + 69, 11x² = 99, x² = 9, x = 3 или x = −3.
  3. Из второго уравнения y² = 3x² − 23 = 27 − 23 = 4, y = 2 или y = −2.
  4. Знаки x и y не связаны (в системе только квадраты), поэтому подходят все четыре сочетания.

Проверка. (3; 2): 18 + 12 = 30, 27 − 4 = 23. Остальные пары дают те же квадраты, значит тоже верны.

Ответ: (3; 2), (3; −2), (−3; 2), (−3; −2)

Ловушка. Записать одну пару (3; 2) вместо четырёх. Взять x = 3 и забыть x = −3.

Задача 3. Симметричная система: s = x + y и p = xy

Условие. Решите систему уравнений: x² + y² + x + y = 12xy = 4

Что видим. Система симметричная: x и y входят одинаково. Левую часть первого уравнения можно записать через s = x + y и p = xy.

Правило. x² + y² = (x + y)² − 2xy. Если x + y = s и xy = p, то x и y — корни уравнения t² − st + p = 0.

Алгоритм.

  1. Выразить первое уравнение через s и p.
  2. Подставить p и найти s.
  3. Для каждого s решить t² − st + p = 0.
  4. Записать пары (с учётом порядка).

Решение.

  1. x² + y² = s² − 2p = s² − 8. Первое уравнение: s² − 8 + s = 12, s² + s − 20 = 0, D = 81, s = (−1 ± 9)/2, s = 4 или s = −5.
  2. Если s = 4, p = 4: t² − 4t + 4 = 0, (t − 2)² = 0, t = 2. Получаем x = y = 2: одна пара (2; 2).
  3. Если s = −5, p = 4: t² + 5t + 4 = 0, t = −1 или t = −4. Пары (−1; −4) и (−4; −1).

Проверка. (2; 2): 4 + 4 + 2 + 2 = 12, 2 · 2 = 4. (−1; −4): 1 + 16 − 1 − 4 = 12, (−1)(−4) = 4. По симметрии (−4; −1) тоже верна.

Ответ: (2; 2), (−1; −4), (−4; −1)

Ловушка. При двойном корне t = 2 записать две пары (2; 2) и (2; 2): пара одна. Потерять s = −5.

Задача 4. Однородное уравнение: разложение на множители

Условие. Решите систему уравнений: x² − 3xy + 2y² = 0x + y = 6

Что видим. Первое уравнение однородное: все члены второй степени. Его левую часть можно разложить на множители.

Правило. Произведение равно нулю, когда хотя бы один множитель равен нулю. Квадратный трёхчлен ax² + bxy + cy² раскладывают, как трёхчлен относительно x с коэффициентом y.

Алгоритм.

  1. Разложить левую часть: (x − y)(x − 2y).
  2. Записать две системы.
  3. Решить каждую подстановкой.
  4. Проверить обе пары.

Решение.

  1. x² − 3xy + 2y² = (x − y)(x − 2y). Проверка раскрытием: x² − 2xy − xy + 2y² = x² − 3xy + 2y².
  2. Случай 1: x − y = 0, то есть x = y. Из x + y = 6 получаем 2y = 6, y = 3, x = 3. Пара (3; 3).
  3. Случай 2: x − 2y = 0, то есть x = 2y. Из x + y = 6 получаем 3y = 6, y = 2, x = 4. Пара (4; 2).

Проверка. (3; 3): 9 − 27 + 18 = 0, 3 + 3 = 6. (4; 2): 16 − 24 + 8 = 0, 4 + 2 = 6.

Ответ: (3; 3), (4; 2)

Ловушка. Решить только один случай. Делить на y² и потерять y = 0: безопаснее разложить на множители.

Задача 5. Произведение равно нулю: две системы

Условие. Решите систему уравнений: (x − 2)(y + 1) = 0x² + y² = 5

Что видим. Первое уравнение — произведение, равное нулю. Оно распадается на два условия: x = 2 или y = −1.

Правило. Произведение равно нулю тогда и только тогда, когда хотя бы один из множителей равен нулю.

Алгоритм.

  1. Разбить на две системы.
  2. Решить каждую.
  3. Объединить решения, совпавшие записать один раз.
  4. Проверить.

Решение.

  1. Система I: x = 2 и x² + y² = 5. Тогда 4 + y² = 5, y² = 1, y = 1 или y = −1. Пары (2; 1) и (2; −1).
  2. Система II: y = −1 и x² + y² = 5. Тогда x² + 1 = 5, x² = 4, x = 2 или x = −2. Пары (2; −1) и (−2; −1).
  3. Пара (2; −1) встретилась в обеих системах. В ответ её записываем один раз: всего три решения.

Проверка. (2; 1): 0 · 2 = 0, 4 + 1 = 5. (2; −1): 0 · 0 = 0, 4 + 1 = 5. (−2; −1): (−4) · 0 = 0, 4 + 1 = 5.

Ответ: (2; 1), (2; −1), (−2; −1)

Ловушка. Записать четыре пары: (2; −1) дважды. Решить только одну ветку.
