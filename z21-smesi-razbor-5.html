5 задач повышенной сложности: подробный разбор

Те же пять задач, что в интерактивном тренажёре z21-smesi-trenazhor.html: сначала решите там по шагам, потом сверьтесь здесь.

Задача 1. Выпаривание

Имеется 50 кг 16%-ного раствора соли. Сколько килограммов воды нужно выпарить, чтобы концентрация соли стала 25%?

  1. При выпаривании уходит только вода, масса соли не меняется.
  2. Соли в исходном растворе: 0,16 · 50 = 8 кг.
  3. Пусть m кг — масса нового раствора (0 < m < 50). Соли в нём 0,25m. Уравнение: 0,25m = 8.
  4. m = 8 : 0,25 = 32 кг.
  5. Выпарили 50 − 32 = 18 кг воды. Проверка: 8 : 32 = 0,25 = 25%.

Ответ: 18 кг.

Ловушка: в ответ идёт масса выпаренной воды (18), а не масса нового раствора (32).

Задача 2. Смесь двух растворов, правило креста для проверки

Смешали 30%-ный и 50%-ный растворы кислоты и получили 600 г 42%-ного раствора. Сколько граммов 50%-ного раствора взяли?

  1. Пусть x г — масса 30%-ного раствора, тогда (600 − x) г — масса 50%-ного (0 < x < 600).
  2. Кислоты в смеси: 0,42 · 600 = 252 г. Кислота в частях: 0,3x и 0,5(600 − x).
  3. Уравнение по кислоте: 0,3x + 0,5(600 − x) = 252.
  4. 300 − 0,2x = 252; 0,2x = 48; x = 240. Значит, 30%-ного раствора 240 г, 50%-ного 600 − 240 = 360 г.
  5. Проверка: 0,3 · 240 + 0,5 · 360 = 72 + 180 = 252. По правилу креста: (50 − 42) : (42 − 30) = 8 : 12 = 2 : 3, и 240 : 360 = 2 : 3.

Ответ: 360 г.

Ловушка: спрашивают про 50%-ный раствор, а x мы обозначили для 30%-ного.

Задача 3. Переливание, отбор корня

Сосуд вместимостью 10 л наполнен 80%-ным раствором кислоты. Из сосуда отлили x л раствора и долили x л воды, затем эту операцию повторили. В результате получился 20%-ный раствор. Найдите x. Ответ дайте в литрах.

  1. 0 < x < 10. После отлива осталось (10 − x) л с прежней концентрацией 0,8, кислоты 0,8(10 − x) л.
  2. Долили x л воды, снова 10 л. Концентрация 0,8(10 − x) : 10 = 0,8(1 − x/10). После второго цикла 0,8(1 − x/10)².
  3. Уравнение: 0,8(1 − x/10)² = 0,2. Тогда (1 − x/10)² = 0,25, и 1 − x/10 = 0,5 или 1 − x/10 = −0,5.
  4. Из первого x = 5, из второго x = 15. Условию 0 < x < 10 подходит только x = 5.
  5. Проверка: 0,8 · 0,5 = 0,4; 0,4 · 0,5 = 0,2.

Ответ: 5 л.

Ловушка: нельзя писать 0,8(1 − 2x/10) = 0,2: второй раз отливают уже разбавленный раствор, поэтому множитель возводят в квадрат.

Задача 4. Два условия, система

Имеются два сосуда. Первый содержит 20 кг, а второй — 30 кг раствора кислоты разной концентрации. Если их слить вместе, получится раствор, содержащий 52% кислоты. Если же слить равные массы этих растворов, получится раствор, содержащий 55% кислоты. Сколько килограммов кислоты содержится в первом сосуде?

  1. Пусть x кг — кислоты в первом сосуде, y кг — во втором (x > 0, y > 0). Концентрации растворов x/20 и y/30.
  2. Слили всё: 50 кг раствора, кислоты в нём 0,52 · 50 = 26 кг. Первое уравнение: x + y = 26.
  3. Слили равные массы m кг: кислоты m · x/20 + m · y/30, масса смеси 2m, концентрация 0,55. Второе уравнение: (x/20 + y/30) : 2 = 0,55, то есть x/20 + y/30 = 1,1.
  4. Умножаем второе на 60: 3x + 2y = 66.
  5. Из первого y = 26 − x: 3x + 52 − 2x = 66; x = 14, y = 12.
  6. Проверка: x/20 = 0,7, y/30 = 0,4; среднее 0,55; кислоты 14 + 12 = 26 кг, 26 : 50 = 52%.

Ответ: 14 кг.

Ловушка: вопрос про массу кислоты в первом сосуде, а не про концентрацию; при равных массах нельзя писать «масса кислоты = 0,55 · 50».

Задача 5. Сплавы

Имеются два сплава. Первый содержит 10% никеля, второй — 40% никеля. Из этих двух сплавов получили третий сплав массой 300 кг, содержащий 34% никеля. На сколько килограммов масса первого сплава меньше массы второго?

  1. Пусть x кг — масса первого сплава, y кг — второго (x > 0, y > 0).
  2. Масса третьего сплава: x + y = 300. Никеля в третьем: 0,34 · 300 = 102 кг.
  3. Никель двух сплавов перешёл в третий: 0,1x + 0,4y = 102.
  4. Из первого y = 300 − x: 0,1x + 120 − 0,4x = 102; −0,3x = −18; x = 60, y = 240.
  5. Разность масс: 240 − 60 = 180 кг. Проверка: 6 + 96 = 102 кг никеля.

Ответ: 180 кг.

Ловушка: ответ — разность масс (180), а не масса первого сплава.
