4. Поезд проходит мимо светофора за 16 секунд, а по мосту длиной 600 м за 40 секунд. Найдите длину поезда в метрах.
Ответ:
Ответы и ключевые точки проверки (для учителя; печатать только первую страницу ученику).
  1. 45 км/ч. x — скорость первого (x > 0); время 180x и 180x + 15; уравнение 180x − 180x + 15 = 1; после преобразований x² + 15x − 2700 = 0; D = 11025 = 105²; корни 45 и −60; отбор. Проверка: 4 ч и 3 ч. Частая ошибка: поменяли местами вычитаемое, получили уравнение с «+».
  2. 10 км/ч. x > 2; по течению x + 2, против x − 2; время движения 6 − 1 = 5 ч (стоянку вычесть!); 24x + 2 + 24x − 2 = 5; 5x² − 48x − 20 = 0; D = 2704 = 52²; корни 10 и −0,4. Проверка: 2 ч + 3 ч + 1 ч = 6 ч. Частая ошибка: правая часть 6 вместо 5.
  3. 75 км/ч. Средняя скорость = весь путь : всё время. Путь S: 1100 + 12x = 160; 12x = 160 − 1100 = 1150; 2x = 150, x = 75. Ловушка: 2·60 − 50 = 70 — неверно, среднее арифметическое не подходит.
  4. 400 м. Мимо светофора путь L, по мосту L + 600; скорость одна: L/16 = (L + 600)/40; 40L = 16L + 9600; 24L = 9600; L = 400. Скорость 25 м/с = 90 км/ч. Ловушка: путь по мосту — только 600 м.
