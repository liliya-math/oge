4. Постройте график функции y = x3 − 9xx − 3. Определите, при каких k прямая y = kx имеет с графиком ровно одну общую точку.
Ответ:
Ответы и ключевые точки для проверки (отрезать).
  1. Ответ: m = 12. ОДЗ: x ≠ 1, x ≠ −3. (x2 − 1)(x2 − 9) = (x − 1)(x + 1)(x − 3)(x + 3), после сокращения y = (x + 1)(x − 3) = x2 − 2x − 3. Вершина (1; −4) выколота! Выколоты (1; −4) и (−3; 12). При m = −4 точек нет, при m = 12 уравнение x2 − 2x − 15 = 0 даёт x = 5 и x = −3 (выколота), остаётся одна. Ловушка: ответ «m = −4».
  2. Ответ: m = 0; m = 4. Гипербола y = −8/x на x ≤ −2: значения от 0 (не достигается) до 4, точка (−2; 4) закрашена. Парабола y = x2 на (−2; 2]: (−2; 4) выколота, (2; 4) закрашена, вершина (0; 0). Луч y = 6 − x на x > 2: (2; 4) выколота. При 0 < m < 4 — четыре точки, при m < 0 — одна, при m = 0 (x = 0 и x = 6) и m = 4 (x = −2 и x = 2) — по две.
  3. Ответ: −4 < m < 0. При x ≥ 0: y = x2 − 4x, вершина (2; −4). При x < 0: y = −x2 + 4x, функция возрастает, y < 0. m = 0 и m = −4: по две точки; m > 0 или m < −4: одна.
  4. Ответ: k = 3; k = 6. Сокращение: y = x(x + 3) = x2 + 3x, x ≠ 3, выколота (3; 18). Прямая y = kx проходит через (0; 0), уравнение x(x + 3 − k) = 0. Один корень при k = 3 (касание в начале координат) и при k = 6 (второй корень x = 3 выколот).
