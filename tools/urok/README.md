# tools/urok — сборщик уроков-объяснений (оболочка «ночной сад»)
Файлы: `lesson_content.py` (конструкторы экранов info/q/widget/cheat, разметка R/F/M/P, таблицы), `figs.py` (рисунки, подписи ставит `Fig.label`), `widgets.js` (интерактивные рисунки, `LAB` ставит подписи), `build.py` (вшивает экраны и виджеты в шаблон `obyasnenie-5-9-bissektrisa.html`), `figcheck.py` + `check_all.py` (подписи не на линиях: статические рисунки и все положения ползунков), `test_run.py` (Playwright: проходит весь урок до диплома), `example_urok_sin_cos.py` (готовый пример сценария на 104 экрана).
Новый урок: скопировать example_urok_sin_cos.py, заменить содержимое экранов; в build.py поменять OUT, TOPIC, KEY, адрес; при новых рисунках добавить функции в figs.py, при новых виджетах — в widgets.js (через LAB).
Оформление текста (обязательно): формулы, уравнения и примеры не рвутся на строки, это делает `LC.finalize()` (функция `nb` в lesson_content.py, вызывается в сборщике после импорта сценария); длинную формулу выводить отдельной строкой (`box=` или блок формул). Новая мысль начинается с нового абзаца: каждая мысль — отдельный аргумент `P(...)`, пример — отдельный абзац, каждый шаг примера — свой абзац. В разборе `why` каждая мысль с новой строки через `<br>`. Красная строка включается сборщиком (`.stmt p{text-indent:1.4em}`).
Для нового урока: сценарий `<тема>.py`, сборщик `build_<тема>.py` (копия `build.py`), прогон `test_run_<тема>.py`; общий `build.py` не править под тему.
