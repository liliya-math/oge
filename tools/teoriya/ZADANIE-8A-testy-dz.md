# Задание ChatGPT: тесты по теории и ДЗ для 23 квадратиков 8А (алгебра)

Образцы формата: `tools/teoriya/works-8A-glava3/` (dz-8A-123..., test-8A-123...) и `works-8A-glava2/`.
Теория каждого квадратика: `tools/teoriya/src/<id>.json`. Тест и ДЗ должны опираться на неё, не выходить за её рамки.

## Что сделать на квадратик

1. Тест по теории: `test-<id>-<slug>-teoriya.txt`. Тип работы: сам, время 10 мин, 9-10 заданий, по 1 баллу. Вопросы на понимание правил, условий, "верно ли, что", выбор формулы; 1-2 очень простых вычисления. Ответы из выбора на разных местах.
2. ДЗ: `dz-<id>-<slug>-variant-01.txt`. Один вариант, 5-10 заданий (по сложности), от простого к сложному. Баллы по сложности, а не по формату ответа: 1 за одно действие, 2 за два-три шага или тонкое место. Подсказка не более одной на задание.
3. Все числа и ответы пересчитать кодом (Fraction/sympy), не в уме. Условие задачи не должно допускать два ответа, если формат ответа один.

## Правила оформления (нарушение = переделывать)

- Система уравнений всегда с левой фигурной скобкой, уравнения друг под другом.
- Перечни пунктов (выражения, равенства, 1), 2), 3)) каждый на новой строке.
- Без длинных тире, только дефис. Модуль `\lvert a\rvert`, знак `|` в вариантах ответа запрещён.
- Ответ-выражение делать выбором из 4 вариантов, правильный на разных местах.
- Формулы не рвутся по строкам.
- Рисунки (если нужны) в `quiz-fig/`, подписи не на линиях.

## Порядок и проверка

Работать по главам, один коммит на главу. После каждой главы запустить `node tools/teoriya/check.cjs tools/teoriya/works-8A-glavaN` и `node --test tests/*.cjs`: 0 ошибок. Предупреждения объяснить в сообщении коммита. В main пушить сразу.
