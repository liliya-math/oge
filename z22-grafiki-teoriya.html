Теория и устный опрос: график кусочной функции и её свойства

Задание 22 ОГЭ (часть 2, 2 балла, до 2023 года тоже было под номером 22). Печать: 2 листа A4.

1. Что требуется в задании 22

Построить график функции, заданной формулой (кусочно, с модулем или дробью), и найти, при каких значениях параметра m прямая y = m (или при каких k прямая y = kx) имеет с графиком ровно одну, две, три общие точки либо не имеет их. Оценивается и график, и найденные значения.

2. Основные понятия

Функция. Зависимость переменной y от переменной x, при которой каждому значению x соответствует единственное значение y. Область определения — все значения x; область значений — все значения y. График — множество всех точек плоскости с абсциссами x и ординатами y = f(x).
Кусочно-заданная функция — функция, которая на разных промежутках задана разными формулами, например {x + 1, если x < 0x2, если x ≥ 0Каждую формулу строят только на своём промежутке; граничную точку закрашивают при нестрогом неравенстве и выкалывают при строгом.
Кусочная функция: (0; 1) выколота, (0; 0) закрашена
Парабола y = x2 − 4x + 3
y = (x² − 4)/(x − 2): выколота (2; 4)

4. Алгоритм построения графика кусочной функции

  1. Выбрать масштаб: единичный отрезок — одна клетка, оси подписать.
  2. Для каждой формулы определить вид графика (прямая, парабола, гипербола).
  3. Для каждого промежутка составить таблицу точек, включая границы промежутка.
  4. Построить кусок только на своём промежутке: нестрогое неравенство — точка закрашена, строгое — выколота.
  5. Если на границе два значения, отметить обе точки.
  6. Проверка: вертикальная прямая пересекает график не более одного раза.

5. Дробь с сокращением

Для y = x2 − 4x − 2: 1) область определения: x − 2 ≠ 0, то есть x ≠ 2; 2) разложить числитель: x2 − 4 = (x − 2)(x + 2); 3) сократить: y = x + 2 при x ≠ 2; 4) построить прямую y = x + 2 и выколоть точку с абсциссой 2: y(2) = 4, точка (2; 4). Область определения находят до сокращения.

6. Модуль

|a| = a при a ≥ 0 и |a| = −a при a < 0. Чтобы раскрыть модуль в формуле функции, находят, где выражение под модулем равно нулю, делят ось на промежутки и раскрывают модуль на каждом. Пример: y = x|x| − 3|x|. При x ≥ 0: y = x2 − 3x. При x < 0: y = −x2 + 3x. Для функции y = |f(x)| часть графика y = f(x), лежащую ниже оси Ox, отражают симметрично вверх.

7. Свойства функции по графику

Область определения — проекция графика на ось Ox, область значений — проекция на Oy. Нули — абсциссы точек пересечения с Ox. Функция возрастает там, где график идёт вверх при движении слева направо, убывает — где вниз. Наибольшее и наименьшее значения — самая высокая и самая низкая точки графика (выколотая точка значением не считается). Для y = x2 − 4x + 3: нули 1 и 3; вершина (2; −1); убывает на (−∞; 2], возрастает на [2; +∞); наименьшее значение −1.

8. Число общих точек с прямой y = m и y = kx

Прямая y = m. «Двигайте» горизонтальную прямую снизу вверх и считайте точки пересечения. Количество точек меняется только в особых положениях: на уровне вершин парабол, на уровне концов кусков и на уровне выколотых точек. Особые значения m проверяйте отдельно (подстановкой), а между ними считайте точки по рисунку.
Прямая y = kx. Она проходит через начало координат. Особые положения: через выколотую точку, через конец куска, касание параболы (дискриминант равен нулю). Ответ — отдельные значения k или промежутки.

9. Типичные ошибки

  • Не найдена область определения до сокращения: выколотые точки потеряны.
  • Выколотая точка нарисована, но при подсчёте общих точек не учтена.
  • Перепутаны строгое и нестрогое неравенства: точка закрашена там, где должна быть выколота.
  • Вершина параболы найдена со знаком «минус» (x0 = −b/(2a), а не b/(2a)).
  • Потеряны особые m: вершина, выколотая точка, значения на концах кусков.
  • Ответ записан промежутком там, где нужны отдельные числа, и наоборот.
Вопросы для устного опроса (с ответами)
  1. Что такое функция? Зависимость переменной y от переменной x, при которой каждому значению x соответствует единственное значение y. Например, y = x2: каждому x соответствует одно значение y.
  2. Что такое область определения и область значений функции? Область определения — все значения, которые принимает независимая переменная x. Область значений — все значения, которые принимает зависимая переменная y.
  3. Что называют графиком функции? Множество всех точек координатной плоскости, абсциссы которых равны значениям аргумента, а ординаты — соответствующим значениям функции.
  4. Как по рисунку проверить, что линия — график функции? Любая вертикальная прямая пересекает линию не более чем в одной точке: одному x соответствует не больше одного y.
  5. Какую функцию называют кусочно-заданной? Функцию, которая на разных промежутках изменения x задана разными формулами. Каждую формулу строят только на своём промежутке.
  6. Когда граничную точку куска закрашивают, а когда выкалывают? Закрашивают, если неравенство нестрогое (≤, ≥): точка принадлежит графику. Выкалывают (пустой кружок), если неравенство строгое (<, >) или значение x не входит в область определения.
  7. Как найти вершину параболы y = ax2 + bx + c? Абсцисса вершины x0 = −b/(2a), ордината y0 равна значению функции в этой точке: y0 = y(x0).
  8. От чего зависит направление ветвей параболы? От знака a: при a > 0 ветви направлены вверх, при a < 0 — вниз.
  9. Как построить гиперболу y = k/x? Составить таблицу значений для x > 0 и x < 0, например x = ±1, ±2, ±4. Две ветви: при k > 0 — в I и III четвертях, при k < 0 — во II и IV. Оси график не пересекает.
  10. Как раскрыть модуль? |a| = a, если a ≥ 0, и |a| = −a, если a < 0. Находят, где выражение под модулем равно нулю, делят ось на промежутки и на каждом раскрывают модуль со своим знаком.
  11. Как построить график y = |x|? Для x ≥ 0 строят y = x, для x < 0 строят y = −x. Получается «галочка» с вершиной в начале координат.
  12. Почему при сокращении дроби появляется выколотая точка и как найти её координаты? Сокращение не расширяет область определения: значения x, при которых знаменатель был равен нулю, в график не входят. Абсциссу берут из знаменателя исходной дроби, ординату считают по сокращённой формуле.
  13. Сколько общих точек у прямой y = m с параболой, если m выше вершины, в вершине, ниже вершины (ветви вверх)? Две, одна, ни одной.
  14. Какие значения m нужно проверять отдельно? Ординаты вершин парабол, значения на концах кусков (закрашенных и выколотых), ординаты выколотых точек.
  15. Чем отличается задача с прямой y = m от задачи с прямой y = kx? Прямая y = m горизонтальна, её «двигают» вверх и вниз. Прямая y = kx проходит через начало координат и «вращается» вокруг него; её особые положения: через выколотые точки, через концы кусков и касание.
  16. Что значит «функция возрастает на промежутке»? Большему значению аргумента из этого промежутка соответствует большее значение функции.
  17. Что такое нули функции? Значения аргумента, при которых значение функции равно нулю. На графике это абсциссы точек пересечения с осью Ox.
