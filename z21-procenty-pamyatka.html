Памятка: алгоритм и оформление, проценты (задание 21)

Решение записывают полностью на бланке ответов №2. Задание стоит 2 балла.

Алгоритм решения

  1. Прочитай, выпиши данные, определи тип. Цена или вклад (коэффициенты); смесь или сплав (масса вещества); сушка (сухое вещество не меняется).
  2. Обозначь неизвестное. «Пусть x кг (руб., %) — …». Запиши ограничение: x > 0, для процента снижения 0 < x < 100.
  3. Переведи проценты в десятичные дроби: 20% = 0,2. Изменение на p% записывай коэффициентом 1 ± p/100.
  4. Определи, что сохраняется. Для цен — коэффициенты перемножают. Для смесей и сплавов — масса вещества складывается: «вещества в первом + вещества во втором = вещества в смеси». Для сушки — сухого вещества до и после поровну. Заполни таблицу: масса · доля = масса вещества.
  5. Составь уравнение или систему и реши. Раскрой скобки, собери подобные, найди x.
  6. Отбери корень по смыслу и проверь подстановкой в условие.
  7. Запиши ответ на тот вопрос, который задан (масса третьего сплава, а не x), в нужных единицах.
Формулы. p% = p/100. Было a, стало a(1 ± p/100). Несколько изменений — коэффициенты перемножают. Вклад: A(1 + p/100)ⁿ. Масса вещества = масса раствора · доля вещества. Вода 0%, чистое вещество 100%.

Что снимает баллы

  • Сложены проценты вместо перемножения коэффициентов (+20% и −20% дают 0, а не 0,96).
  • Сложены концентрации вместо масс вещества.
  • Процент записан числом без деления на 100 (20 вместо 0,2) — уравнение неверное, 0 баллов.
  • Вычислительная ошибка при верном уравнении — 1 балл вместо 2.
  • Не отобран корень (в ответе отрицательная масса или процент больше 100).
  • В ответ записано не то, что спрашивали (x вместо массы третьего сплава).
  • Решение оборвано на уравнении, нет ответа.

Образец записи

Задача. Первый сплав содержит 10% меди, второй — 40% меди. Масса второго сплава на 3 кг больше массы первого. Из этих двух сплавов получили третий сплав, содержащий 30% меди. Найдите массу третьего сплава.

Решение. Пусть x кг — масса первого сплава (x > 0), тогда масса второго (x + 3) кг, масса третьего (2x + 3) кг.

масса, кгдоля медимасса меди, кг
1-йx0,10,1x
2-йx + 30,40,4(x + 3)
3-й2x + 30,30,3(2x + 3)

Медь первого и второго сплавов вся перешла в третий. Составим уравнение:

0,1x + 0,4(x + 3) = 0,3(2x + 3).

0,1x + 0,4x + 1,2 = 0,6x + 0,9; 0,5x + 1,2 = 0,6x + 0,9; 0,1x = 0,3; x = 3.

Первый сплав весит 3 кг, второй 6 кг, третий 2 · 3 + 3 = 9 кг.

Проверка. Меди 0,3 + 2,4 = 2,7 кг; 0,3 · 9 = 2,7 кг. Верно.

Ответ: 9 кг.

Где эксперт ищет баллы: 1) введено неизвестное с единицами; 2) выражены массы всех трёх сплавов; 3) уравнение составлено по массе меди; 4) уравнение решено верно; 5) дан ответ на заданный вопрос.
