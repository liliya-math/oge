Задача 1. Дробь с выколотыми точками, прямая y = m

Условие. Постройте график функции y = x4 − 13x2 + 36(x − 3)(x + 2). Определите, при каких значениях m прямая y = m имеет с графиком ровно одну общую точку.

  1. Область определения: (x − 3)(x + 2) ≠ 0, то есть x ≠ 3 и x ≠ −2.
  2. Числитель: замена t = x2: t2 − 13t + 36 = (t − 4)(t − 9), значит x4 − 13x2 + 36 = (x − 2)(x + 2)(x − 3)(x + 3).
  3. Сокращение: y = (x − 2)(x + 3) = x2 + x − 6 при x ≠ 3, x ≠ −2.
  4. График — парабола, ветви вверх. Вершина: x0 = −1/2, y0 = −6,25. Нули −3 и 2. Таблица: x = −4, −3, −1, 0, 1, 2, 4 даёт y = 6, 0, −6, −6, −4, 0, 14. Выколоты точки (−2; −4) и (3; 6).
  5. Двигаем прямую y = m снизу вверх. Ниже вершины точек нет. В вершине (m = −6,25) одна точка. Выше вершины обычно две, но на уровне m = −4 и m = 6 одна из двух точек выколота, остаётся одна.

Ответ: m = −6,25; m = −4; m = 6.

Проверка. m = −4: x2 + x − 2 = 0, x = 1 или x = −2; точка x = −2 выколота, остаётся одна. m = 6: x2 + x − 12 = 0, x = 3 или x = −4; точка x = 3 выколота, остаётся одна.

Ловушка. Взять только вершину (m = −6,25) и потерять m = −4 и m = 6. Это потеря балла: значения параметра найдены не все.

Задача 2. Кусочная функция с гиперболой

Условие. Постройте график функции y = {−4/x, если x ≤ −1−x2 + 2x + 3, если −1 < x ≤ 3x − 3, если x > 3Определите, при каких m прямая y = m имеет с графиком ровно одну общую точку.

  1. Гипербола y = −4/x при x ≤ −1 (II четверть): x = −8, −4, −2, −1 даёт y = 0,5; 1; 2; 4. Точка (−1; 4) закрашена.
  2. Парабола y = −x2 + 2x + 3 на (−1; 3], ветви вниз. Вершина x0 = 1, y0 = 4. Нули −1 и 3. Точка (−1; 0) выколота, точка (3; 0) закрашена. Ещё точки: (0; 3), (2; 3).
  3. Прямая y = x − 3 при x > 3: x = 4, 5 даёт y = 1, 2. Точка (3; 0) здесь выколота, но принадлежит параболе, поэтому на графике закрашена.
  4. Считаем точки. m > 4: только прямая, 1 точка. m = 4: гипербола, вершина, прямая, 3 точки. 0 < m < 4: 1 + 2 + 1 = 4 точки. m = 0: парабола в точке x = 3 (x = −1 выколота), 1 точка. m < 0: точек нет.

Ответ: m = 0; m > 4.

Проверка. При m = 0: x2 − 2x − 3 = 0, x = 3 или x = −1; x = −1 не входит в промежуток (−1; 3], значит точка одна. Гипербола и прямая при m = 0 значений 0 не принимают.

Ловушка. При m = 0 посчитать две точки пересечения с параболой (x = −1 выколота). При m = 4 забыть про гиперболу и получить две точки вместо трёх. Для этой задачи важно, что (−1; 4) закрашена.

Задача 3. Модуль, прямая y = m

Условие. Постройте график функции y = x|x| − 3|x|. Определите, при каких m прямая y = m имеет с графиком ровно две общие точки.

  1. Раскрываем модуль. При x ≥ 0: |x| = x, y = x2 − 3x. При x < 0: |x| = −x, y = −x2 + 3x.
  2. Правый кусок (x ≥ 0): парабола, ветви вверх, нули 0 и 3, вершина (1,5; −2,25). Точки: (1; −2), (2; −2), (4; 4).
  3. Левый кусок (x < 0): ветви вниз, вершина x0 = 1,5 лежит правее промежутка, значит слева функция возрастает и y < 0. Точки: (−1; −4), (−2; −10).
  4. Считаем точки. m > 0: 1 точка (только справа). m = 0: x = 0 и x = 3, 2 точки. −2,25 < m < 0: справа 2, слева 1, всего 3. m = −2,25: справа 1, слева 1, всего 2. m < −2,25: 1 точка.

Ответ: m = −2,25; m = 0.

Проверка. m = 0: x|x| − 3|x| = |x|(x − 3) = 0, x = 0 или x = 3. m = −2,25: справа x = 1,5; слева −x2 + 3x = −2,25, откуда x2 − 3x − 2,25 = 0 и подходит x = (3 − 3√2)/2 < 0.

Ловушка. Считать график симметричным (как у y = x2 − 3|x|). Здесь x|x| нечётная функция, левая часть — другая парабола.

Задача 4. Дробь, прямая y = kx

Условие. Постройте график функции y = x3 − 4xx − 2. Определите, при каких k прямая y = kx имеет с графиком ровно одну общую точку.

  1. Область определения: x ≠ 2.
  2. Сокращение: x3 − 4x = x(x − 2)(x + 2), поэтому y = x(x + 2) = x2 + 2x при x ≠ 2. Выколота точка (2; 8).
  3. Парабола, ветви вверх, вершина (−1; −1), нули −2 и 0. Точки: (−3; 3), (1; 3), (−2; 0), (0; 0).
  4. Прямая y = kx проходит через (0; 0), а эта точка принадлежит графику. Значит одна общая точка есть всегда, нужно, чтобы вторых не было.
  5. x2 + 2x = kx, то есть x(x + 2 − k) = 0: x = 0 или x = k − 2. Вторая точка исчезает, если она совпадает с первой (k − 2 = 0, k = 2, прямая касается параболы) или выколота (k − 2 = 2, k = 4, прямая проходит через (2; 8)).

Ответ: k = 2; k = 4.

Проверка. k = 2: x2 = 0, единственный корень x = 0. k = 4: x2 − 2x = 0, x = 0 или x = 2, а x = 2 выколота.

Ловушка. Найти только k = 4 («прямая через выколотую точку») и забыть касание в начале координат (k = 2), либо забыть, что (0; 0) всегда на графике.

Задача 5. Дробь с модулем

Условие. Постройте график функции y = x2 − 3|x|x. Определите, при каких m прямая y = m имеет с графиком ровно одну общую точку.

  1. Область определения: x ≠ 0.
  2. Раскрываем модуль. При x > 0: |x| = x, y = (x2 − 3x)/x = x − 3. При x < 0: |x| = −x, y = (x2 + 3x)/x = x + 3.
  3. График — два луча. Левый: y = x + 3 при x < 0, конец (0; 3) выколот. Правый: y = x − 3 при x > 0, конец (0; −3) выколот. Точки: (−3; 0), (−1; 2), (1; −2), (3; 0).
  4. Значения. Левый луч принимает все значения y < 3, правый — все y > −3.
  5. Считаем точки. m ≤ −3: подходит только левый луч, 1 точка (при m = −3 правая точка x = 0 выколота). −3 < m < 3: два луча, 2 точки. m ≥ 3: только правый луч, 1 точка (при m = 3 левая точка x = 0 выколота).

Ответ: m ≤ −3 или m ≥ 3, то есть m ∈ (−∞; −3] ∪ [3; +∞).

Проверка. m = 3: левая ветвь даёт x = 0, она выколота; правая даёт x = 6, значит одна точка. m = −3: левая даёт x = −6, правая x = 0 (выколота), одна точка.

Ловушка. Не включить граничные m = −3 и m = 3 (в ответе «m < −3 или m > 3»), хотя в них одна из точек выколота и общая точка остаётся одна.
