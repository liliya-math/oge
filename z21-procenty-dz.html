3. Смешали 25%-ный и 45%-ный растворы соли и получили 40 кг 36%-ного раствора. Сколько килограммов 25%-ного раствора взяли?
Ответ:
4. Первый сплав содержит 15% серебра, второй — 35% серебра. Масса второго сплава на 4 кг больше массы первого. Из этих двух сплавов получили третий сплав, содержащий 27% серебра. Найдите массу третьего сплава. Ответ дайте в килограммах.
Ответ:
Ответы и ключевые точки проверки (для учителя; печатать только первую страницу ученику).
  1. 40. Пусть x% — повышение и снижение, 0 < x < 100; (1 + x/100)(1 − x/100) = 0,84 (начальная цена сокращается); 1 − x²/10 000 = 0,84; x² = 1600; x = 40, корень −40 не подходит. Проверка: 1,4 · 0,6 = 0,84. Частая ошибка: «на 16% ниже» записать как 0,16 вместо 0,84.
  2. 10. 30 000(1 + x/100)² = 36 300; (1 + x/100)² = 1,21; 1 + x/100 = 1,1 или −1,1; x = 10, корень −210 не подходит. Проверка: 30 000 · 1,1 = 33 000; 33 000 · 1,1 = 36 300. Частая ошибка: 1 + 2x/100 = 1,21, получают 10,5.
  3. 18 кг. x кг 25%-ного, (40 − x) кг 45%-ного; по соли: 0,25x + 0,45(40 − x) = 0,36 · 40; 18 − 0,2x = 14,4; x = 18 (45%-ного 22 кг). Проверка: 4,5 + 9,9 = 14,4. Частая ошибка: сложить концентрации 25 + 45.
  4. 20 кг. x кг первого, (x + 4) второго, (2x + 4) третьего; 0,15x + 0,35(x + 4) = 0,27(2x + 4); 0,5x + 1,4 = 0,54x + 1,08; 0,04x = 0,32; x = 8. Масса третьего 2 · 8 + 4 = 20. Проверка по серебру: 1,2 + 4,2 = 5,4 = 0,27 · 20. Частая ошибка: ответить 8 (масса первого).
