Задача A. Порядок действий: скобки, затем деление и умножение слева направо; обыкновенные и десятичные дроби вместе

Найдите значение выражения 214 : (112 − 0,75) · 0,4

Что видим. Скобки, деление и умножение. В выражении есть и смешанные числа, и десятичные дроби.

Правило. Сначала действия в скобках; затем умножение и деление слева направо. Если в выражении разные виды дробей, приводят их к одной форме: 214 = 2,25; 112 = 1,5.

Алгоритм. скобки → приведение к одной форме → деление → умножение.

Решение по шагам.

  1. 112 = 1,5; 1,5 − 0,75 = 0,75.
  2. 214 = 2,25; 225 : 75 = 3. Дробями: 94 : 34 = 3.
  3. 3 · 0,4 = 1,2.

Ответ: 1,2.

Проверка. Прикидка: 214 : 0,75 = 3 (так как 0,75 · 3 = 2,25); 3 · 0,4 = 1,2.

Ловушка. Умножение и деление равноправны и идут слева направо. Если сначала умножить 0,75 · 0,4, получится 214 : 0,3 = 7,5 вместо 1,2.

Задача B. Смешанные числа с разными знаменателями

Найдите значение выражения 356 − 138 + 2124

Что видим. Три смешанных числа, знаменатели 6, 8 и 24 разные.

Правило. Чтобы сложить или вычесть дроби с разными знаменателями, надо привести их к наименьшему общему знаменателю, а затем выполнить действие.

Алгоритм. наименьший общий знаменатель → вычитание → сложение → сокращение → запись десятичной.

Решение по шагам.

  1. НОК(6, 8, 24) = 24.
  2. 32024 − 1924 = 21124.
  3. 2 + 2 = 4; 1124 + 124 = 1224 = 12. Получилось 412.
  4. 12 = 0,5, значит 412 = 4,5.

Ответ: 4,5.

Проверка. переведём в 24-е доли: 9224 − 3324 + 4924 = 10824 = 4,5.

Ловушка. Нельзя складывать и вычитать знаменатели. Сначала общий знаменатель, потом действие. Частая ошибка — не сократить 1224 и записать 41224.

Задача C. Отрицательные числа: знаки в произведении, частном и «минус перед отрицательным»

Найдите значение выражения −23 · (−4,5) − 112 : (−34)

Что видим. Умножение и деление отрицательных чисел, затем вычитание.

Правило. Произведение и частное чисел с одинаковыми знаками положительны, с разными знаками отрицательны. Вычесть число — значит прибавить противоположное ему число.

Алгоритм. знак произведения → значение → знак частного → значение → вычитание.

Решение по шагам.

  1. 23 · 92 = 3; знаки одинаковые, значит +3.
  2. 32 : 34 = 32 · 43 = 2; знаки разные, значит −2.
  3. 3 − (−2) = 3 + 2 = 5.

Ответ: 5.

Проверка. «+» · «+» = «+»; «+» : «−» = «−»; вычитаем отрицательное — прибавляем.

Ловушка. 3 − (−2) — это 3 + 2 = 5. Если записать 3 − 2, получится 1.

Задача D. Дробная черта: числитель и знаменатель считаются отдельно

Найдите значение выражения 112 + 23 · 0,753,5 − 214

Что видим. Длинная дробная черта: в числителе и в знаменателе стоят выражения.

Правило. Дробная черта означает деление и заменяет скобки: сначала находят значение числителя и значение знаменателя, затем делят.

Алгоритм. числитель → знаменатель → деление.

Решение по шагам.

  1. 0,75 = 34; 23 · 34 = 12 = 0,5.
  2. 1,5 + 0,5 = 2.
  3. 3,5 − 2,25 = 1,25.
  4. 200 : 125 = 1,6. Проверка: 1,25 · 1,6 = 2.

Ответ: 1,6.

Проверка. частное · делитель = делимое: 1,6 · 1,25 = 2.

Ловушка. Нельзя делить отдельные слагаемые числителя на знаменатель. Сначала весь числитель, потом весь знаменатель, потом деление.

Задача E. Рациональный счёт: вынести общий множитель

Найдите значение выражения 58 · 3,2 + 38 · 3,2 − 114 · 0,4

Что видим. В двух слагаемых повторяется множитель 3,2; дроби 58 и 38 дают в сумме единицу.

Правило. Распределительное свойство умножения: a · b + a · c = a · (b + c).

Алгоритм. общий множитель → сумма в скобках → произведение → вычитание.

Решение по шагам.

  1. 58 · 3,2 + 38 · 3,2 = (58 + 38) · 3,2 = 1 · 3,2.
  2. 1 · 3,2 = 3,2.
  3. 54 · 25 = 12 = 0,5.
  4. 3,2 − 0,5 = 2,7.

Ответ: 2,7.

Проверка. 58 · 3,2 = 2; 38 · 3,2 = 1,2; 2 + 1,2 − 0,5 = 2,7.

Ловушка. Не нужно считать 58 · 3,2 и 38 · 3,2 по отдельности: общий множитель выносится, и 58 + 38 = 1.
