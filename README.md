## Важные правила внесения изменений

1. Не редактировать `main` напрямую: сначала вносить изменения в отдельную ветку.
2. Не перемещать и не переименовывать страницы без проверки всех ссылок на них.
3. Перед изменением пробников проверять ответы, подсчёт баллов, подсказки, сохранение прогресса и отправку результатов.
4. Перед изменением `kabinet.html` или `kabinet-apps-script.txt` отдельно проверять обмен данными с Google Таблицами.
5. После правок проверять ссылки и пути к изображениям, мобильную ширину и работу интерактивных элементов.
6. Разные визуальные стили страниц не унифицировать автоматически: сначала установить, являются ли различия намеренными.

## Рабочий процесс

- Вести аудит и исправления в отдельной ветке.
- Проверять каждое изменение до переноса в `main`.
- Сохранять существующие URL страниц, если нет необходимости менять их.


## Интеграция результатов пробника с кабинетом

Для передачи завершённого результата в кабинет используются два Apps Script и две Google-таблицы:

1. Скрипт-приёмник пробников сохраняет полный отчёт в листе `Результаты`.
2. При наличии кода ученика он передаёт итог в Apps Script кабинета.
3. Скрипт кабинета проверяет общий секрет и существование активного ученика, затем добавляет/обновляет запись в листе `Пробники`. Пятый столбец `ID попытки` используется для предотвращения дублей.

### Настройка после проверки кода

- В обоих проектах Apps Script открыть **Настройки проекта → Свойства скрипта** и добавить `PROBE_SHARED_SECRET` с одним и тем же длинным случайным значением. Значение не помещать в HTML и не коммитить в репозиторий.
- В проект приёмника перенести код из `probnik-result-receiver.gs.txt`, сохранив привязку к таблице с листом `Результаты`.
- В проект кабинета перенести обновлённый код из `kabinet-apps-script.txt` и повторно развернуть веб-приложение с тем же URL, который указан в `kabinet.html`.
- В панели `#lilia` в пробнике указывать код ученика из кабинета при создании персональной ссылки. Старые ссылки без кода продолжат открываться, но не будут автоматически привязаны к кабинету.
- Проверить на тестовом ученике: завершить пробник, убедиться, что полный отчёт появился в `Результаты`, а баллы — в кабинете. Затем проверить повторную отправку той же попытки: дублироваться запись не должна.

**Важно:** код изменён в рабочей ветке и не опубликован. До развёртывания обновлённого Apps Script интеграция не заработает. Изменения Google Apps Script нельзя выполнить через GitHub автоматически — код нужно вручную вставить в соответствующие проекты.
