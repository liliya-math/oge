Линейная функция. Знаки k и b

Что нужно знать

  • Наклон k
  • Пересечение с Oy
  • Прямая через начало

Теория

Наклон k
Читай слева направо. При k > 0 прямая поднимается, при k < 0 опускается, при k = 0 горизонтальна.
Пересечение с Oy
При x = 0 получается y = b. Если пересечение выше нуля, b положительно, ниже нуля отрицательно.
Прямая через начало
Если b = 0, график y = kx проходит через (0; 0). При ненулевом k это прямая пропорциональность.

Разбор примера

По графику y = kx + b определи знаки коэффициентов.

  1. Прямая поднимается слева направо, значит, k > 0.
  2. Она пересекает Oy при y = −2, значит, b < 0.

Линейная функция. Формула по двум точкам

Что нужно знать

  • Коэффициент b
  • Коэффициент k
  • Проверка формулы

Теория

Коэффициент b
Найди ординату точки, в которой прямая пересекает ось Oy.
Коэффициент k
По двум точкам вычисли y₂ − y₁x₂ − x₁. Учитывай масштаб осей и знаки при вычитании.
Проверка формулы
Подставь координаты целой точки. Например, для (2; 3) и (0; 2) получаем k = 3 − 22 − 0 = 0,5.

Разбор примера

Восстанови формулу по точкам (0; −1) и (2; 2).

  1. Получаем b = −1.
  2. k = 2 − (−1)2 − 0 = 1,5. Формула y = 1,5x − 1.
  3. При x = 2 получаем 3 − 1 = 2.

Квадратичная функция. Знаки a, b и c

Что нужно знать

  • Ветви и коэффициент a
  • Вершина и коэффициент b
  • Коэффициент c

Теория

Ветви и коэффициент a
Если a > 0, ветви направлены вверх, если a < 0 — вниз. Чем больше |a| при фиксированной вершине, тем уже парабола.
Вершина и коэффициент b
Абсцисса вершины xв = −b2a. Отсюда b = −2axв. При вершине на Oy получаем b = 0.
Коэффициент c
При x = 0 значение y равно c. Найди точку пересечения с Oy. Нули функции, напротив, находятся на Ox.

Разбор примера

Определи знаки a, b и c для параболы на рисунке.

  1. Ветви направлены вверх, поэтому a > 0.
  2. Вершина справа от Oy, её абсцисса 1. Значит, b = −2a < 0.
  3. Парабола пересекает Oy при y = −1, значит, c < 0. Формула данного графика y = x² − 2x − 1.

Обратная пропорциональность. Гипербола

Что нужно знать

  • Область определения
  • Четверти
  • Восстановление k

Теория

Область определения
Для y = kx с k ≠ 0 запрещено x = 0. Значение y также не равно нулю.
Четверти
При k > 0 числа x и y имеют одинаковый знак, ветви лежат в I и III четвертях. При k < 0 знаки разные, ветви во II и IV четвертях.
Восстановление k
Коэффициент k = xy для любой точки графика. Например, для (2; −1) получаем k = −2.

Разбор примера

Определи формулу по рисунку.

  1. Правая ветвь ниже Ox, значит k < 0.
  2. Точка (2; −1) даёт k = −2. Формула y = −2x.

График квадратного корня

Что нужно знать

  • Область определения
  • Форма и значения
  • Отражение

Теория

Область определения
Для y = √x допустимы x ≥ 0. Начальная точка (0; 0).
Форма и значения
График поднимается вправо, постепенно становится положе. Точки (1; 1), (4; 2), (9; 3) легко проверить возведением в квадрат.
Отражение
График y = −√x получается отражением относительно Ox. При x ≥ 0 его значения неположительны.

Разбор примера

Назови точки графика y = √x при x = 0, 1 и 4.

  1. √0 = 0, √1 = 1, √4 = 2.
  2. Получаем (0; 0), (1; 1), (4; 2).

Графики разных семейств

Что нужно знать

  • Силуэт и область определения
  • Проверка по точкам
  • Порядок ответа

Теория

Силуэт и область определения
Прямая равномерно наклонена. Парабола имеет вершину и ось симметрии. Гипербола имеет две отдельные ветви. Квадратный корень начинается в (0; 0).
Проверка по точкам
Если вид совпадает у нескольких формул, проверь знакомые координаты. Для прямой удобно брать пересечение с Oy, для параболы вершину, для гиперболы точку на ветви.
Порядок ответа
Выпиши номера формул в порядке А, Б, В. Например, А → 2, Б → 3, В → 1 дают 231.

Разбор примера

Назови семейства графиков А, Б, В.

  1. А: прямая проходит через начало координат.
  2. Б: парабола ветвями вниз.
  3. В: гипербола с ветвями в I и III четвертях.
