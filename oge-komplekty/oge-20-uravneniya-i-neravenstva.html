Значение выражения по условию

Что нужно знать

  • Одна комбинация букв
  • Ограничение и подстановка

Теория

Одна комбинация букв
Если в условии и в вопросе повторяется одна и та же комбинация, обозначь её новой буквой.
Ограничение и подстановка
Исключи нуль знаменателя. Найди значение новой переменной и подставь его в выражение из вопроса.

Разбор примера

Найди 3(3a − 2b) + 1, если 3a − 2b + 43a − 2b − 2 = 2.

  1. Обозначим 3a − 2b через t, t ≠ 2. После умножения на t − 2 получаем t + 4 = 2(t − 2).
  2. Отсюда t = 8. Тогда 3 · (8) + 1 = 25.

Дробное уравнение и ОДЗ

Что нужно знать

  • Нули знаменателей
  • Общий знаменатель

Теория

Нули знаменателей
Их исключаем до преобразований. Решение полученного многочлена принимается только на ОДЗ.
Общий знаменатель
Домножь обе части на общий знаменатель на ОДЗ, затем реши полученное уравнение.

Разбор примера

Реши уравнение 1(x − 2)² + 3(x − 2) = 4.

  1. ОДЗ: x ≠ 2. Обозначим u = (x − 2).
  2. Умножаем на u². Получаем 4u² − 3u − 1 = 0, или (u − 1)(4u + 1) = 0.
  3. Из u = 1 и u = −0,25 получаем два допустимых значения x.
  4. Ответ 2. 1,75; 3.

Биквадратное уравнение со сдвигом

Что нужно знать

  • Замена квадратом
  • Обратная замена

Теория

Замена квадратом
Если встречаются степени 2 и 4 одного выражения, положи t = (x − h)².
Обратная замена
Из корней по t оставь неотрицательные. Положительный t даёт два значения x, нулевой одно.

Разбор примера

Реши уравнение (x − 2)⁴ − 7(x − 2)² − 18 = 0.

  1. Пусть t = (x − 2)² ≥ 0.
  2. Уравнение (t − 9)(t + 2) = 0. Корень t = −2 исключаем.
  3. Из (x − 2)² = 9 получаем x = −1 и x = 5.
  4. Ответ 2. −1; 5.

Одинаковые радикалы по обе стороны

Что нужно знать

  • ОДЗ под корнем
  • Вычитание радикалов

Теория

ОДЗ под корнем
Арифметический квадратный корень существует, если подкоренное выражение неотрицательно.
Вычитание радикалов
Одинаковые радикалы можно вычесть. Их прежнее ограничение сохраняется после упрощения.

Разбор примера

Реши уравнение x² − 2x + √1 − x = √1 − x + 8.

  1. Условие под корнем: x ≤ 1. Одинаковые корни вычитаем из обеих частей именно на этой области.
  2. Остаётся x² − 2x − 8 = 0. Корни −2 и 4. Допустим только −2.
  3. Ответ 1. −2.

Общий множитель, полный квадрат и группировка

Что нужно знать

  • Общий множитель
  • Группировка
  • Нулевое произведение

Теория

Общий множитель
Приведи правую часть к нулю и вынеси повторяющееся выражение. Деление на него может потерять корни.
Группировка
В кубическом уравнении сгруппируй два первых и два последних слагаемых. Ищи одинаковую скобку.
Нулевое произведение
Если произведение равно нулю, достаточно обнулить хотя бы один множитель. Используй разность квадратов.

Разбор примера

Реши уравнение (x − 3)(x² + 4x + 4) = 4(x − 3).

  1. Вынесем (x − 3). Остаётся (x − 3)((x + 2)² − 4) = 0.
  2. По разности квадратов получаем (x − 3)x(x + 4) = 0.
  3. Ответ 2. −4; 0; 3.

Равенство квадратов или сумма квадратов

Что нужно знать

  • Равенство квадратов
  • Сумма квадратов
  • Степень 4

Теория

Равенство квадратов
Если A² = B², то A = B или A = −B. Это следует из (A − B)(A + B) = 0.
Сумма квадратов
Если A² + B² = 0, то A = 0 и B = 0 одновременно, поскольку оба слагаемых неотрицательны.
Степень 4
Запиши x⁴ как (x²)². Дальше используй равенство квадратов.

Разбор примера

Реши уравнение (x² − 4)² = (12)².

  1. Из равенства квадратов x² − 4 = 12 или x² − 4 = -12.
  2. Первая ветка даёт x² = 16, вторая x² = -8 < 0.
  3. Ответ 2. −4; 4.

Системы уравнений. Подстановка и замена

Что нужно знать

  • Подстановка
  • Порядок пары
  • Проверка

Теория

Подстановка
Если x или y уже выражена, подставь её во вторую строку. Если в обеих строках есть одна комбинация, подставь её значение целиком.
Порядок пары
После решения уравнения восстанови вторую координату. В ответе сначала x, затем y.
Проверка
Каждая пара должна удовлетворять сразу двум уравнениям.

Разбор примера

Реши систему y = x + 3x² + y = 15.

  1. Выражение x² + x + 3 = 15 сводится к (x − 3)(x + 4) = 0. Возвращаемся к y = x + 3.
  2. Проверяем каждую пару в обеих строках.
  3. Ответ 2. (3; 6), (−4; −1).

Неравенство со сдвигом и корнем в коэффициенте

Что нужно знать

  • Общий множитель
  • Интервал

Теория

Общий множитель
Перенеси правую часть влево и вынеси x − h. Если коэффициент √a, получишь (x − h)(x − h − √a).
Интервал
Для строгого знака «меньше» решение лежит между корнями, обе точки исключаются. При a = 0 квадрат не бывает отрицательным.

Разбор примера

Реши (x − 1)² < √3(x − 1).

  1. Пусть t = (x − 1). Тогда t(t − √3) < 0. Между нулями 0 и √3 знаки множителей разные.
  2. Прибавляем 1 к границам. Ответ (1; 1 + √3).

Метод интервалов для кубических произведений и двух квадратных трёхчленов

Что нужно знать

  • Корни и знак
  • Кратность

Теория

Корни и знак
Разложи все множители и отметь корни. Справа знак произведения определяется старшим коэффициентом.
Кратность
У простого корня знак меняется. У двойного, например (x − 2)², не меняется. При нестрогом знаке изолированный корень тоже может входить.

Разбор примера

Реши (4 − x)(x² + 2x − 3) ≥ 0.

  1. Ответ 2. Разложение даёт −(x − (−3))(x − (1))(x − 4). Справа «−», знаки чередуются на простых корнях. Получаем (−∞; −3] ∪ [1; 4].

Кратный корень и отдельная точка

Что нужно знать

  • Двойной множитель
  • Неравенство с равенством

Теория

Двойной множитель
Квадрат положителен по обе стороны своего нуля.
Неравенство с равенством
Если требуется ≥ или ≤, отдельно проверь нуль квадрата, даже если соседние промежутки не подходят.

Разбор примера

Реши (2 − x)(x² − 4) ≥ 0.

  1. Ответ 2. Получаем −(x − 2)²(x + 2). При x = 2 произведение нулевое. Для остальных x знак определяется выражением −(x + 2), поэтому x ≤ −2. Получаем (−∞; −2] ∪ [2; 2].

Дробное неравенство. Общий знаменатель и ОДЗ

Что нужно знать

  • Перенос в одну часть
  • Порядок отметок
  • Знак дроби

Теория

Перенос в одну часть
Приведи выражения к одной дроби. Нельзя умножать на выражение неизвестного знака без разбора случаев.
Порядок отметок
Отметь нули числителя и знаменателя. Нули знаменателя выколоты при любом знаке.
Знак дроби
На каждом промежутке определи знаки числителя и знаменателя, затем знак всей дроби.

Разбор примера

Реши x ≤ 16x.

  1. Ответ 2. После переноса x² − 16x ≤ 0. Нули ±4, x = 0 исключён. На интервалах слева направо знаки −, +, −, +. Получаем (−∞; −4] ∪ (0; 4].

Дробное неравенство с сокращением

Что нужно знать

  • ОДЗ до сокращения
  • Пересечение с ОДЗ

Теория

ОДЗ до сокращения
Запрет на нули исходного знаменателя сохраняется после сокращения.
Пересечение с ОДЗ
Реши упрощённое неравенство и исключи все запрещённые значения, даже если они лежат внутри ответа.

Разбор примера

Реши x² − 7x + 10(x − 2) ≤ 0.

  1. Ответ 2. На ОДЗ x ≠ 2. Сокращаем общий множитель и получаем x − 5 ≤ 0. Точка 2 выколота, 5 включаем. Получаем (−∞; 2) ∪ (2; 5].
