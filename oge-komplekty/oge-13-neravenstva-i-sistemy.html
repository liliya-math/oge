Линейное неравенство

Что нужно знать

  • Равносильные преобразования
  • Знак при делении
  • Граница на прямой

Теория

Равносильные преобразования
Можно прибавить или вычесть одно и то же выражение из обеих частей. Скобки раскрывают по распределительному закону.
Знак при делении
При делении или умножении обеих частей на отрицательное число направление знака меняется. При положительном сохраняется. Например, из −2x > 6 следует x < −3.
Граница на прямой
При < и > точка выколота, при ≤ и ≥ закрашена. У бесконечности всегда круглая скобка.

Разбор примера

Реши 2x + 8 ≤ 5x − 1.

  1. Вычитаем 5x и 8 из обеих частей. Получаем −3x ≤ −9.
  2. Делим на −3 и меняем направление: x ≥ 3.
  3. Ответ [3; +∞). Подстановка x = 3 даёт равенство, x = 4 даёт 16 ≤ 19.

Квадрат числа и разность квадратов

Что нужно знать

  • Симметрия
  • Перенос и строгость
  • Неположительная правая часть

Теория

Симметрия
Если a > 0, то x² = a² при x = −a и x = a. Квадрат меньше a² строго между этими точками и больше a² снаружи.
Перенос и строгость
Выражение x² − a² сравниваем с нулём или сразу переносим a² вправо. При строгом знаке границы исключаем, при нестрогом включаем.
Неположительная правая часть
Квадрат неотрицателен. Например, x² < 0 не имеет решений, x² ≥ 0 верно для любого x, а x² ≤ 0 только при x = 0.

Разбор примера

Реши x² < 36.

  1. Равенство достигается в точках −6 и 6.
  2. Между этими точками |x| < 6. Границы выколоты.
  3. Ответ (−6; 6).

Квадратное неравенство ax − x² и общий вид

Что нужно знать

  • Общий множитель
  • Знаки по ветвям
  • Корни совпадают или отсутствуют

Теория

Общий множитель
В ax − x² вынеси x. Получится x(a − x). Нули выражения 0 и a. Отметь их слева направо независимо от знака a.
Знаки по ветвям
У ax − x² старший коэффициент −1. При двух разных корнях значение положительно между корнями и отрицательно снаружи. Для a2x² + bx + c с a2 > 0 знаки обратные.
Корни совпадают или отсутствуют
Если корень двойной, знак через него не меняется. Если действительных корней нет, выражение всюду имеет знак старшего коэффициента.

Разбор примера

Реши −3x − x² ≥ 0.

  1. Вынесем x: x(−3 − x) ≥ 0. Нули −3 и 0.
  2. Ветви вниз, поэтому выбираем промежуток между нулями. Нестрогое неравенство включает оба конца.
  3. Ответ [−3; 0].

Произведение двух линейных множителей

Что нужно знать

  • Нули множителей
  • Метод интервалов
  • Равенство нулю

Теория

Нули множителей
Реши каждое уравнение отдельно. В x + 5 нуль −5, в x − 2 нуль 2. Они делят прямую на промежутки.
Метод интервалов
Проверь знак произведения внутри каждого промежутка. Два множителя одного знака дают плюс, разных знаков дают минус.
Равенство нулю
Нули произведения входят в решение при ≤ и ≥. Если множитель повторяется дважды, знак возле его нуля с обеих сторон одинаков.

Разбор примера

Реши (x + 5)(x − 2) < 0.

  1. Границы −5 и 2. Между границами первый множитель положительный, второй отрицательный.
  2. Подходит (−5; 2), так как требуется строго отрицательное произведение.

По рисунку к неравенству

Что нужно знать

  • Открытая и закрытая точка
  • Расположение решения
  • Проверка точки

Теория

Открытая и закрытая точка
Сначала выпиши границы. По заливке точек определи, включаются ли они.
Расположение решения
Для x² − a² внутри между корнями знак минус, снаружи плюс. Для −(x² − a²) знаки меняются.
Проверка точки
Подставь точку из выделенного промежутка и точку вне него. Например, 0 подходит для (−3; 3), а 4 нет.

Разбор примера

Выбери знак в записи x² − 9 ? 0 по рисунку.

  1. Границы −3 и 3 включены.
  2. В центре подставляем x = 0, получаем −9. Поэтому нужен знак ≤.

Система. Лучи направлены навстречу

Что нужно знать

  • Фигурная скобка
  • Построение
  • Пусто или одна точка

Теория

Фигурная скобка
В системе все неравенства должны выполняться одновременно. Решение системы — пересечение множеств решений.
Построение
Изобрази каждый луч и выдели общую часть. Конец включён, если он удовлетворяет обоим неравенствам.
Пусто или одна точка
Если левая граница правее правой, пересечение пусто. При равных границах возможна одна точка, если оба знака нестрогие.

Разбор примера

Реши систему x − 1 ≥ −32x < 6.

  1. Первый луч x ≥ −2, второй x < 3.
  2. Отмечаем общую часть [−2; 3).

Система. Лучи одного направления

Что нужно знать

  • Два нижних ограничения
  • Два верхних ограничения
  • Совпадение границ

Теория

Два нижних ограничения
При x ≥ a и x ≥ b выбирай большее из a и b. Например, x ≥ 1 и x ≥ 4 дают x ≥ 4.
Два верхних ограничения
При x ≤ a и x ≤ b выбирай меньшее из a и b.
Совпадение границ
Если границы равны, а один знак строгий, точка исключена: x ≥ 3 и x > 3 дают x > 3.

Разбор примера

Реши систему x + 1 ≥ −2x − 4 > 0.

  1. Получаем x ≥ −3 и x > 4.
  2. Все x > 4 удовлетворяют первому условию. Ответ (4; +∞).

Дробно-рациональное неравенство

Что нужно знать

  • ОДЗ
  • Нули числителя
  • Знаки на интервалах

Теория

ОДЗ
Знаменатель не может быть нулём. Такие точки выколоты при любом знаке неравенства. Если сократил общий множитель, прежние запреты сохраняются.
Нули числителя
Дробь равна нулю, когда числитель равен нулю и знаменатель ненулевой. Нуль числителя включается при ≤ или ≥.
Знаки на интервалах
Нули числителя и знаменателя разбивают прямую. Для дроби знак плюс, если числитель и знаменатель одного знака, и минус, если знаки разные.

Разбор примера

Реши x + 2x − 3 ≤ 0.

  1. x = −2 обнуляет числитель, x = 3 запрещён.
  2. Слева от −2 и справа от 3 дробь положительна, между ними отрицательна.
  3. Включаем −2 и исключаем 3. Ответ [−2; 3).
