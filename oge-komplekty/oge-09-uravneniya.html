Линейные и квадратные уравнения

За экзаменационное задание предусмотрен 1 балл.

Типы заданий

  1. Линейное уравнение со скобками
  2. Линейное уравнение с дробями
  3. Неполное квадратное уравнение
  4. Полное квадратное уравнение

Линейное уравнение со скобками

Теория

Раскрой скобки и приведи подобные слагаемые. Из обеих частей можно вычитать одно и то же выражение и делить обе части на одно и то же ненулевое число.

Разбор примера

Реши 3(x − 2) = x + 4.

3x − 6 = x + 4, откуда 2x = 10 и x = 5.

Ответ: 5

Линейное уравнение с дробями

Теория

Умножение обеих частей на общий знаменатель сохраняет множество корней и превращает дробные коэффициенты в целые.

Разбор примера

Реши x3 + 12 = 56.

Умножаем уравнение на 6. Получаем 2x + 3 = 5, откуда x = 1.

Ответ: 1

Неполное квадратное уравнение

Теория

Если c = 0, вынеси x за скобки. Если b = 0, получи x² = d. При d > 0 два противоположных корня, при d = 0 один корень, при d < 0 действительных корней нет. При b = c = 0 для ax² = 0 корень равен нулю.

Разбор примера

Найди меньший корень 2x² − 18 = 0.

x² = 9. Корни −3 и 3, меньший −3.

Ответ: −3

Полное квадратное уравнение

Теория

Для ax² + bx + c = 0 при a ≠ 0 вычисли D = b² − 4ac. При D > 0 корни равны −b ± √D2a, при D = 0 есть один корень, при D < 0 корней нет. Для приведённого уравнения можно подобрать корни по сумме −b и произведению c.

Разбор примера

Найди больший корень x² − 5x + 6 = 0.

D = 25 − 24 = 1. Корни (5 − 1) ÷ 2 = 2 и (5 + 1) ÷ 2 = 3.

Ответ: 3
