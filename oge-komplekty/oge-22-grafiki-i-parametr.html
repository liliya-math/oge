Парабола с выколотой точкой и прямая y = kx

Что нужно знать

  • Исходная область определения
  • Касание
  • Потеря пересечения

Теория

Исходная область определения
Исключи корень знаменателя, даже если множитель сокращается. На графике отметь пустой кружок.
Касание
При равенстве y = kx и формулы параболы составь квадратное уравнение. Дискриминант 0 означает один алгебраический корень.
Потеря пересечения
Если при обычном пересечении одним из корней оказалась абсцисса выколотой точки, её исключаем. Проверь вторую точку отдельно.

Разбор примера

y = (x² + 1)(x − 2)2 − x. Построй график. При каких k прямая y = kx имеет ровно одну общую точку?

  1. На ОДЗ x ≠ 2 сокращаем множитель. График парабола y = −x² − 1 с выколотой точкой (2; −5).
  2. Из −x² − 1 = kx получаем x² + kx + 1 = 0. При D = k² − 4 = 0 остаётся одна точка: k = ±2. Их абсциссы ±1 допустимы.
  3. Кроме того, при k = −2,5 один из двух корней равен 2 и удаляется. Второй равен 0,5, он допустим. Других способов получить одну точку нет.
  4. Ответ. −2,5; −2; 2

Гипербола с дыркой и наклонная прямая

Что нужно знать

  • Сокращение и ОДЗ
  • Число пересечений

Теория

Сокращение и ОДЗ
Вынеси общий множитель из знаменателя и сократи его только на исходной области определения. x = 0 остаётся асимптотой, другой запрет даёт выколотую точку.
Число пересечений
Для y = kx решай уравнение по x и убирай запрещённый корень. Для y = m учти уровень асимптоты и уровень дырки.

Разбор примера

y = x − 2x(x − 2). Построй график. При каком k прямая y = kx имеет ровно одну общую точку?

  1. До сокращения выписываем ОДЗ x ≠ 0, x ≠ 2. Строим y = 1x с дыркой (2; 0,5).
  2. При k ≤ 0 уравнение kx² = 1 не имеет решений. При k > 0 есть симметричная пара корней. Ровно одна точка остаётся, когда x = 2 исключён, то есть k = 0,25.
  3. Ответ. 0,25

Сдвинутая гипербола и горизонталь

Что нужно знать

  • Сокращение и ОДЗ
  • Число пересечений

Теория

Сокращение и ОДЗ
Вынеси общий множитель из знаменателя и сократи его только на исходной области определения. x = 0 остаётся асимптотой, другой запрет даёт выколотую точку.
Число пересечений
Для y = kx решай уравнение по x и убирай запрещённый корень. Для y = m учти уровень асимптоты и уровень дырки.

Разбор примера

y = −1 + x − 2x(x − 2). Построй график. При каких m прямая y = m не имеет общих точек?

  1. До сокращения выписываем ОДЗ x ≠ 0, x ≠ 2. Строим y = 1x + (−1) с дыркой (2; −0,5).
  2. Горизонталь y = −1 является асимптотой. Любая другая горизонталь пересекает полную гиперболу ровно раз. Уровень y = −0,5 тоже исключён: его единственная точка выколота.
  3. Ответ. −1; −0,5

Три участка прямых

Что нужно знать

  • Каждая формула на своём участке
  • Граница и подсчёт

Теория

Каждая формула на своём участке
Сначала найди точки стыка. Для каждого x используй только формулу с подходящим условием.
Граница и подсчёт
Закрашивай точку при ≤ или ≥. Если две формулы ведут к одним координатам на стыке, пересечение считают один раз.

Разбор примера

y = x + 2, x < −1y = −x, −1 ≤ x ≤ 1
y = x − 2, x > 1 Построй график. При каких m будет ровно три пересечения с y = m?

  1. Строим три прямые на своих участках. Точки стыка (−1; 1) и (1; −1) принадлежат средней части.
  2. Вне промежутка уровней [−1; 1] пересечение одно. При m = ±1 пересечений два, поскольку у стыка совпадают предельные точки. Внутри (−1; 1) пересечений три.
  3. Ответ. (−1; 1)

Парабола и прямая по частям

Что нужно знать

  • Свои области
  • Критические уровни
  • Подсчёт на границах

Теория

Свои области
Построй каждую формулу только на её участке. Сверь ограничение при x = a и поставь открытый или закрытый кружок.
Критические уровни
Для горизонталей y = m сначала отметь высоту вершины, высоты границ и, если есть, горизонтальную асимптоту.
Подсчёт на границах
Считай пересечения отдельно между критическими уровнями и отдельно на каждом уровне. Возможна комбинация интервала и отдельного значения параметра.

Разбор примера

y = x² при x ≥ −2y = x + 5 при x < −2 Построй график. При каких m у y = m ровно две общие точки с графиком?

  1. Парабола имеет вершину (0; 0) и закрашенный край (−2; 4). Левая часть подходит при x < −2, её край (−2; 3) выколот.
  2. Считаем обе части отдельно. По уровням m число пересечений: (−∞; 0): 1; {0}: 2; (0; 3): 3; {3}: 2; (3; 4): 2; {4}: 2; (4; +∞): 1. Берём уровни с двумя пересечениями.
  3. Ответ. m = 0 или [3; 4]

Модуль снаружи квадратичной функции

Что нужно знать

  • Отражение
  • Подсчёт

Теория

Отражение
Для y = |f(x)| точки графика выше Ox сохраняются, а точки ниже Ox отражаются вверх.
Подсчёт
При m > 0 решай f(x) = m и f(x) = −m. При m = 0 считай общие нули один раз.

Разбор примера

y = |x² − 2|. Построй график. Каково максимальное число пересечений с y = m?

  1. Нули исходного трёхчлена x = −√(2) и x = √(2). Часть ниже Ox отражаем вверх.
  2. При 0 < m < 2 уравнения f(x) = m и f(x) = −m имеют по два решения. Итого четыре. При m = 2 внутренняя пара сливается в вершину.
  3. Ответ. 4

Квадратичная функция с линейным модулем

Что нужно знать

  • Смена знака аргумента
  • Вершины и стык

Теория

Смена знака аргумента
При x ≥ h получаем |x − h| = x − h. При x < h получаем h − x.
Вершины и стык
Посчитай вершину каждой параболы. Она влияет на ответ только если лежит на нужном участке. Стык на общей абсциссе считаем по одному разу.

Разбор примера

y = x² − 2|x − (0)|. Построй график. При каком m у y = m ровно три общие точки?

  1. Разбиваем на x < 0 и x ≥ 0. Получаем части парабол x² + 2x и x² − 2x.
  2. У обеих вершин уровень −1, в точке стыка уровень 0. При m = 0 совпадающая центральная точка учитывается один раз, и ещё по пересечению на каждой внешней ветви. Между −1 и 0 четыре пересечения, на −1 и выше 0 по два, ниже ни одного.
  3. Ответ. 0

Произведение модуля на линейное выражение

Что нужно знать

  • Раскрытие |x|
  • Разные вершины

Теория

Раскрытие |x|
При x ≥ 0 подставляем x, при x < 0 подставляем −x. Можно сначала раскрыть скобки: x|x| и a|x| рассматриваются на тех же двух участках.
Разные вершины
Левая и правая параболы могут быть направлены в разные стороны. Проверь высоту каждой вершины, затем уровень стыка.

Разбор примера

y = |x|(x + 1) − 3x. Построй график. При каких m будет ровно два пересечения с y = m?

  1. При x < 0 получаем −x² − 4x, при x ≥ 0 получаем x² − 2x. Вершина слева (−2; 4), справа (1; −1).
  2. На уровнях −1 и 4 касание одной части добавляет одну точку к единственному пересечению другой. Между этими уровнями три точки, включая случай m = 0, где x = 0 учитываем один раз. Снаружи по одной точке.
  3. Ответ. −1; 4

Дробь с модулем и сокращением

Что нужно знать

  • Факторизация до сокращения
  • График упрощённой формулы
  • Уровень без пересечений

Теория

Факторизация до сокращения
Выпиши все нули исходного знаменателя. При разложении можно использовать x² = |x|².
График упрощённой формулы
Раскрой модуль по знаку x и построй соответствующие ветви. В запрещённых точках ставь пустые кружки.
Уровень без пересечений
Чтобы линия не пересекала график, все её алгебраические точки пересечения должны отсутствовать или оказаться выколотыми.

Разбор примера

y = (x² − 2x)|x|x − 2. Построй график. При каком m горизонталь не имеет с ним общих точек?

  1. При x ≠ 2 сокращаем x − 2, получаем y = x|x|. Выколота точка (2; 4).
  2. Функция x|x| строго возрастает и принимает все действительные значения по одному разу. Поэтому исчезает только уровень y = 4.
  3. Ответ. 4

Разбор примера

y = 2|x| − 1|x| − 2x². Построй график. При каких k прямая y = kx не имеет общих точек?

  1. Знаменатель |x|(1 − 2|x|), поэтому x ≠ 0 и |x| ≠ 0,5. После сокращения y = −1|x|.
  2. При k = 0 точек нет, поскольку y < 0. При k ≠ 0 уравнение имеет одну точку: x и k противоположных знаков, |x| = 1/√|k|. Она запрещена при |k| = 4.
  3. Ответ. −4; 0; 4

Модуль разности прямой и гиперболы

Что нужно знать

  • ОДЗ и критические точки
  • Верхняя огибающая
  • Подсчёт секущих

Теория

ОДЗ и критические точки
Исключи x = 0. При x = ±a значения x/a и a/x равны, на этих границах ветви соединяются.
Верхняя огибающая
Выражение (|u − v| + u + v) : 2 равно большему из u и v: при u ≥ v получаем u, при u < v получаем v.
Подсчёт секущих
Сравни горизонталь с уровнями стыков и асимптотой. На уровне стыка две части дают одну точку.

Разбор примера

y = 12 (|x1 − 1x| + x1 + 1x). Построй график. При каких m у y = m ровно две общие точки с графиком?

  1. ОДЗ x ≠ 0. Выражение под знаком модуля x² − 11x меняет знак в точках −1, 0, 1.
  2. Исходная формула равна большему из x1 и 1x. На каждом участке выбираем верхнюю ветвь.
  3. При m ≥ 1 в положительной части две точки для m > 1 и одна при m = 1. При −1 < m < 0 в отрицательной части две точки, при m = −1 одна. При m < −1 и при 0 ≤ m < 1 точек нет.
  4. Ответ. (−1; 0) ∪ (1; +∞)
