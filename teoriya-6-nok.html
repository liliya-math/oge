Наименьшее общее кратное (НОК)

Кратные числа

Если одно натуральное число делится нацело на другое, то второе число называется делителем первого числа, а первое число называется кратным второго.

Кратные числа 3: 3; 6; 9; 12; 15; 18; 21; ... Кратные числа 5: 5; 10; 15; 20; 25; 30; ... Числа, которые есть в обоих рядах, называются общими кратными чисел 3 и 5.

15; 30; 45; …15;\ 30;\ 45;\ \ldots15; 30; 45; …
Почему так

Кратное числа получается, если это число умножить на натуральное число: 3, 3·2, 3·3 и так далее. Общее кратное - это число, которое попало в оба ряда кратных.

Наименьшее общее кратное (НОК)

Наименьшее натуральное число, которое делится на каждое из данных чисел, называется наименьшим общим кратным (НОК).

Общих кратных чисел 3 и 5 бесконечно много, наименьшее из них 15.

НОК(3;5)=15\text{НОК}(3;5)=15НОК(3;5)=15
Почему так

Общие кратные идут по порядку: 15, 30, 45, ... Самое маленькое из них и есть НОК. Больших общих кратных можно найти сколько угодно, а наименьшее только одно.

Как найти НОК через простые множители

Для нахождения НОК двух (и более) натуральных чисел нужно:

  1. разложить каждое из данных чисел на простые множители;
  2. выписать все множители одного из чисел и добавить все недостающие множители из других чисел, а затем перемножить их (каждый множитель берётся с наибольшим показателем из встречающихся в разложениях).

Найдём НОК(20;45)\text{НОК}(20;45)НОК(20;45):

20=2⋅2⋅520=2\cdot2\cdot520=2⋅2⋅5
45=3⋅3⋅545=3\cdot3\cdot545=3⋅3⋅5

Выписываем множители числа 20: 2, 2, 5. Из числа 45 добавляем недостающие: 3, 3. Множитель 5 уже есть.

НОК(20;45)=2⋅2⋅5⋅3⋅3=180\text{НОК}(20;45)=2\cdot2\cdot5\cdot3\cdot3=180НОК(20;45)=2⋅2⋅5⋅3⋅3=180

Если числа записаны со степенями, берут больший показатель:

НОК(23⋅5; 2⋅52)=23⋅52=200\text{НОК}(2^3\cdot5;\,2\cdot5^2)=2^3\cdot5^2=200НОК(23⋅5;2⋅52)=23⋅52=200
Почему так

Кратное числа должно содержать все его простые множители. Чтобы число делилось на каждое из данных, в нём должны быть все множители каждого из них, причём столько раз, сколько множитель встречается в самом «длинном» разложении. Лишних множителей не берём, тогда число получается наименьшим.

Как быстро найти НОК на практике

Практически НОК можно быстро найти так:

  1. проверяем, будет ли нацело делиться большее из чисел на остальные;
  2. если не делится, то большее число удваиваем и вновь проверяем, делится ли оно на остальные, и т. д.;
  3. процесс повторяем, т. е. если не делится, то утраиваем до тех пор, пока полученное число не будет делиться на остальные, а затем находим НОК.

Найдём НОК(4;6;9;12)\text{НОК}(4;6;9;12)НОК(4;6;9;12). Наибольшее из чисел 12. Оно делится на 4 и 6, но не делится на 9. Удваиваем: 24 не делится на 9. Утраиваем: 36 делится на каждое из чисел.

НОК(4;6;9;12)=36\text{НОК}(4;6;9;12)=36НОК(4;6;9;12)=36

Если большее число делится на все остальные, то оно и есть НОК. Например, НОК(6;10;30)=30\text{НОК}(6;10;30)=30НОК(6;10;30)=30.

Почему так

Общее кратное обязательно кратно самому большому из чисел, поэтому перебираем только его кратные: 12, 24, 36, ... Первое из них, которое делится на все остальные числа, и будет наименьшим общим кратным.
