4. Геометрическая прогрессия (bn) задана условиями: b1 = −4, bn+1 = 3bn. Найдите сумму первых четырёх её членов.
Ответ:
Ответы и ключевые точки для проверки (отрезать до раздачи).
  1. Ответ: 49. d = (17 − (−3)) : (7 − 2) = 4. От a7 до a15 восемь шагов: a15 = 17 + 8·4 = 49. Ключевая точка: Разность делится на число шагов 7 − 2 = 5. Шагов от седьмого до пятнадцатого члена 8. Проверка через первый член: −7 + 14·4 = 49.
  2. Ответ: 650. d = 3; a20 = 4 + 19·3 = 61. S20 = (4 + 61)·20 : 2 = 650. Ключевая точка: До 20-го члена 19 шагов, не 20. Делить на 2 в формуле суммы. Проверка: (2·4 + 19·3)·10 = 65·10 = 650.
  3. Ответ: 18. d = 0,3. Решаем −5,4 + 0,3(n − 1) < 0: n − 1 < 18, n < 19. Наибольшее натуральное n = 18. Ключевая точка: При n = 19 член равен 0, он не отрицательный: строгое неравенство. Проверка: a18 = −5,4 + 0,3·17 = −0,3 < 0, a19 = 0.
  4. Ответ: −160. q = 3, q4 = 81. S4 = −4·(81 − 1) : (3 − 1) = −4·40 = −160. Ключевая точка: Знак минус от первого члена. Проверка выпиской: −4 − 12 − 36 − 108 = −160.
