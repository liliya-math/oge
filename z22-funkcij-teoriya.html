Графики функций: теория и устный опрос

Задания 11 и 22 ОГЭ (22 — часть 2, 2 балла). Печать: 2 листа A4 теории и лист устного опроса. Определения и правила записаны близко к школьному учебнику (алгебра, 9 класс).

1. Функция и её график

Функцией называется зависимость переменной y от переменной x, при которой каждому значению x соответствует единственное значение y. Переменную x называют независимой переменной (аргументом), переменную y — зависимой переменной (значением функции).
Графиком функции называется множество всех точек координатной плоскости, абсциссы которых равны значениям аргумента, а ординаты — соответствующим значениям функции.

Точка (x₀; y₀) лежит на графике, если при подстановке получается верное равенство y₀ = f(x₀). Нули функции — значения x, при которых y = 0 (точки пересечения с осью Ox). Значение функции при x = 0 — точка пересечения с осью Oy. Область определения — все значения x, при которых формула имеет смысл (знаменатель не равен нулю).

2. Линейная функция

Линейной функцией называется функция вида y = kx + b, где x — независимая переменная, k и b — числа. Графиком линейной функции является прямая.
  • k — угловой коэффициент: при k > 0 функция возрастает (график идёт вверх слева направо), при k < 0 убывает.
  • b — ордината точки пересечения с осью Oy: точка (0; b). При b = 0 получаем y = kx — прямую, проходящую через начало координат.
  • Прямые y = k₁x + b₁ и y = k₂x + b₂ параллельны, если k₁ = k₂ и b₁ ≠ b₂.
  • Строят по двум точкам. Прямая через (x₁; y₁) и (x₂; y₂) имеет k = y₂ − y₁x₂ − x₁.

3. Квадратичная функция

Квадратичной функцией называется функция вида y = ax² + bx + c, где a, b, c — числа, a ≠ 0. Графиком является парабола.

Если y = a(x − x₀)² + y₀, вершина сразу видна: (x₀; y₀). От вершины при a = 1: на 1 вправо и влево — вверх на 1, на 2 — на 4, на 3 — на 9.

y = x² − 2x − 3 = (x − 1)² − 4

4. Обратная пропорциональность

Функция вида y = kx, где k ≠ 0, называется обратной пропорциональностью. Область определения — все числа, кроме 0. Графиком является гипербола.

При k > 0 ветви лежат в I и III четвертях, при k < 0 — во II и IV. Оси координат — асимптоты: график к ним приближается, но не пересекает. Для любой точки графика xy = k.

5. Модуль и графики с модулем

Модулем числа x называется само число x, если x ≥ 0, и противоположное ему число −x, если x < 0. |x| = x при x ≥ 0; |x| = −x при x < 0.
  • y = |f(x)|. Часть графика y = f(x), лежащая выше оси Ox (и на ней), остаётся; часть ниже оси Ox отражается симметрично относительно оси Ox вверх.
  • y = f(|x|). Правая часть (x ≥ 0) остаётся, левая — её симметричное отражение относительно оси Oy. Функция чётная.
  • Модуль вместе с x (например, y = x|x| − 2|x|). Раскрываем модуль отдельно при x ≥ 0 и при x < 0, получаем две формулы и строим каждую только на своём промежутке.

y = |x² − 4x|: пунктир — часть исходной параболы, которая отражена

6. Кусочно заданная функция

Функция может быть задана разными формулами на разных промежутках изменения аргумента. Каждую формулу строят только на её промежутке.

Если неравенство строгое (<, >), конец промежутка не принадлежит этому куску: рисуем выколотую точку (пустой кружок). Если нестрогое (≤, ≥), точка принадлежит графику: рисуем закрашенную. На стыке значения кусков могут не совпадать (разрыв).

7. Дробь и выколотая точка

  1. Разложить числитель и знаменатель на множители.
  2. До сокращения записать, при каких x знаменатель равен нулю: эти значения не входят в область определения.
  3. Сократить дробь.
  4. Построить график получившейся функции.
  5. Точки с исключёнными абсциссами выколоть; их ординаты найти по сокращённой формуле.

Пример. y = x² − 9x − 3 = (x − 3)(x + 3)x − 3 = x + 3 при x ≠ 3. График — прямая y = x + 3 без точки (3; 6).

8. Прямые y = m и y = kx: общие точки

Число общих точек графика функции y = f(x) и прямой y = m равно числу решений уравнения f(x) = m.

y = m — горизонтальная прямая. Двигаем её снизу вверх и считаем общие точки. Число точек меняется только в особых положениях: на уровне вершин, концов кусков (закрашенных и выколотых точек), выколотых точек. Каждое такое m проверяем отдельно. В ответ — значения m и промежутки (строгие и нестрогие неравенства).

y = kx — прямая через начало координат; вращаем её вокруг O. Особые положения: прямая проходит через выколотую точку (x₀; y₀), тогда k = y₀x₀; k = 0 (ось Ox); касание (D = 0).

y = x² − 2|x| − 3: прямая y = −3 имеет ровно три общие точки

9. Задание 11: соответствие графиков и формул

  • y = kx + b: k > 0 — вверх, k < 0 — вниз; b > 0 — пересекает Oy выше O, b < 0 — ниже.
  • y = ax² + bx + c: a > 0 — ветви вверх; c — точка пересечения с Oy; знак b определяют по вершине x₀ = −b2a.
  • y = kx: k > 0 — I и III четверти, k < 0 — II и IV.
  • Сначала определяем вид графика (прямая, парабола, гипербола), затем знаки; каждый признак исключает варианты. Ответ — цифры подряд без пробелов в порядке А, Б, В.

13Как строить график функции с x|x|?Раскрыть модуль отдельно при x ≥ 0 и при x < 0; каждую получившуюся формулу строить только на своём промежутке.

15Как найти ординату выколотой точки?Подставить её абсциссу в сокращённую формулу.

18Как найти k, при котором прямая y = kx проходит через точку (x₀; y₀)?k = y₀/x₀ (при x₀ ≠ 0).
19Как записать ответ в задании 22?Перечислить значения параметра и промежутки, проверив каждый конец (строгое или нестрогое неравенство).

Типичные ошибки (на что смотреть)

  1. Парабола или гипербола нарисована «от руки» без таблицы значений и без вершины.
  2. При x ≥ 0 и x < 0 обе формулы построены целиком, а не на своих промежутках.
  3. Выколотые точки не отмечены или поставлены по неупрощённой формуле.
  4. Особые значения m или k не проверены отдельно, берутся «на глаз».
  5. В ответе потеряна граница промежутка (строгое и нестрогое неравенство перепутаны).
