Памятка: алгоритм и оформление, неравенства (№20)

№20 оформляют полностью на бланке №2 (2 балла). В ответе — промежуток (или объединение промежутков). Ход решения должен быть виден эксперту.

Алгоритм решения неравенства

  1. Посмотри на вид. Линейное, квадратное, дробь, произведение, многочлен выше второй степени, система?
  2. Приведи к виду «выражение ∨ 0». Всё перенеси влево (слагаемые меняют знак). Если в знаменателе переменная, приведи к одной дроби. На выражение с неизвестным знаком не умножай.
  3. Если старший коэффициент отрицательный, умножь обе части на −1 и смени знак неравенства.
  4. Разложи на множители (корни по D или Виета, группировка, вынесение за скобку).
  5. Отметь нули на оси: нули знаменателя всегда выколоты; нули числителя закрашены при ≥, ≤ и выколоты при >, <.
  6. Расставь знаки справа налево. Через корень чётной кратности знак не меняется.
  7. Выбери промежутки нужного знака, отдельно проверь изолированные точки.
  8. Проверь подстановкой одного числа из ответа и одного не из ответа. Запиши ответ промежутками.

Какой способ выбрать

Множитель (x − a)²Знак в a не меняется; при ≥, ≤ проверь точку a отдельно.

Формулы. Корни ax² + bx + c = 0: x = (−b ± √D)/(2a), D = b² − 4ac. По теореме Виета для x² + px + q: x₁ + x₂ = −p, x₁x₂ = q. Разложение: a(x − x₁)(x − x₂). Если D < 0 и a > 0, то ax² + bx + c > 0 при любом x.

Что снимает баллы

  • Не изменён знак при умножении или делении на отрицательное число.
  • Умножение на выражение с переменной без учёта знака (особенно в дробях).
  • Нули знаменателя не выколоты; квадратные скобки у выколотых точек.
  • Потеряны изолированная точка или один из промежутков; вместо пересечения записано объединение.
  • Только ответ без хода решения: 0 баллов.
  • Верный ход, но описка или вычислительная ошибка: 1 балл из 2.

Образец записи (№20)

Задача. Решите неравенство x² − 2x − 8x − 1 > 0.

Решение. Разложим числитель на множители: x² − 2x − 8 = 0, по теореме Виета x₁ = 4, x₂ = −2, значит x² − 2x − 8 = (x − 4)(x + 2).

Получаем (x − 4)(x + 2)x − 1 > 0. Решим методом интервалов. Нули числителя: −2 и 4, нуль знаменателя: 1. Неравенство строгое, поэтому все точки выколоты.

При x = 5 дробь равна 9 · 7 / 4 > 0, знак «+». Справа налево знаки чередуются: на (1; 4) «−», на (−2; 1) «+», на (−∞; −2) «−».

Нужен знак «+»: (−2; 1) и (4; +∞).

Проверка. x = 0: (0 − 0 − 8)/(0 − 1) = 8 > 0, верно, 0 лежит в (−2; 1). x = 2: (4 − 4 − 8)/(2 − 1) = −8 < 0, неверно, число 2 в ответ не входит.

Ответ: (−2; 1) ∪ (4; +∞).

Образец для системы. 3x − 1 > 5x² − 9 ≤ 0 Первое: 3x > 6, x > 2, то есть (2; +∞). Второе: x² − 9 = (x − 3)(x + 3) ≤ 0, корни −3 и 3, ветви вверх, значит [−3; 3]. Общая часть: (2; 3]. Число 3 входит (второе неравенство нестрогое), число 2 не входит. Ответ: (2; 3].
Где эксперт ищет баллы: 1) неравенство верно преобразовано к виду «выражение ∨ 0»; 2) многочлены разложены на множители; 3) нули отмечены, знаки определены (метод интервалов); 4) выбраны нужные промежутки, учтены скобки и изолированные точки; 5) записан верный ответ. Описка при верном ходе — 1 балл из 2. Точные критерии смотрите в актуальных материалах ФИПИ.
