Задача A. Арифметическая прогрессия: разность по двум членам и далёкий член

Условие. Арифметическая прогрессия (an) задана условиями: a4 = 5, a9 = −10. Найдите a20.

Что видим. Арифметическая прогрессия, даны два члена с номерами 4 и 9, надо найти член с номером 20. Первого члена нет, но он и не нужен: между a4 и a9 ровно 5 шагов, и каждый шаг прибавляет d.

Правило. Разность прогрессии: d = (am − ak) : (m − k). Любой член через соседний известный: am = ak + (m − k)·d.

Алгоритм. найти число шагов между известными номерами → найти d → посчитать число шагов до нужного номера → прибавить

Решение по шагам.

  1. Между a4 и a9 шагов: 9 − 4 = 5. Прогрессия изменилась на a9 − a4 = −10 − 5 = −15.
  2. Разность: d = −15 : 5 = −3.
  3. От a9 до a20 шагов: 20 − 9 = 11. Значит a20 = a9 + 11d = −10 + 11·(−3) = −10 − 33 = −43.

Ответ: −43.

Проверка. Найдём a1 = a4 − 3d = 5 + 9 = 14. Тогда a20 = 14 + 19·(−3) = 14 − 57 = −43. Совпало.

Ловушка. Разность членов делят на разность номеров (9 − 4 = 5), а не на сам номер 9 и не на 4. Ещё одна частая ошибка: от a9 до a20 шагов 11, а не 10 и не 12.

Задача B. Арифметическая прогрессия: сумма, когда первый член не дан

Условие. В арифметической прогрессии a6 = 14, a10 = 26. Найдите сумму первых 15 её членов.

Что видим. Нужна сумма a1…a15, но ни a1, ни a15 не даны. Даны два члена, из них находим d, потом a1 и a15, и только потом применяем формулу суммы.

Правило. Сумма первых n членов: Sn = (a1 + an)·n : 2. Формула n-го члена: an = a1 + (n − 1)d.

Алгоритм. d по двум членам → первый член → последний член суммы → формула суммы

Решение по шагам.

  1. d = (a10 − a6) : (10 − 6) = (26 − 14) : 4 = 3.
  2. a1 = a6 − 5d = 14 − 15 = −1 (от a1 до a6 пять шагов).
  3. a15 = a1 + 14d = −1 + 42 = 41.
  4. S15 = (−1 + 41)·15 : 2 = 40·15 : 2 = 300.

Ответ: 300.

Проверка. Формула an = a1 + (n − 1)d = 3n − 4. Проверим: a6 = 18 − 4 = 14, a10 = 30 − 4 = 26. Сумма 3(1 + 2 + … + 15) − 4·15 = 3·120 − 60 = 300.

Ловушка. От a1 до a6 пять шагов, поэтому a1 = a6 − 5d, а не a6 − 6d. И не забыть разделить на 2 в формуле суммы: без деления получится 600.

Задача C. Арифметическая прогрессия: сколько членов отрицательные

Условие. Сколько отрицательных членов в арифметической прогрессии −8,6; −8,4; −8,2; …?

Что видим. Прогрессия возрастает (каждый следующий член больше на 0,2), начинается с −8,6. Члены отрицательны, пока не дойдём до нуля или до положительных чисел. Нужно найти последний номер, при котором an < 0.

Правило. an = a1 + (n − 1)d. Неравенство an < 0 решаем относительно n, номер n — натуральное число.

Алгоритм. найти d → записать a_n < 0 → решить неравенство → взять наибольшее натуральное n (строго меньше!)

Решение по шагам.

  1. d = −8,4 − (−8,6) = 0,2; a1 = −8,6.
  2. an = −8,6 + 0,2(n − 1) < 0, значит 0,2(n − 1) < 8,6, то есть n − 1 < 43, n < 44.
  3. Наибольшее натуральное n < 44 — это 43. Отрицательных членов 43.

Ответ: 43.

Проверка. a43 = −8,6 + 0,2·42 = −8,6 + 8,4 = −0,2 < 0. А a44 = −8,6 + 0,2·43 = 0: ноль не отрицательный. Значит ответ 43.

Ловушка. Ответ 44 — частая ошибка: при n = 44 член равен нулю, а ноль не является отрицательным числом. Неравенство строгое: n < 44, а не n ≤ 44. Ещё один промах: n − 1 < 43 и забыть прибавить единицу, получить 42.

Задача D. Геометрическая прогрессия: сумма первых членов, первый член отрицательный

Условие. Геометрическая прогрессия (bn) задана условиями: b1 = −6, bn+1 = 2bn. Найдите сумму первых пяти её членов.

Что видим. Рекуррентное задание: каждый следующий член вдвое больше предыдущего, значит q = 2. Первый член отрицательный, поэтому и сумма будет отрицательной.

Правило. Sn = b1(qn − 1) : (q − 1), q ≠ 1. Из условия bn+1 = qbn знаменатель читается сразу.

Алгоритм. прочитать q из рекуррентной формулы → посчитать q^n → подставить в формулу суммы

Решение по шагам.

  1. Из условия bn+1 = 2bn получаем q = 2.
  2. q5 = 32, q5 − 1 = 31, q − 1 = 1.
  3. S5 = −6·31 : 1 = −186.

Ответ: −186.

Проверка. Выпишем члены: −6; −12; −24; −48; −96. Сумма −6 − 12 − 24 − 48 − 96 = −186.

Ловушка. Знак: b1 отрицателен, поэтому ответ отрицательный. Не путайте q5 = 32 с 5q = 10. И не берите в формулу b5 вместо b1.

Задача E. Практическая задача на арифметическую прогрессию: места в зале

Условие. В зрительном зале 18 рядов: в первом ряду 14 мест, а в каждом следующем на 2 места больше, чем в предыдущем. Сколько всего мест в зале?

Что видим. «На 2 места больше, чем в предыдущем» значит арифметическая прогрессия с a1 = 14 и d = 2. Всего мест в зале — это сумма первых 18 членов.

Правило. Sn = (a1 + an)·n : 2, an = a1 + (n − 1)d.

Алгоритм. записать, что дано (a_1, d, n) → найти последний ряд → применить формулу суммы

Решение по шагам.

  1. a18 = 14 + 17·2 = 48 (до 18-го ряда 17 шагов).
  2. S18 = (14 + 48)·18 : 2 = 62·9 = 558.

Ответ: 558.

Проверка. Вторая формула: S18 = (2·14 + 17·2)·18 : 2 = 62·9 = 558. Совпало.

Ловушка. До 18-го ряда 17 прибавлений: a18 = a1 + 17d, а не 18d. Ещё ошибка: ответом записать число мест в последнем ряду (48) вместо суммы по всем рядам.
