Корень из произведения и дроби

Корень из произведения

Корень из произведения неотрицательных множителей равен произведению корней из этих множителей.

ab=a⋅b\sqrt{ab}=\sqrt{a}\cdot\sqrt{b}ab​=a​⋅b​,   a≥0,  b≥0\;a\ge 0,\; b\ge 0a≥0,b≥0

Правило верно для любого числа множителей: abc=abc\sqrt{abc}=\sqrt{a}\sqrt{b}\sqrt{c}abc​=a​b​c​.

Например: 36⋅25=36⋅25=6⋅5=30\sqrt{36\cdot 25}=\sqrt{36}\cdot\sqrt{25}=6\cdot 5=3036⋅25​=36​⋅25​=6⋅5=30; 0,04⋅81=0,2⋅9=1,8\sqrt{0{,}04\cdot 81}=0{,}2\cdot 9=1{,}80,04⋅81​=0,2⋅9=1,8.

Почему так

Оба числа ab\sqrt{ab}ab​ и ab\sqrt{a}\sqrt{b}a​b​ неотрицательны, и квадрат каждого равен ababab. Значит, они равны.

Корень из дроби

Корень из дроби равен корню из числителя, делённому на корень из знаменателя.

ab=ab\sqrt{\dfrac{a}{b}}=\dfrac{\sqrt{a}}{\sqrt{b}}ba​​=b​a​​,   a≥0,  b>0\;a\ge 0,\; b>0a≥0,b>0

Например: 4964=78\sqrt{\dfrac{49}{64}}=\dfrac{7}{8}6449​​=87​; 279=259=53\sqrt{2\dfrac{7}{9}}=\sqrt{\dfrac{25}{9}}=\dfrac{5}{3}297​​=925​​=35​.

Почему так

Оба числа неотрицательны, и квадрат каждого равен ab\dfrac{a}{b}ba​.

Когда это удобно

Свойства применяют, чтобы вычислять корни из больших чисел, разложив их на множители, являющиеся точными квадратами.

1600⋅0,09=40⋅0,3=12\sqrt{1600\cdot 0{,}09}=40\cdot 0{,}3=121600⋅0,09​=40⋅0,3=12.

50⋅2=100=10\sqrt{50}\cdot\sqrt{2}=\sqrt{100}=1050​⋅2​=100​=10.

753=25=5\dfrac{\sqrt{75}}{\sqrt{3}}=\sqrt{25}=53​75​​=25​=5.

Нельзя применять правило к отрицательным числам: выражение (−4)(−9)=36=6\sqrt{(-4)(-9)}=\sqrt{36}=6(−4)(−9)​=36​=6 верно, а запись −4⋅−9\sqrt{-4}\cdot\sqrt{-9}−4​⋅−9​ смысла не имеет.

Корень из суммы

Для суммы и разности такого правила нет.

a+b≠a+b\sqrt{a+b}\ne\sqrt{a}+\sqrt{b}a+b​=a​+b​

Проверка: 9+16=5\sqrt{9+16}=59+16​=5, но 9+16=7\sqrt{9}+\sqrt{16}=79​+16​=7.
