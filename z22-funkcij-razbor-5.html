Разбор 5 задач повышенной сложности · графики функций (№22)

Каждая задача: условие, что видим, правило, алгоритм, решение с таблицей и рисунком, проверка, ответ и типичная ловушка. Задание 22 — часть 2 (бланк №2), 2 балла: оценивается и график, и найденные значения параметра.

Задача 1. Раскрытие модуля: две параболы

Условие. Постройте график функции y = x|x| − 2|x| − 4x. Определите, при каких значениях m прямая y = m имеет с графиком ровно две общие точки.

Что видим. Функция с модулем, умноженным на x. Модуль нужно раскрыть: получатся две формулы — для x ≥ 0 и для x < 0, то есть график составлен из частей двух парабол. Прямая y = m горизонтальна; нужно найти m, при которых общих точек ровно две.

Правило. Модуль числа: |x| = x при x ≥ 0 и |x| = −x при x < 0. Число общих точек графика функции y = f(x) и прямой y = m равно числу решений уравнения f(x) = m.

Алгоритм.

  1. Раскрыть модуль отдельно при x ≥ 0 и при x < 0.
  2. Каждую формулу привести к виду a(x − x₀)² + y₀ и построить на своём промежутке.
  3. Двигать прямую y = m снизу вверх, считать общие точки.
  4. Проверить особые значения m (ординаты вершин) отдельно.
  5. Записать ответ.

Решение.

  1. При x ≥ 0: |x| = x, поэтому y = x² − 2x − 4x = x² − 6x = (x − 3)² − 9. Парабола, ветви вверх, вершина (3; −9), нули 0 и 6. Строим при x ≥ 0.
  2. При x < 0: |x| = −x, поэтому y = −x² + 2x − 4x = −x² − 2x = −(x + 1)² + 1. Парабола, ветви вниз, вершина (−1; 1), нули −2 и 0. Строим при x < 0 (точка (0; 0) уже есть у первой части).
  3. Таблица значений:
    x−3−2−101234567
    y−3010−5−8−9−8−507
  4. Двигаем прямую y = m снизу вверх. При m < −9 — одна точка (левая часть); при m = −9 — две (вершина правой части и точка левой); при −9 < m < 1 — три; при m = 1 — две (вершина левой части и точка правой); при m > 1 — одна (правая ветвь).

Штриховые линии — особые положения прямой

Проверка. m = 1: левая часть даёт вершину (−1; 1), правая — уравнение x² − 6x = 1 с корнями разных знаков (произведение корней −1 < 0), подходит один положительный: всего две точки. m = −9: правая часть — вершина (3; −9); в левой части уравнение x² + 2x − 9 = 0 имеет один отрицательный корень: всего две точки.

Ответ: m = −9; m = 1.

Ловушка. Строят обе параболы целиком, а не на своих промежутках. Теряют одну из двух вершин. Считают, что при m = 0 точек две; на самом деле их три: (−2; 0), (0; 0) и (6; 0).

Задача 2. Дробь: сокращение и выколотые точки

Условие. Постройте график функции y = x⁴ − 20x² + 64(x − 2)(x + 4). Определите, при каких значениях m прямая y = m имеет с графиком ровно одну общую точку.

Что видим. Дробь: в числителе многочлен четвёртой степени без нечётных степеней, в знаменателе произведение двух скобок. Нужно разложить числитель, сократить и построить параболу с двумя выколотыми точками. Значения m, при которых одна из двух точек пересечения выколота, дают ровно одну общую точку.

Правило. Дробь определена, когда знаменатель не равен нулю; область определения записывают до сокращения. Дробь можно сократить на общий множитель: значения исходной и сокращённой функций совпадают везде, кроме точек, где знаменатель исходной дроби равен нулю.

Алгоритм.

  1. Записать область определения (знаменатель не равен нулю).
  2. Разложить числитель на множители и сократить дробь.
  3. Построить параболу и выколоть точки с исключёнными абсциссами.
  4. Найти m: вершина и значения, при которых одна из двух общих точек выколота.
  5. Записать ответ.

Решение.

  1. Область определения: (x − 2)(x + 4) ≠ 0, то есть x ≠ 2 и x ≠ −4.
  2. Числитель: пусть t = x², тогда t² − 20t + 64 = 0, t = 4 или t = 16. Значит, x⁴ − 20x² + 64 = (x² − 4)(x² − 16) = (x − 2)(x + 2)(x − 4)(x + 4).
  3. Сокращаем на (x − 2)(x + 4): y = (x + 2)(x − 4) = x² − 2x − 8 = (x − 1)² − 9, где x ≠ 2, x ≠ −4.
  4. Парабола, ветви вверх, вершина (1; −9), нули −2 и 4, точка (0; −8). Выколотые точки находим по сокращённой формуле: при x = 2 получаем y = −8, при x = −4 получаем y = 16. Выколоты (2; −8) и (−4; 16).
  5. Таблица (звёздочка — выколотая точка):
    x−5−4−3−2−10123456
    y27(16)*70−5−8−9(−8)*−50716
  6. Прямая y = m: при m < −9 общих точек нет; при m = −9 — одна (вершина); при m > −9 — две точки x = 1 ± √(m + 9). Но одна из двух точек может оказаться выколотой. Если m = −8, корни x = 2 (выколота) и x = 0: остаётся одна точка. Если m = 16, корни x = −4 (выколота) и x = 6: тоже одна.

Штриховые линии — особые положения прямой

Проверка. m = −8: x² − 2x − 8 = −8, корни 2 и 0; первый выколот, второй допустим. m = 16: корни −4 и 6; первый выколот. Вершина не выколота (1 не равно 2 и −4).

Ответ: m = −9; m = −8; m = 16.

Ловушка. Записывают только m = −9. Не замечают, что выколотая точка забирает одну из двух общих точек. Считают ординаты выколотых точек по неупрощённой формуле (там получается 0/0). Путают знак абсциссы при x = −4.

Задача 3. Гипербола с модулем и прямая y = kx

Условие. Постройте график функции y = 2|x| − 1|x| − 2x². Определите, при каких значениях k прямая y = kx не имеет с графиком ни одной общей точки.

Что видим. Дробь с модулем; знаменатель раскладывается на множители. Прямая y = kx проходит через начало координат. Нужно найти k, при которых общих точек нет.

Правило. Модуль: |x| = x при x ≥ 0, |x| = −x при x < 0; кроме того, x² = |x|². Область определения записывают до сокращения; после сокращения точки, не входящие в область определения, выкалывают.

Алгоритм.

  1. Записать область определения.
  2. Раскрыть модуль, сократить, построить две ветви гиперболы.
  3. Выколоть точки и найти их координаты.
  4. Провести y = kx через начало координат: рассмотреть k = 0, k > 0, k < 0.
  5. Найти k, при которых единственная общая точка выколота.
  6. Записать ответ.

Решение.

  1. Область определения: |x| − 2x² = |x|(1 − 2|x|) ≠ 0, то есть x ≠ 0 и x ≠ ±12.
  2. Числитель 2|x| − 1 = −(1 − 2|x|). Сокращаем на (1 − 2|x|): y = −1|x|.
  3. При x > 0: y = −1x (гипербола в IV четверти); при x < 0: y = 1x (в III четверти). График симметричен относительно оси Oy. Выколоты точки с x = ±12: y = −2, то есть (0,5; −2) и (−0,5; −2).
  4. Таблица для x > 0 (левая часть симметрична):
    x > 00,250,5124
    y−4(−2)*−1−0,5−0,25
  5. Прямая y = kx. При k = 0 это ось Ox: весь график лежит ниже оси (y < 0), общих точек нет. При k > 0 прямая проходит по I и III четвертям, общую точку может иметь только левая ветвь: kx = 1x, x² = 1k, x = −1√k — одна точка. Она выколота, если x = −12, то есть k = 4: тогда общих точек нет. При k < 0 общую точку может иметь только правая ветвь: x = 1√(−k); она выколота при k = −4.

Штриховые линии — особые положения прямой

Проверка. k = 4: прямая y = 4x проходит через (−0,5; −2): 4 · (−0,5) = −2, и это единственная её точка пересечения с графиком. Симметрично для k = −4.

Ответ: k = −4; k = 0; k = 4.

Ловушка. Теряют k = 0. Берут только положительные k. Не замечают, что единственная общая точка выколота. Путают «нет общих точек» и «одна общая точка».

Задача 4. Кусочная функция: выколотая и закрашенная точки

Условие. Постройте график функции y = 3 − x при x < 1x² − 4x + 1 при x ≥ 1. Определите, при каких значениях m прямая y = m имеет с графиком ровно одну общую точку.

Что видим. Кусочная функция: на каждом промежутке своя формула, в точке x = 1 график разрывается. Нужно аккуратно обращаться с концами: выколотый и закрашенный.

Правило. Каждую формулу строят только на своём промежутке. При строгом неравенстве (<, >) конец промежутка выкалывают, при нестрогом (≤, ≥) точка принадлежит графику.

Алгоритм.

  1. Построить каждую формулу на своём промежутке.
  2. Определить, какие концы выколоты, какие закрашены; найти их ординаты.
  3. Двигать прямую y = m, считать точки на каждом промежутке и в особых значениях.
  4. Записать ответ с учётом строгих и нестрогих неравенств.

Решение.

  1. При x < 1: y = 3 − x — прямая, убывает. Если подставить x = 1, получится 2, но x < 1 строго, поэтому точка (1; 2) выколота. На этой части y > 2.
    x−100,51
    y432,5(2)*
  2. При x ≥ 1: y = x² − 4x + 1 = (x − 2)² − 3. Парабола, вершина (2; −3) входит в эту часть (2 ≥ 1). Точка (1; −2) принадлежит графику (закрашена).
    x12345
    y−2−3−216
  3. Двигаем прямую y = m. При m < −3 точек нет; при m = −3 — одна (вершина); при −3 < m ≤ −2 — две (оба корня x = 2 ± √(m + 3) не меньше 1); при −2 < m ≤ 2 — одна (только правая ветвь параболы; прямая такие значения не принимает); при m > 2 — две (парабола и прямая).

Штриховые линии — особые положения прямой

Проверка. m = −2: уравнение (x − 2)² − 3 = −2 даёт x = 1 и x = 3, оба принадлежат участку x ≥ 1: две точки, значит m = −2 не подходит. m = 2: прямая в точку (1; 2) не попадает (выколота), остаётся одна точка параболы: подходит.

Ответ: m = −3 и −2 < m ≤ 2.

Ловушка. Включают m = −2 (там две точки). Не включают m = 2 («выколотая точка не считается», значит значение подходит). Теряют вершину m = −3.

Задача 5. Модуль квадратного трёхчлена и прямая y = kx

Условие. Постройте график функции y = |x² − 4x|. Определите, при каких значениях k прямая y = kx имеет с графиком ровно одну общую точку.

Что видим. Модуль квадратного трёхчлена (часть параболы ниже оси Ox отражается вверх) и прямая через начало координат. Точка O(0; 0) принадлежит графику, значит, прямая y = kx всегда имеет с графиком общую точку O. Для «ровно одной» нужно, чтобы других общих точек не было.

Правило. График y = |f(x)|: часть графика y = f(x), лежащая выше оси Ox, остаётся, часть ниже оси Ox отражается симметрично относительно оси Ox. Число общих точек графика и прямой равно числу решений уравнения f(x) = kx.

Алгоритм.

  1. Построить y = x² − 4x и отразить часть ниже оси Ox вверх.
  2. Заметить, что O(0; 0) принадлежит графику при любом k.
  3. Решить f(x) = kx на каждом участке, отобрать допустимые корни.
  4. Посчитать общие точки при разных k; записать ответ.

Решение.

  1. y = x² − 4x = x(x − 4) — парабола с нулями 0 и 4, вершина (2; −4). При 0 < x < 4 значения отрицательны, эту часть отражаем вверх: y = −x² + 4x, вершина (2; 4). При x ≤ 0 и при x ≥ 4 график — часть исходной параболы y = x² − 4x.
  2. Таблица значений:
    x−2−10123456
    y12503430512
  3. Решаем f(x) = kx на каждом участке. При x ≤ 0 и при x ≥ 4: x² − 4x = kx, x(x − 4 − k) = 0, откуда x = 0 или x = 4 + k. При 0 < x < 4: −x² + 4x = kx, откуда x = 4 − k. Корень x = 0 даёт точку O при любом k.
  4. Какие корни допустимы. x = 4 + k подходит, если k + 4 < 0, то есть k < −4 (на левой части), или если k + 4 ≥ 4, то есть k ≥ 0 (на правой части). x = 4 − k подходит, если 0 < 4 − k < 4, то есть 0 < k < 4.
  5. Считаем общие точки: k < −4 — две (O и ещё одна); −4 ≤ k < 0 — одна (только O); k = 0 — две (O и (4; 0)); 0 < k < 4 — три (O и две других); k ≥ 4 — две.

Штриховые линии — особые положения прямой

Проверка. k = −4: при x ≤ 0 имеем x² − 4x = −4x, x² = 0, x = 0; на остальных участках корней нет. Общая точка одна — O. k = 0: прямая y = 0 пересекает график в точках (0; 0) и (4; 0): две точки.

Ответ: −4 ≤ k < 0.

Ловушка. Забывают, что O всегда принадлежит графику. Включают k = 0 (там две точки: O и (4; 0)). Не включают k = −4 (общая точка одна — O).

Ответы. 1) m = −9; m = 1 · 2) m = −9; m = −8; m = 16 · 3) k = −4; k = 0; k = 4 · 4) m = −3 и −2 < m ≤ 2 · 5) −4 ≤ k < 0.
