Квадратные уравнения: теория и устный опрос

№9 (часть 1) и №20 (часть 2) ОГЭ. Печать: 2 страницы A4.

Теория

1. Определение. Квадратным уравнением называют уравнение вида ax² + bx + c = 0, где x — переменная, a, b и c — некоторые числа, причём a ≠ 0. Числа a, b, c называют коэффициентами: a — первый (старший) коэффициент, b — второй коэффициент, c — свободный член. Уравнение, в котором b = 0 или c = 0, называют неполным квадратным уравнением. Пример: в уравнении 2x² − 5x + 3 = 0 имеем a = 2, b = −5, c = 3. Прежде чем применять формулы, уравнение приводят к виду ax² + bx + c = 0: раскрывают скобки и переносят все слагаемые в левую часть.
2. Неполные квадратные уравнения. 1) Уравнение ax² + c = 0 приводят к виду x² = −c/a. Если −c/a > 0, то у уравнения два корня: x = ±√(−c/a); если −c/a < 0, корней нет. Пример: x² − 49 = 0, x² = 49, x = 7 или x = −7. 2) Уравнение ax² + bx = 0 решают разложением на множители: x(ax + b) = 0. Произведение равно нулю, когда хотя бы один из множителей равен нулю, поэтому x = 0 или x = −b/a. Пример: x² + 6x = 0, x(x + 6) = 0, x = 0 или x = −6. Обе части на x делить нельзя: потеряется корень 0. 3) Уравнение ax² = 0 имеет единственный корень x = 0.
3. Дискриминант и формула корней. Выражение D = b² − 4ac называют дискриминантом квадратного уравнения. Если D > 0, уравнение имеет два корня: x₁,₂ = (−b ± √D) / (2a). Если D = 0, уравнение имеет один корень: x = −b / (2a). Если D < 0, уравнение не имеет действительных корней. Пример: 2x² − 3x − 5 = 0; D = 9 + 40 = 49; x = (3 ± 7) / 4; x₁ = 2,5; x₂ = −1.
4. Чётный второй коэффициент. Если b = 2k, удобно пользоваться дискриминантом D₁ = k² − ac. Тогда корни находят по формуле x = (−k ± √D₁) / a. Пример: x² − 6x + 5 = 0; k = −3; D₁ = 9 − 5 = 4; x = 3 ± 2; x₁ = 5, x₂ = 1.
5. Теорема Виета. Если x₁ и x₂ — корни приведённого квадратного уравнения x² + px + q = 0, то x₁ + x₂ = −p и x₁ · x₂ = q. Для уравнения ax² + bx + c = 0: x₁ + x₂ = −b/a, x₁ · x₂ = c/a. Верна и обратная теорема: если числа x₁ и x₂ таковы, что x₁ + x₂ = −p и x₁ · x₂ = q, то они — корни уравнения x² + px + q = 0. Пример: x² − 7x + 12 = 0; сумма корней 7, произведение 12; корни 3 и 4. Теоремой Виета подбирают целые корни и проверяют найденные.
6. Разложение на множители. Если x₁ и x₂ — корни квадратного трёхчлена ax² + bx + c, то ax² + bx + c = a(x − x₁)(x − x₂). Пример: x² − 5x + 6 = (x − 2)(x − 3). Это разложение используют для сокращения дробей и для решения уравнений более высоких степеней.
7. Уравнения, сводящиеся к квадратным (№20). а) Замена переменной. В уравнении (x² − 3x)² − 2(x² − 3x) − 8 = 0 вводят t = x² − 3x, решают t² − 2t − 8 = 0, затем решают уравнение x² − 3x = t для каждого найденного t. Биквадратное уравнение ax⁴ + bx² + c = 0 решают заменой t = x², где t ≥ 0. б) Способ группировки: x³ + 3x² − 4x − 12 = x²(x + 3) − 4(x + 3) = (x + 3)(x² − 4). в) Дробно-рациональные уравнения. Дробь равна нулю, когда числитель равен нулю, а знаменатель не равен нулю. Сначала находят значения x, при которых знаменатели обращаются в нуль (их исключают из ответа), затем умножают обе части на общий знаменатель, решают получившееся уравнение и проверяют корни. Корень, обращающий знаменатель в нуль, называют посторонним.
8. Системы с квадратным уравнением. Из линейного уравнения системы выражают одну переменную через другую и подставляют в квадратное уравнение. Решением системы называют пару чисел (x; y); ответ записывают парами.

Вопросы для устного опроса

Учитель задаёт вопрос, ответ сверяет с правой колонкой.

№ВопросОтвет
1Какое уравнение называют квадратным? Что значит условие a ≠ 0?Уравнение вида ax² + bx + c = 0. При a = 0 членов с x² нет, уравнение становится линейным.
2Назовите коэффициенты уравнения 2x² − 5x + 3 = 0.a = 2, b = −5, c = 3.
3Решите устно x² − 49 = 0 и x² + 49 = 0.x = ±7; у второго корней нет (x² не может быть отрицательным).
4Решите устно x² + 6x = 0. Почему нельзя поделить обе части на x?x(x + 6) = 0; x = 0 или x = −6. При делении на x теряется корень 0.
5Запишите формулу дискриминанта. Сколько корней при D > 0, D = 0, D < 0?D = b² − 4ac. Два корня; один корень; корней нет.
6Найдите дискриминант 3x² − 4x − 4 и корни.D = 16 + 48 = 64; x = (4 ± 8) / 6; x = 2 и x = −2/3.
7Сколько корней у x² − 4x + 5 = 0?D = 16 − 20 = −4 < 0; корней нет.
8Сформулируйте теорему Виета для x² + px + q = 0.x₁ + x₂ = −p, x₁ · x₂ = q.
9Не решая, подберите корни x² − 7x + 12 = 0.Сумма 7, произведение 12: корни 3 и 4.
10Чему равна сумма корней уравнения 2x² − 6x + 1 = 0?По Виету −b/a = 6/2 = 3 (корни действительные, D = 28 > 0).
11Как привести (x − 1)(x + 2) = 4 к виду ax² + bx + c = 0?Раскрыть скобки: x² + x − 2 = 4; перенести: x² + x − 6 = 0.
12Как решают биквадратное уравнение x⁴ − 5x² + 4 = 0?Замена t = x², t ≥ 0: t² − 5t + 4 = 0; t = 1 или 4; x = ±1, ±2.
13Когда дробь равна нулю? Решите (x² − x − 6)/(x − 3) = 0.Когда числитель равен нулю, а знаменатель нет. x = 3 или x = −2; x = 3 посторонний; ответ −2.
14Что обязательно записывают в решении №20?ОДЗ (если есть дробь), замену или преобразование, квадратное уравнение, его решение, отбор корней, ответ (все корни).
