Пробники ОГЭ

Обновление сервера кабинета до версии 7.14 включает передачу результатов по заданиям в новый раздел.

  1. Нажми «Скопировать код».
  2. В Google Таблице кабинета открой «Расширения → Apps Script».
  3. Замени содержимое основного файла скопированным кодом и сохрани.
  4. «Развернуть → Управление развёртываниями → карандаш → Новая версия → Развернуть». Сохрани прежний адрес веб-приложения.
  5. Вернись в тесты и обнови страницу.

Запускать setup или setupDz не нужно. Ученики, домашка и прежние результаты сохраняются.
