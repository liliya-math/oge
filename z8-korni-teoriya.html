Корни: теория и устный опрос

Задание 8 ОГЭ, часть 1. Печать: 2 страницы A4. Определения и свойства даны в формулировках школьного учебника.

Теория

1. Квадратный корень. Арифметическим квадратным корнем из числа a называют неотрицательное число, квадрат которого равен a. Обозначают √a, где a ≥ 0; число a называют подкоренным выражением. √49 = 7, так как 7 ≥ 0 и 72 = 49. Корень из отрицательного числа не существует. √0 = 0. При a ≥ 0 верно (√a)2 = a. Для любого числа a верно √a2 = |a|: √(−7)2 = √49 = 7, а не −7. Арифметический корень никогда не бывает отрицательным.
2. Квадраты, которые надо знать. 112 = 121, 122 = 144, 132 = 169, 142 = 196, 152 = 225, 162 = 256, 172 = 289, 182 = 324, 192 = 361, 202 = 400, 252 = 625. Десятичные: 0,12 = 0,01; 0,22 = 0,04; 0,32 = 0,09; 0,52 = 0,25; 1,12 = 1,21; 1,22 = 1,44; 1,32 = 1,69; 1,52 = 2,25. Если после запятой под корнем 2 знака, то в ответе 1 знак; если 4 знака, то 2: √0,0049 = 0,07.
3. Свойства арифметического квадратного корня. Для a ≥ 0 и b ≥ 0 верно √ab = √a · √b: корень из произведения неотрицательных множителей равен произведению корней из этих множителей. Для a ≥ 0 и b > 0 верно √ab = √a√b: корень из дроби равен корню из числителя, делённому на корень из знаменателя. Читая справа налево, эти равенства позволяют перемножать и делить корни: √a · √b = √ab, √a : √b = √a : b. Примеры: √36 · 49 = 6 · 7 = 42; √12 · √27 = √324 = 18; √72 : √2 = √36 = 6; √0,36 · 49 = 0,6 · 7 = 4,2. Корень из суммы не равен сумме корней: √9 + 16 = 5, а √9 + √16 = 7.
4. Вынесение множителя из-под знака корня. При a ≥ 0 и b ≥ 0 верно √a2b = a√b. Чтобы вынести множитель, подкоренное число раскладывают на множитель, являющийся точным квадратом, и остаток: √75 = √25 · 3 = 5√3; √12 = √4 · 3 = 2√3; √72 = √36 · 2 = 6√2. Обратное действие, внесение множителя под знак корня: 3√2 = √9 · 2 = √18. Корни с одинаковым подкоренным выражением называют подобными, их складывают и вычитают как подобные слагаемые: m√a ± n√a = (m ± n)√a. Поэтому √75 − √12 = 5√3 − 2√3 = 3√3. Складывать и вычитать подкоренные числа нельзя: √75 − √12 не равно √63.
5. Произведение и степень корней. По определению √a · √a = (√a)2 = a. Отсюда m√a · n√a = mn · a и (m√a)2 = m2a. Примеры: 3√2 · 5√2 = 15 · 2 = 30; (3√2)2 = 9 · 2 = 18; 6√3 : √3 = 6.
6. Формулы сокращённого умножения с корнями. Разность квадратов: (a + b)(a − b) = a2 − b2. Квадрат суммы и квадрат разности: (a ± b)2 = a2 ± 2ab + b2. Примеры: (√11 + 2√7)(√11 − 2√7) = 11 − 4 · 7 = −17; (√7 − 2)2 = 7 − 4√7 + 4 = 11 − 4√7. Квадрат разности не равен разности квадратов: (√7 − 2)2 не равно 7 − 4.
7. Корень из произведения степеней. При a ≥ 0 верно √a2n = an: показатель под корнем делят на 2. Если под корнем произведение степеней, то извлекают корень из каждого множителя: √26 · 34 · 52 = 23 · 32 · 5 = 8 · 9 · 5 = 360. Если основание не является квадратом, число раскладывают на простые множители: √1800 = √23 · 32 · 52 = 2 · 3 · 5 · √2 = 30√2.
8. Порядок действий и запись ответа. Сначала выполняют действия в скобках, затем возведение в степень и извлечение корня, умножение и деление, в последнюю очередь сложение и вычитание. Значение выражения в задании 8 — целое число или конечная десятичная дробь; корень в ответе не остаётся. Если в конце остался знак корня, вернитесь и проверьте решение. Ответ записывают в бланк №1 числом с запятой: 7,5; −17.

Вопросы для устного опроса

  1. Что называют арифметическим квадратным корнем из числа a? Чему равны √169 и √0,81?
  2. Чему равны (√13)2 и √(−5)2? Почему второй результат не равен −5?
  3. Как извлечь корень из произведения? Чему равен √36 · 49?
  4. Как перемножить корни? Чему равно √12 · √27?
  5. Как разделить корни? Чему равно √72 : √2?
  6. Верно ли, что √9 + 16 = √9 + √16? Проверьте.
  7. Вынесите множитель из-под знака корня: √75, √12, √72.
  8. Чему равна разность √75 − √12? Почему нельзя вычесть 75 − 12?
  9. Чему равно (3√2)2? Что возводится в квадрат?
  10. Запишите формулу разности квадратов. Чему равно (√7 − √3)(√7 + √3)?
  11. Раскройте скобки: (√7 − 2)2. Какие слагаемые получаются?
  12. Как извлечь корень из степени? Чему равны √26 и √34 · 52?
  13. Чему равны √1,44, √0,0049, √0,25? Как определить, сколько знаков после запятой в ответе?
  14. Чему равны √(−7)2 и (−√7)2? Чем отличаются эти записи?
Ответы на вопросы (для учителя).
  1. Неотрицательное число, квадрат которого равен a. √169 = 13; √0,81 = 0,9.
  2. (√13)2 = 13; √(−5)2 = √25 = 5, так как √a2 = |a| и арифметический корень неотрицателен.
  3. Равен произведению корней: √36 · 49 = 6 · 7 = 42.
  4. Перемножить подкоренные числа: √12 · √27 = √324 = 18.
  5. Разделить подкоренные числа: √72 : √2 = √36 = 6.
  6. Нет: √9 + 16 = √25 = 5, а √9 + √16 = 3 + 4 = 7.
  7. √75 = 5√3; √12 = 2√3; √72 = 6√2.
  8. 5√3 − 2√3 = 3√3. Корни сначала приводят к виду с одинаковым подкоренным числом.
  9. (3√2)2 = 9 · 2 = 18. В квадрат возводят и коэффициент 3, и корень.
  10. (a + b)(a − b) = a2 − b2. (√7 − √3)(√7 + √3) = 7 − 3 = 4.
  11. (√7 − 2)2 = 7 − 4√7 + 4 = 11 − 4√7.
  12. Показатель делят на 2: √26 = 23 = 8; √34 · 52 = 9 · 5 = 45.
  13. √1,44 = 1,2; √0,0049 = 0,07; √0,25 = 0,5. В ответе вдвое меньше знаков после запятой, чем под корнем.
  14. √(−7)2 = 7; (−√7)2 = 7 (минус в скобках, квадрат положителен). Но −√49 = −7: минус остался перед корнем.
