Задача A. Вынесение множителя из-под знака корня, подобные слагаемые

Найдите значение выражения √75 − √12√3

Что видим. Дробь: в числителе разность двух корней, в знаменателе корень. Подкоренные числа разные (75, 12, 3), но 75 = 25 · 3 и 12 = 4 · 3, то есть под корнем можно получить множитель 3.

Правило. Вынесение множителя: √a2b = a√b при a ≥ 0, b ≥ 0. Подобные корни складывают и вычитают как подобные слагаемые: m√b ± n√b = (m ± n)√b.

Алгоритм. вынести множитель из каждого корня → привести подобные → разделить на √3

Решение по шагам.

  1. √75 = √25 · 3 = 5√3; √12 = √4 · 3 = 2√3.
  2. Разность: 5√3 − 2√3 = (5 − 2)√3 = 3√3.
  3. Деление: 3√3 : √3 = 3.

Ответ: 3.

Проверка. √75 ≈ 8,660; √12 ≈ 3,464; разность ≈ 5,196; √3 ≈ 1,732; 5,196 : 1,732 = 3,000.

Ловушка. Нельзя вычесть подкоренные числа: √75 − √12 не равно √63. Также частая ошибка — записать √75 = 25√3 (в коэффициент нужно взять √25 = 5).

Задача B. Разность квадратов с корнями

Найдите значение выражения (√11 + 2√7)(√11 − 2√7)

Что видим. Произведение суммы и разности одних и тех же выражений √11 и 2√7.

Правило. Разность квадратов: (a + b)(a − b) = a2 − b2. Квадрат корня: (√a)2 = a; квадрат произведения: (mb)2 = m2b2.

Алгоритм. найти a² → найти b² → вычесть

Решение по шагам.

  1. a = √11, b = 2√7; a2 = 11.
  2. b2 = 22 · (√7)2 = 4 · 7 = 28.
  3. a2 − b2 = 11 − 28 = −17.

Ответ: −17.

Проверка. √11 ≈ 3,3166; 2√7 ≈ 5,2915; сумма ≈ 8,6081; разность ≈ −1,9749; произведение ≈ −17,00.

Ловушка. (2√7)2 = 28, а не 14 и не 4√7. Ответ получается отрицательным: 11 − 28 = −17.

Задача C. Квадрат разности и сокращение слагаемых с корнем

Найдите значение выражения (√7 − 2)2 + 4√7

Что видим. Квадрат разности с корнем и слагаемое 4√7. Ответ должен быть числом, значит слагаемые с √7 сократятся.

Правило. Квадрат разности: (a − b)2 = a2 − 2ab + b2.

Алгоритм. раскрыть квадрат → привести подобные

Решение по шагам.

  1. a = √7, b = 2. a2 = 7; 2ab = 2 · √7 · 2 = 4√7; b2 = 4.
  2. (√7 − 2)2 = 7 − 4√7 + 4 = 11 − 4√7.
  3. 11 − 4√7 + 4√7 = 11.

Ответ: 11.

Проверка. √7 ≈ 2,6458; √7 − 2 ≈ 0,6458; квадрат ≈ 0,4170; 4√7 ≈ 10,583; сумма ≈ 11,000.

Ловушка. (√7 − 2)2 не равно 7 − 4: потерять удвоенное произведение 2ab — самая частая ошибка.

Задача D. Корень из произведения степеней

Найдите значение выражения √26 · 34 · 5212

Что видим. Корень из произведения степеней, затем деление на 12. Все показатели под корнем чётные.

Правило. При a ≥ 0 верно √a2n = an, потому что (an)2 = a2n. Корень из произведения равен произведению корней.

Алгоритм. корень из каждого множителя → перемножить → разделить на 12

Решение по шагам.

  1. √26 = 23 = 8; √34 = 32 = 9; √52 = 5.
  2. 8 · 9 · 5 = 360.
  3. 360 : 12 = 30.

Ответ: 30.

Проверка. 26 · 34 · 52 = 64 · 81 · 25 = 129600. 3602 = 129600, поэтому корень равен 360, а 360 : 12 = 30.

Ловушка. Показатель делят на 2: √26 = 23 = 8. Ошибки: оставить показатель (26), вычесть из него 2 или извлечь корень из основания.

Задача E. Корни из десятичных дробей

Найдите значение выражения √1,6 · √40 − √0,01 · 25

Что видим. Корни из десятичных дробей. Первое произведение корней удобно записать под одним корнем.

Правило. √a · √b = √ab при a ≥ 0, b ≥ 0. Корень из десятичной дроби: после запятой в ответе вдвое меньше знаков, чем под корнем.

Алгоритм. первое слагаемое под одним корнем → второе слагаемое → вычесть

Решение по шагам.

  1. √1,6 · √40 = √1,6 · 40 = √64 = 8.
  2. √0,01 · 25 = √0,25 = 0,5 (0,52 = 0,25).
  3. 8 − 0,5 = 7,5.

Ответ: 7,5.

Проверка. √1,6 ≈ 1,2649; √40 ≈ 6,3246; произведение ≈ 8,000; 8 − 0,5 = 7,5.

Ловушка. √0,01 = 0,1, а не 0,01 и не 0,001. Запятую переносят на вдвое меньше знаков: 0,25 под корнем даёт 0,5.
