# STATE — сайт lili.math (lilimath.ru)

Единственный файл состояния. Заменяет perenos1–3: после каждой сессии правим его, а не создаём новый.

## Правила
1. Рабочая папка одна: клон этого репозитория. Не копировать файлы между папками сессий.
2. Любой новый файл сразу попадает в `catalog.json` (тип, класс, номер задания, статус).
3. Перед публикацией: `python3 tools/check_links.py` (код 0 = можно), `node --check` для скриптов в kabinet.html.
4. Опубликованные файлы не переименовываем: на них ведут личные ссылки учеников, Авито, Профи, рилсы.
5. Новые файлы называем `тип-класс-тема.html`, например `diagnostika-9-algebra.html`.
6. Изменения — в ветке, в main только после проверки.
7. Рисунки и чертежи: подписи (буквы, цифры) никогда не лежат на линиях чертежа и не налезают друг на друга. Подпись ставится в свободное место рядом (`Fig.label` в `tools/urok/figs.py`, `LAB` в `tools/urok/widgets.js`), результат проверяется на готовой картинке: `tools/urok/figcheck.py` должен дать 0 проблем на всех рисунках и положениях ползунков.
