Памятка: алгоритм и оформление, квадратные уравнения (№9 и №20)

№9 — в бланк записывают только ответ (1 балл). №20 — решение записывают полностью на бланке №2 (2 балла).

Алгоритм решения

  1. Определи тип. Квадратное уравнение, дробь, замена (повторяющееся выражение), кубическое, система.
  2. Если есть дробь — запиши ОДЗ. Знаменатели не равны нулю: x ≠ …
  3. Приведи к виду ax² + bx + c = 0: раскрой скобки, перенеси всё влево, собери подобные. Если a < 0, можно умножить на −1.
  4. Выбери способ. Нет c — вынеси x за скобку. Нет b — x² = число. Иначе дискриминант D = b² − 4ac (проверь Виетом: сумма −b/a, произведение c/a).
  5. Реши. D > 0 — два корня, D = 0 — один, D < 0 — корней нет.
  6. Если была замена — вернись к x и реши уравнение для каждого t. Если была дробь — отбрось корни из ОДЗ.
  7. Проверь хотя бы один корень подстановкой. Запиши ответ: все корни, а в №9 — тот, который просят (меньший, больший).
Формулы. D = b² − 4ac; x = (−b ± √D) / (2a). Виета: x₁ + x₂ = −b/a, x₁ · x₂ = c/a. ax² + bx + c = a(x − x₁)(x − x₂). Дробь = 0, когда числитель = 0 и знаменатель ≠ 0.

Что снимает баллы

  • Деление обеих частей на x (или на скобку с x): потерян корень.
  • Не приведено к виду ax² + bx + c = 0 до подсчёта D, ошибка в знаках b и c.
  • Посторонний корень оставлен в ответе (в дробном уравнении без ОДЗ).
  • После замены найдено t, но не найден x.
  • В системе в ответе только x или только y: нужны пары.
  • №9: записан не тот корень (оба вместо меньшего) или не в том виде (дробь вместо десятичной).
  • Вычислительная ошибка при верном ходе — 1 балл вместо 2. Нет хода решения, только ответ — 0 баллов.

Образец записи (№20)

Задача. Решите уравнение x/(x − 2) − 8/(x² − 4) = 1/(x + 2).

Решение. Разложим x² − 4 = (x − 2)(x + 2). ОДЗ: x ≠ 2, x ≠ −2.

Умножим обе части на (x − 2)(x + 2):

x(x + 2) − 8 = x − 2.

x² + 2x − 8 − x + 2 = 0; x² + x − 6 = 0.

D = 1 + 24 = 25; x₁ = (−1 + 5)/2 = 2; x₂ = (−1 − 5)/2 = −3.

Число 2 не входит в ОДЗ, поэтому не является корнем уравнения.

Проверка. x = −3: −3/(−5) − 8/5 = 0,6 − 1,6 = −1; 1/(−3 + 2) = −1. Верно.

Ответ: −3.

Где эксперт ищет баллы: 1) записана ОДЗ или есть проверка знаменателей; 2) уравнение верно преобразовано к квадратному; 3) квадратное уравнение верно решено (D и корни); 4) отобран корень; 5) в ответ записаны все корни и только они.

№9: как записать

Решение на бланк не пишут, но считать нужно на черновике полностью. Пример: «Найдите корни уравнения x² − 5x + 6 = 0. Если корней несколько, запишите меньший из них». Ответ: 2. Если корень десятичная дробь, пишут через запятую: 2,5. Проверка Виетом: сумма 5, произведение 6.
