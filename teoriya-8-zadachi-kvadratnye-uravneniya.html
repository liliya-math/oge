Решение задач с помощью квадратных уравнений

Алгоритм решения задачи

Решение текстовых задач - самое трудное для многих учеников. Чтобы не учить каждый тип задач отдельно, пользуются одним общим алгоритмом, который подходит для любой задачи.

  1. обозначить неизвестную величину буквой, например xxx, и выразить через неё остальные величины;
  2. согласно условию задачи составить уравнение;
  3. решить полученное уравнение;
  4. отобрать корни: проверить, подходит ли каждый корень по смыслу задачи;
  5. записать ответ.

Оформлять решение можно в виде таблицы или в виде кратких пояснений.

Почему так

Квадратное уравнение может иметь два корня, а в задаче часто подходит только один. Например, длина стороны, число рядов или число людей не могут быть отрицательными или дробными. Поэтому четвёртый шаг пропускать нельзя.

Типы задач

Задачи, которые решаются с помощью квадратных уравнений, условно делят на типы:

  1. задачи на числовые зависимости;
  2. задачи на движение;
  3. задачи на совместную работу;
  4. задачи на сплавы и смеси;
  5. задачи на проценты;
  6. задачи на разбавление;
  7. задачи на движение по воде.

Алгоритм у всех один. Меняется только то, какие формулы связывают величины в условии.

Пример

Задача. Одно из двух натуральных чисел на 3 больше другого, а их произведение равно 70. Найти эти числа.

Пусть меньшее число равно xxx, тогда большее равно x+3x+3x+3. По условию их произведение равно 70.

x(x+3)=70x(x+3)=70x(x+3)=70

Раскроем скобки и перенесём 70 влево:

x2+3x−70=0x^2+3x-70=0x2+3x−70=0

Дискриминант D=32−4⋅1⋅(−70)=9+280=289D=3^2-4\cdot 1\cdot(-70)=9+280=289D=32−4⋅1⋅(−70)=9+280=289, D=17\sqrt{D}=17D​=17.

x1=−3+172=7,x2=−3−172=−10x_1=\dfrac{-3+17}{2}=7,\quad x_2=\dfrac{-3-17}{2}=-10x1​=2−3+17​=7,x2​=2−3−17​=−10

Число −10-10−10 не натуральное, поэтому не подходит. Значит, меньшее число равно 7, а большее 7+3=107+3=107+3=10.

Проверка: 7⋅10=707\cdot 10=707⋅10=70, и 10 на 3 больше 7. Всё верно.

Ответ: 7 и 10.

Теорема Пифагора для прямоугольного треугольника с катетами aaa, bbb и гипотенузой ccc:

a2+b2=c2a^2+b^2=c^2a2+b2=c2

Диагональ прямоугольника делит его на два прямоугольных треугольника, поэтому для сторон aaa, bbb и диагонали ddd верно a2+b2=d2a^2+b^2=d^2a2+b2=d2.
