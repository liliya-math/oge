Системы уравнений: теория и устный опрос

Задание 20 ОГЭ (часть 2, 2 балла). Печать: 2 листа A4. Определения и правила записаны близко к школьному учебнику (алгебра, 9 класс).

1. Решение системы

Решением системы уравнений с двумя переменными называется пара значений переменных, обращающая каждое уравнение системы в верное равенство. Решить систему — значит найти все её решения или доказать, что решений нет.

Решение записывают парой (x; y): сначала x, потом y. Пары (3; 4) и (4; 3) — разные решения.

Пример. Пара (2; 1) — решение системы x + y = 3x² + y² = 5 Проверка: 2 + 1 = 3 и 4 + 1 = 5, оба равенства верны.

2. Способ подстановки

  1. Выразить из какого-либо уравнения одну переменную через другую (удобнее из линейного).
  2. Подставить полученное выражение в другое уравнение.
  3. Решить уравнение с одной переменной.
  4. Найти соответствующие значения второй переменной.
  5. Записать ответ: пары (x; y).

Если в системе есть линейное уравнение, подставляем из него. Тогда нелинейное уравнение превращается в квадратное с одной переменной.

3. Способ сложения

  1. Умножить уравнения почленно на такие числа, чтобы коэффициенты при одной из переменных стали противоположными.
  2. Сложить уравнения почленно.
  3. Решить получившееся уравнение с одной переменной.
  4. Найти вторую переменную подстановкой.

Если в обоих уравнениях стоят только x² и y² (без x, y и xy), складываем или вычитаем уравнения и находим x² и y². Каждый квадрат даёт два значения: ±.

8. Проверка и запись ответа

Подставьте каждую пару в оба уравнения. Ответ запишите парами через запятую: (1; 2), (2; 1). Если в условии сказано «запишите решение с наибольшим x», выберите пару и запишите её целиком.

4. Произведение равно нулю

Произведение равно нулю тогда и только тогда, когда хотя бы один из множителей равен нулю, а остальные при этом имеют смысл.

Уравнение (x − 2)(y + 1) = 0 разбиваем на две системы: с x = 2 и с y = −1. Решения объединяем; одинаковые пары записываем один раз.

Однородное уравнение x² − 3xy + 2y² = 0 раскладываем на множители: (x − y)(x − 2y) = 0.

5. Симметричные системы

Если x + y = s и xy = p, то x и y — корни квадратного уравнения t² − st + p = 0 (теорема, обратная теореме Виета).

Полезные формулы: x² + y² = (x + y)² − 2xy; (x − y)² = (x + y)² − 4xy.

Если в системе есть x² + y² и x + y, обозначаем s = x + y, p = xy. Найдя s и p, решаем t² − st + p = 0. Для t₁ ≠ t₂ получаем две пары: (t₁; t₂) и (t₂; t₁).

6. Дроби и замена переменной

Если в системе есть дроби, сначала записываем ОДЗ: знаменатели не равны нулю. Для выражения xy + yx вводим t = xy, тогда yx = 1t.

Решив уравнение для t, возвращаемся к x и y. Каждое значение t даёт свою ветку; ветка может не дать решений.

7. Графический способ

Решения системы — координаты общих точек графиков уравнений. Число решений равно числу общих точек.
УравнениеГрафик
ax + by = cпрямая
x² + y² = r²окружность, центр (0; 0), радиус r
y = x² + bx + cпарабола
y = k/xгипербола

Прямая и окружность имеют 0, 1 или 2 общие точки. Точку пересечения по рисунку не всегда можно прочитать точно, поэтому график надёжно даёт число решений, а сами решения находим вычислением.

Вопросы для устного опроса (с ответами)

Ученику читают вопрос, ответ закрыт. Ответ «примерно» засчитывается, если сохранён смысл правила. Для 5-минутного опроса: вопросы 1, 5, 7, 9, 12.

№ВопросОтвет
1Что называют решением системы двух уравнений с двумя переменными?Пару значений переменных, обращающую каждое уравнение системы в верное равенство.
2Чем отличаются решения (2; 5) и (5; 2)?Это разные решения: на первом месте x, на втором y. Для несимметричной системы подходить может только одна из пар.
3Что значит «решить систему»?Найти все её решения или доказать, что решений нет.
4Какие способы решения систем вы знаете?Подстановка, сложение, графический способ, замена переменных.
5Когда удобнее подстановка?Когда одно из уравнений линейное: из него легко выразить переменную.
6Когда удобнее сложение?Когда коэффициенты при одной переменной равны или противоположны, например в системе из двух уравнений с x² и y².
7Как решить систему x + y = s, xy = p?Составить уравнение t² − st + p = 0: его корни — это x и y; записать обе пары.
8Как выразить x² + y² через x + y и xy?x² + y² = (x + y)² − 2xy.
9Что делать с уравнением (x − a)(y − b) = 0?Разбить на две системы (x = a и y = b), решить каждую и объединить ответы; одинаковые пары записать один раз.
10Что нужно записать в системе с дробями?ОДЗ: знаменатели не равны нулю; в конце проверить, что найденные пары в ОДЗ входят.
11Сколько решений может быть у системы «окружность и прямая»?Ни одного, одно (касание) или два.
12Нашли значения x. Что дальше?Для каждого x найти y и записать пары. Ответ «x = 2, x = −3» — неполный.
13Что значит «запишите решение с наибольшим x»?Из всех пар выбрать ту, где x больше, и записать её целиком, обе координаты.
14Почему нельзя делить обе части уравнения на переменную?Переменная может быть равна нулю: при делении теряется корень. Правильно вынести за скобку.
15Как проверить решение системы?Подставить пару в оба уравнения: оба равенства должны быть верными.

Типичные ошибки (на что смотреть)

  1. Нашли x и не нашли y: в ответе нет пар.
  2. Потеряли ветку: (x − a)(y − b) = 0 решили только для x = a.
  3. Одну и ту же пару записали дважды или не заметили, что она общая для двух веток.
  4. В системе с дробями не записали ОДЗ и не проверили найденные пары.
  5. Из x² = 9 записали только x = 3.
  6. Нашли s = x + y, но не вернулись к t² − st + p = 0.
