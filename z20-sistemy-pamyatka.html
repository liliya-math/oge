Памятка: алгоритм и оформление, системы уравнений (№20)

№20 оформляют полностью на бланке №2 (2 балла). В ответе — пары чисел (x; y). Ход решения должен быть виден эксперту.

Алгоритм решения системы

  1. Посмотри на уравнения. Какие члены есть: x², y², xy, дроби, линейное уравнение, произведение?
  2. Если есть дробь — запиши ОДЗ: x ≠ 0, y ≠ 0 и т. д.
  3. Выбери способ по таблице ниже. Напиши фразу: «Из второго уравнения выразим x» или «Сложим уравнения».
  4. Сведи к одному уравнению с одной переменной и реши его (дискриминант, Виета, разложение).
  5. Для каждого найденного значения найди вторую переменную. Запиши пары.
  6. Проверь пары по ОДЗ и подстановкой хотя бы в одно уравнение (лучше в оба).
  7. Запиши ответ парами: (x₁; y₁), (x₂; y₂). Совпавшие пары — один раз.

Какой способ выбрать

Что вижуЧто делаю
Есть линейное уравнениеПодстановка: выразить переменную из линейного.
Только x² и y² в обоихСложение или вычитание (с умножением), затем ±.
x + y и xy (или x² + y²)s = x + y, p = xy; t² − st + p = 0.
Произведение равно 0Две системы: каждый множитель = 0.
Однородное уравнение второй степениРазложить на множители (x − ay)(x − by) = 0.
x/y + y/x или другие дробиОДЗ; замена t = x/y; потом x = ty.
Формулы. x² + y² = (x + y)² − 2xy. (x − y)² = (x + y)² − 4xy. Корни t² − st + p = 0 — это x и y. Из x² = a (a > 0): x = ±√a.

Что снимает баллы

  • В ответе только x (или только y), нет пар.
  • Потеряна ветка: решена одна из двух систем (произведение, однородное).
  • Из x² = 4 записано только x = 2.
  • Совпавшая пара записана дважды или не отброшена после проверки ОДЗ.
  • Деление обеих частей на переменную: теряется корень (или решение с нулём).
  • Вычислительная ошибка при верном ходе: 1 балл вместо 2. Только ответ без хода: 0 баллов.

Образец записи (№20)

Задача. Решите систему уравнений: x + y = 7x² + y² = 25

Решение. Пусть x + y = s, xy = p. Тогда x² + y² = s² − 2p.

Из условия s = 7 и 25 = 7² − 2p; 2p = 49 − 25 = 24, p = 12.

Числа x и y — корни уравнения t² − 7t + 12 = 0. D = 49 − 48 = 1; t₁ = (7 + 1)/2 = 4; t₂ = (7 − 1)/2 = 3.

Значит, пары (4; 3) и (3; 4).

Проверка. (4; 3): 4 + 3 = 7; 16 + 9 = 25. Верно. Вторая пара получается перестановкой, система симметрична.

Ответ: (3; 4), (4; 3).

Образец с дробью. Система 1x + 1y = 56x + y = 5. ОДЗ: x ≠ 0, y ≠ 0. Так как 1x + 1y = x + yxy, получаем 5xy = 56, то есть xy = 6. Вместе с x + y = 5: t² − 5t + 6 = 0, t = 2 или t = 3. Пары (2; 3), (3; 2). Числа не равны нулю, ОДЗ выполнено. Ответ: (2; 3), (3; 2).
Где эксперт ищет баллы: 1) выбран и назван способ; 2) уравнения верно преобразованы (одно уравнение с одной переменной); 3) оно верно решено; 4) для каждого корня найдена вторая переменная; 5) в ответ записаны все пары и только они. Описка при верном ходе — 1 балл из 2. Точные критерии смотрите в актуальных материалах ФИПИ.
