Неравенства: теория и устный опрос

№13 (часть 1) и №20 (часть 2). Печать: 3 страницы A4. Определения и правила записаны близко к школьному учебнику (алгебра, 8–9 класс).

1. Решение неравенства

Решением неравенства с одной переменной называется значение переменной, которое обращает его в верное числовое неравенство. Решить неравенство — значит найти все его решения или доказать, что решений нет. Неравенства, имеющие одни и те же решения, называют равносильными.

Пример. Число 3 — решение неравенства 2x − 1 > 4: при x = 3 получаем 5 > 4, это верно. Число 2 не решение: 3 > 4 неверно.

2. Свойства неравенств

  1. Если к обеим частям неравенства прибавить (или из обеих частей вычесть) одно и то же число, получится равносильное неравенство. Любое слагаемое можно перенести из одной части в другую, изменив его знак.
  2. Если обе части неравенства умножить (или разделить) на одно и то же положительное число, получится равносильное неравенство.
  3. Если обе части умножить (или разделить) на одно и то же отрицательное число и изменить знак неравенства на противоположный, получится равносильное неравенство.

Пример. −3x > 12. Делим на −3 и меняем знак: x < −4.

3. Линейное неравенство

Неравенство ax > b сводится к виду: при a > 0 получаем x > b/a; при a < 0 получаем x < b/a (знак меняется). Если a = 0, неравенство 0·x > b верно при любом x (если b < 0) или не имеет решений (если b ≥ 0).

Пример. 5x − 7 ≤ 8x + 2; 5x − 8x ≤ 2 + 7; −3x ≤ 9; x ≥ −3. Ответ: [−3; +∞).

5. Системы неравенств

Решением системы неравенств с одной переменной называется значение переменной, при котором верно каждое неравенство системы. Чтобы решить систему, решают каждое неравенство, отмечают решения на одной числовой прямой и берут их общую часть (пересечение).

Пример. Система x > 1, x ≤ 4: общая часть (1; 4]. Если общих точек нет, решений нет. Не путайте пересечение (система) с объединением (две ветки).

6. Квадратное неравенство

Неравенство вида ax² + bx + c > 0 (< 0, ≥ 0, ≤ 0), где x — переменная, a, b, c — числа, a ≠ 0, называется квадратным неравенством.
  1. Если a < 0, умножить обе части на −1 и сменить знак неравенства.
  2. Найти корни трёхчлена (дискриминант или теорема Виета).
  3. Схематично изобразить параболу (ветви вверх) и отметить корни.
  4. Выбрать промежутки: «> 0» — где парабола выше оси, «< 0» — где ниже.
  5. Записать ответ с нужными скобками.

Примеры. x² < 9: (−3; 3). x² > 9: (−∞; −3) ∪ (3; +∞). Запись «x > ±3» неверна.

7. Метод интервалов

Чтобы решить неравенство (x − x₁)(x − x₂)…(x − xₙ) > 0 (< 0): 1) отметить на оси нули множителей; 2) определить знак на самом правом промежутке (при положительном старшем коэффициенте это «+»); 3) расставить знаки справа налево, меняя знак при переходе через корень нечётной кратности; через корень чётной кратности знак не меняется; 4) выбрать промежутки нужного знака.

Корень чётной кратности, например (x − 1)², при нестрогом знаке даёт в ответ отдельную точку, если рядом знак «минус».

8. Дробно-рациональные неравенства

Дробь P/Q положительна, если P и Q одного знака; отрицательна, если разных знаков; равна нулю, если P = 0, а Q ≠ 0.
  1. Перенести всё в левую часть, привести к одной дроби.
  2. Разложить числитель и знаменатель на множители, отметить их нули.
  3. Нули знаменателя всегда выколоты; нули числителя закрашены только при ≥ и ≤.
  4. Решить методом интервалов.

Нельзя умножать обе части на выражение с неизвестным знаком и сокращать на выражение с переменной.

9. Где это в ОГЭ

№13 (часть 1): по неравенству выбрать верный промежуток или рисунок, в ответ записывается номер. №20 (часть 2): полное решение на бланке №2, в ответе записывается промежуток. Точные формулировки и критерии — по актуальным материалам ФИПИ.

Типичные ошибки (на что смотреть)

  1. Деление на отрицательное число без смены знака неравенства.
  2. Для x² > 9 записали только x > 3 (потеряли x < −3).
  3. Квадратная скобка у бесконечности или круглая у закрашенной точки.
  4. Вместо пересечения решений системы записали объединение.
  5. В дроби не выколота нулевая точка знаменателя.
  6. Умножили обе части на выражение с x, не зная его знак.
  7. Потеряли изолированную точку от корня чётной кратности (x − 1)² при знаке ≥ или ≤.
  8. Не заметили, что D < 0: решили «до корней» там, где решений нет или подходит любое x.
